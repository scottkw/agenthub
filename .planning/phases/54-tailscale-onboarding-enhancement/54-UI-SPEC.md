## Interaction Contracts

### TS-01: Copy-to-Clipboard Button

- Trigger: user clicks "Copy" button next to a command block
- API: `navigator.clipboard.writeText(command)` — must be called inside `onClick` handler (user gesture required for WKWebView clipboard permission)
- State transition: idle → `copied` (true) for 1500ms → idle
- Visual: button text changes from "Copy" to "Copied!" and `.health-modal__btn--copy--active` class applied during `copied` state
- No confirmation modal required — feedback is inline button label change
- Do not call `document.execCommand('copy')` — deprecated

### TS-01: Download Link

- Trigger: user clicks download link
- Handler: calls `onOpenURL(url)` prop — NOT `BrowserOpenURL` directly (Vitest isolation requirement from RESEARCH.md)
- Visual: `#7aa2f7` text with underline, no spinner needed (external browser handles it)
- Platform-specific URLs:
  - macOS: `https://tailscale.com/download/macos`
  - Linux: `https://tailscale.com/download/linux`
  - Windows: `https://tailscale.com/download/windows`

### TS-02: Try Auto-Install Button (macOS only)

- Only rendered when `platform === 'darwin'`
- Trigger: user clicks "Try Auto-Install"
- Handler: calls `onAutoInstall()` prop — NOT direct Wails binding (Vitest isolation requirement)
- State machine:
  - `idle` → button visible, enabled
  - `running` → button text "Installing..." + `.health-modal__btn--auto-install--running` + progress `<pre>` appears
  - `success` → progress `<pre>` gets `.health-modal__install-output--success` border + "Next steps" message appears below output
  - `error` → progress `<pre>` gets `.health-modal__install-output--error` border + manual fallback copy-command shown
- Button disabled (pointer-events: none) during `running` state
- Progress lines appended to `<pre>` content via React state; auto-scroll to bottom on each new line
- No "Cancel" button in v1.9 (deferred per RESEARCH.md open question 1)
- Non-macOS platforms: show manual copy command only (no auto-install button)

### TS-03: NoCerts Next Steps Guide

- Replaces the flat paragraph list in `NoCertsPanel` with a numbered step guide
- Steps rendered as `<ol>` using `.health-modal__steps` / `.health-modal__step` / `.health-modal__step-number`
- Step 4 admin console URL (`login.tailscale.com/admin/dns`) rendered as `.health-modal__download-link`, calls `onOpenURL`
- CT disclosure banner (`.ct-disclosure`) preserved below the step list — no change to existing disclosure text
- "Check Again" button preserved in `.health-modal__footer`

### After Auto-Install Completion (Success)

- Do NOT auto-dismiss the modal
- Show inline message below output: "Next: open Tailscale from your menu bar and sign in, then click Check Again."
- "Check Again" button already in footer handles re-polling
- Source: RESEARCH.md open question 2 recommendation
