## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CDN (cdn.jsdelivr.net) → browser | Previously: browser fetched xterm JS/CSS from third-party CDN at runtime. Post-this-plan: terminal.html no longer points there; all xterm tags reference same-origin `/assets/xterm/*`. Actual serving of those paths is wired in Plan 04. |
| inline HTML → browser parser | Inline <script>/<style> blocks run under default CSP context. A strict CSP (`script-src 'self'`) would block them. This plan removes that blocker so Plan 04's CSP is viable. |

| T-89-01 | Tampering | Inline script/style injection path | mitigate | This plan extracts all inline blocks (D-06). Subsequent CSP (`script-src 'self'; style-src 'self'`) in Plan 04 blocks any future inline injection at the browser layer — no nonces or hashes needed. |
| T-89-02 | Tampering | CDN supply-chain (cdn.jsdelivr.net) | mitigate | This plan replaces the three `https://cdn.jsdelivr.net/...` URLs in terminal.html with `/assets/xterm/*`. Combined with Plan 01's vendoring and Plan 04's /assets/ route, the app no longer makes any runtime request to the CDN. |
