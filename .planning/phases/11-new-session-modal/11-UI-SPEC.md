## Interaction Contract

### Opening

- Trigger: clicking the `+` (add tab) button in the tab bar — `handleAddTab` in App.tsx
- Old behavior (CLI picker dropdown) is removed entirely in this phase
- Modal is always shown when `+` is clicked, regardless of how many CLIs are detected
- Exception: if zero CLIs detected, existing behavior (open Settings) is preserved (from RESEARCH.md Pattern 1)

### Agent selection

- On open: first CLI in `detectedCLIs` array is pre-selected
- Selection is single-choice (radio group behavior via state, not native radio inputs)
- No confirmation needed — selection is reflected immediately via visual state

### Folder selection

- On open: read `localStorage.getItem('agenthub:lastWorkDir') ?? ''`
- If `''`: display "Home directory (default)" in dim text; pass `''` to Go — Go resolves home directory
- Clicking "Browse…": calls `OpenDirectoryDialog(selectedDir)`, sets `browseLoading: true`
- On return with non-empty path: update displayed path, write to localStorage, set `browseLoading: false`
- On return with `''` (user cancelled): no state change — keep existing displayed path
- Folder path is never validated client-side (RESEARCH.md Open Question 2: let it fail naturally)

### Confirm / Cancel

- "Create Session": calls `onConfirm(selectedCLI, selectedDir)` → parent calls `createTab(cli, workDir)` → closes modal
- "Cancel" or overlay click or `×` button: calls `onClose()` → modal unmounts
- ESC key: not required for v1.1 (no keyboard trap requirement in SESS-01 through SESS-04)

### Loading states

- "Browsing…" label on Browse button while native dialog is open — button is also `disabled`
- "Creating…" label on Create Session button while `createTab` is in flight — button is also `disabled`
- No spinner animation — text change only (consistent with SettingsPanel "Saving…" / "Starting…" patterns)

### State reset on close/reopen

- When modal unmounts (JSX conditional), React resets state naturally
- On next open: selectedCLI re-defaults to `clis[0].Name`; selectedDir re-reads from localStorage

## Implementation Notes for Executor

1. **CSS namespace**: All new classes use `.new-session-modal` prefix. Add to `style.css` after the existing `.cli-picker` block.

2. **Remove old picker**: Delete `.cli-picker-overlay`, `.cli-picker`, `.cli-picker__label`, `.cli-picker__btn` CSS rules from style.css. Remove `showCLIPicker` state and its JSX from App.tsx in the same commit (RESEARCH.md Pitfall 1).

3. **Modal width**: 460px (narrower than SettingsPanel's 520px — less content). `max-width: 95vw`.

4. **No scroll**: Modal body has fixed short content (agent list + folder row). No `overflow-y: auto` needed on body. `max-height` guard: `max-height: 80vh` on panel container as a safety net.

5. **Font family**: Inherit from `body` — no override needed on modal elements. Only the folder path display uses monospace (inherited).

6. **z-index**: `z-index: 1000` — same as `.settings-overlay` and `.qr-modal-overlay`.

7. **Backdrop**: `background-color: rgba(0, 0, 0, 0.6)` — matches existing modal overlays exactly.
