
**Light mode additions** (inside `[data-ui-theme="light"]` block):
```css
/* COLORBLIND-SAFE: internet badge light hex #0d7a5c — WCAG AA ~5.2:1 on white; icon + text carry state */
--hub-internet-badge-bg: rgba(13, 122, 92, 0.13);
--hub-internet-badge-text: #0d7a5c;
```

**Colorblind-safety verification (MANDATORY per standing convention):**
- State is encoded by **icon shape** (`GlobeAltIcon`, distinctive globe silhouette) **+ text label** ("INTERNET" on card, aria-label "Internet exposed" on tab)
- Color (`--hub-internet-badge-text`) is reinforcement only — removing it must not remove the ability to read the state
- Verify at hex/source level, NOT by eye. User is colorblind.
- Contrast: dark `#43ddb2` on `#14151b` bg = ~7.8:1 AA PASS. Light `#0d7a5c` on `#f5f5f7` = ~5.2:1 AA PASS.

## Interaction Contract

### Funnel toggle → risk panel flow

```
State machine:
  off → [toggle ON] → panel-visible → [Keep local only] → off
                                     → [Enable internet share] → warming-up → active
                                                                             → warm-up-failed (30s timeout)
  active → [Disable internet share] → off (immediate, SetSessionFunnel(id, false, 0))
```

1. **Funnel toggle is OFF:** normal toggle appearance, `aria-checked="false"`, no risk panel.
2. **User flips toggle to ON:** toggle does NOT call `SetSessionFunnel` directly. Instead, reveal the risk panel inline with expand animation. Toggle visually remains in the "pending" / partially-checked state (opacity 0.7) while panel is open to signal that it is not yet committed.
3. **User selects expiry and clicks "Enable internet share":** call `SetSessionFunnel(sessionId, true, expirySeconds)`. Collapse panel. Show warm-up state in the Internet URL section immediately.
4. **User clicks "Keep local only":** collapse panel. Toggle reverts to OFF visually. No API call.
5. **Warm-up:** poll `funnelActive` from session-info (2s interval). Reveal URL/QR when active. Timeout at 30s.
6. **Active state:** toggle is checked, risk panel hidden, Internet (public) section shows URL + copy + QR + disable button.
7. **Disable:** single click on "Disable internet share" → `SetSessionFunnel(id, false, 0)` → toggle → OFF, Internet section hides, badge clears on next poll.

### Local fallback state (webServerMode !== 'tailscale')

- Funnel toggle is `disabled` (HTML `disabled` attribute + `aria-disabled="true"` + `pointer-events: none`).
- Explanatory note below toggle: "Internet sharing requires Tailscale" (12.5px / `--hub-text-muted`).
- No risk panel is ever shown in this state.
- Re-enables automatically when `webServerMode` changes back to `'tailscale'`.

### Auto-expiry selector

`<select>` element inside the risk panel. Options:

| Display label | Value passed to SetSessionFunnel (expirySeconds) |
|--------------|---------------------------------------------------|
| 30 minutes | 1800 |
| 1 hour (default) | 3600 |
| 4 hours | 14400 |
| 8 hours | 28800 |
| Until I disable | 0 |

Default selected: "1 hour". Maps `expirySeconds=0` to the "no auto-expiry" sentinel per D-07 (confirm with Phase-165 backend: `expirySeconds <= 0` means no expiry in the `funnelExpiry` map).

### Focus management

- Risk panel receives focus when expanded (focus the Cancel button or the expiry selector as the first focusable element).
- On "Keep local only" or successful enable, return focus to the Funnel toggle.
- All interactive elements in the risk panel are keyboard-navigable (Tab order: expiry select → help link → Keep local only → Enable internet share).
- Disable button in the Internet section follows the existing `.tab-status-bar__btn` focus pattern: `outline: 2px solid var(--hub-accent)` on `:focus-visible`.

### Motion

All new animations respect the existing motion guard pattern:
```css
@media (prefers-reduced-motion: no-preference) {
  .hub-funnel-risk-panel { transition: max-height 200ms ease-out, opacity 150ms ease; }
}
@media (prefers-reduced-motion: reduce) {
  .hub-funnel-risk-panel { transition: none; }
}
```

### Help guide content requirements (HLP-01/HLP-02)

The `sharing-guide.md` article MUST include, in this order:

1. **H2: "Sharing Outside Your Tailnet"** — intro paragraph explaining the two paths
2. **H3: "Option 1 — Tailscale Funnel (public internet)"** — step-by-step for the Funnel flow (toggle → risk dialog → copy URL); note that the join code is the only gate and expires
3. **H3: "Option 2 — Device Share + ACL (contained)"** — the tighter-containment alternative. Steps:
   - Share the device in the Tailscale admin console
   - Tag it `tag:agenthub`
   - Restrict shared users to AgentHub's port
   - Grant: copy-pasteable ACL block:
     ```json
     {
       "action": "accept",
       "src": ["autogroup:shared"],
       "dst": ["tag:agenthub:tcp:7443"]
     }
     ```
   - **Explicitly call out the wildcard-default gotcha:** "Tailscale ACLs default to `*→*` (allow all). Adding a `tag:agenthub` restriction will narrow this — verify your full ACL after editing."
4. External links to Tailscale docs (use `BrowserOpenURL` + `.help-content__external-link` button pattern — no raw `<a>` tags, per Wails CSP)
5. Link back to the Funnel path from Option 2: "For fully public sharing (no Tailscale account required), see Option 1 above."

Port reference: use `:7443` for the local web-share port (confirmed from STATE.md references to `:7443`).
