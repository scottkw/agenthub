<objective>
Close the three CSS accessibility gaps (GAP-135-A, GAP-135-E, GAP-135-F) on the Hub surface: add `:focus-visible` outline rings to every interactive Hub element, upgrade the existing `.hub-card:focus` rule to `:focus-visible`, and add two `prefers-reduced-motion: reduce` blocks that stop the running-status spinner and suppress the card hover transition.

Purpose: Satisfies A11Y-02 (keyboard-visible focus rings, not mouse-noisy) and A11Y-03 (motion respects OS reduced-motion preference) at the CSS layer. The user is colorblind — focus-ring visibility and motion fallbacks are release-blocking and verified at source against the `--hub-accent` token, never by eye.
Output: Modified `frontend/src/style.css` plus source-inspection assertions in the existing `style.hub.test.ts`.
</objective>
