<objective>
Eliminate the data race in `SessionEngine.GetSessionStyledTailLines` (#100) by adopting
RESEARCH.md Option 2: strip terminal-query and in-band-resize escape sequences from the
scrollback BEFORE `emu.Write`, then remove the drain goroutine so the emulator is driven
fully synchronously (Write -> Close -> read) on a single goroutine. With no concurrent
`emu.Read`/`emu.Close`, the race in `charmbracelet/x/vt`'s unsynchronized `closed` field is
structurally impossible — without bumping vt (Option 1 is dead per RESEARCH.md).

Purpose: CI's race-detector job ("Run Go tests (all platforms, race detector)") is red on the
daemon package because of this structural race. This is the FIX-01 burndown for v4.0.
Output: A subtractive change to `internal/daemon/engine.go` (-1 goroutine, -1 channel, -1
import; +1 package-level regex, +1 ReplaceAll), a broadened regression fixture in the existing
daemon test file, and a TESTING.md traceability row for FIX-01.
</objective>
