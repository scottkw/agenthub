<objective>
Fix CHAT-LAYOUT-01: a web peer's raw `authorID` (e.g. `nodekey:456d9361bab4eb7…`) renders un-truncated as the `.chat-msg__tailnet-id` secondary label, forcing horizontal scroll on the web-share `/app/` surface. Two coordinated changes in the SHARED chat components so all surfaces (GUI session tab, Hub interactive modal, web-share guest) benefit:

1. Root-cause fix (CONTEXT Decision 1): constrain the virtualizer row in `getRowStyle()` to the thread width so the already-correct WEBCHAT-06 ellipsis engages.
2. Secondary-label fingerprint (CONTEXT Decision 2): render the last 6 characters of `authorID` as a compact disambiguator instead of the full raw nodekey, derived client-side via a pure exported helper.

Purpose: Eliminate the horizontal-scroll layout break on web-share and replace an unreadable raw nodekey with a short stable fingerprint, without changing the identity/dedup key.
Output: Updated `ChatPanel.tsx`, `ChatMessage.tsx`, extended vitest coverage, TESTING.md traceability.
</objective>
