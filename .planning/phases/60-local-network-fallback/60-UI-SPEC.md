## Component Specifications

### 1. LocalNetworkBanner

**Purpose:** Persistent nudge informing the user they are running in local network mode (not Tailscale). Recommends installing Tailscale for better security.

**Layout position:** Rendered as a direct sibling of `.app__content` inside `.app`, placed ABOVE `.app__content`. Never inside `.terminal-container` or any flex container that holds terminal panes.

```
.app (flex row)
  .sidebar
  .local-network-banner   ← NEW: sibling wrapper, full-width above content
  .app__content (flex column)
    .tab-bar
    .tab-content / terminal
```

Wait — the banner must NOT displace the terminal. It should sit ABOVE `app__content` within the column flow. Correct structure:

```
.app (flex row)
  .sidebar
  .app__main (flex column — NEW wrapper or reuse existing)
    .local-network-banner   ← sticky top, shrink: 0
    .app__content           ← flex: 1, takes remaining height
```

Per STATE.md decision: "Nudge banner renders as sibling to app__content, never inside terminal flex container."

**CSS class:** `.local-network-banner`

**Dimensions:**
- Width: 100% of parent
- Height: auto (content-driven, approximately 48px)
- flex-shrink: 0 (never compress)

**Visual style (mirrors `.update-banner` with warning color variant):**
```css
.local-network-banner {
  display: flex;
  align-items: center;
  gap: 8px;
  padding: 12px 16px;
  background: #16161e;
  border-bottom: 1px solid #292e42;
  border-left: 3px solid #f59e0b;   /* warning amber, not blue */
  flex-shrink: 0;
}
```

**Visibility rule:** Rendered only when `webServerMode === 'local'`. Hidden (not rendered) when mode is `'tailscale'` or `null`. No animation — instant mount/unmount.

**Dismiss behavior:** The banner is persistent per-launch (NET-04 requirement). No dismiss/close button. It reappears on every app launch when in local mode. Do not add a "don't show again" checkbox — that is out of scope for this phase.

**Content elements:**
- Warning icon: `⚠` character (U+26A0), color `#f59e0b`, font-size 14px
- Message text: "Local network mode active — your sessions are accessible on your LAN." color `#a9b1d6`, font-size 13px
- Secondary text: "Install Tailscale for end-to-end encrypted remote access." color `#565f89`, font-size 12px
- CTA button: "Install Tailscale" — accent button style (background `#7aa2f7`, color `#1a1b26`, border-radius 4px, padding 4px 12px, font-size 12px, font-weight 600)
- CTA action: calls `BrowserOpenURL('https://tailscale.com/download')` via Wails runtime

**Accessibility:** `role="status"` on banner container. CTA button has `aria-label="Install Tailscale — opens tailscale.com in browser"`.

### 2. Settings Tab — Password Display Field (NET-05)

**Location:** Inside `SettingsTab.tsx`, within the Web Server section (`activeTab === 'web-server'`).

**Visibility rule:** Rendered only when `isServerRunning === true AND webServerMode === 'local'`. Hidden in Tailscale mode (password is not applicable).

**Layout:** Appended after the existing server URL row, before any stop/start buttons. Full-width within the web-server settings section.

**CSS class:** `.settings-web-server__password`

**Visual style:**
```css
/* Label above the field */
.settings-web-server__password-label {
  font-size: 12px;
  color: #565f89;
  margin-bottom: 4px;
}

/* Read-only input field */
.settings-web-server__password-field {
  display: flex;
  align-items: center;
  gap: 8px;
  background: #1e2030;
  border: 1px solid #292e42;
  border-radius: 4px;
  padding: 6px 10px;
  font-size: 13px;
  color: #c0caf5;
  font-family: inherit;
  letter-spacing: 0.05em;
  width: 100%;
  cursor: default;
  user-select: text;
}
```

**Content:**
- Label: "LAN Access Password"
- Field value: the password string (22-character base64url) rendered as readable text
- Copy hint: Small "(click to copy)" text at 11px in color `#414868`, displayed inline after the password value
- On click: copies password to clipboard; shows a brief "Copied!" confirmation for 1.5 seconds in same spot, color `#9ece6a`

**Password masking:** Password is shown unmasked. This is a local-only app (Wails desktop); no masking is needed or desired. The user needs to type this password into a browser.

**Mode indicator:** Immediately above the password field, a single-line mode indicator: "Web server mode: Local network (self-signed TLS)" — font-size 12px, color `#a9b1d6`. This replaces no existing element; it is a new row.

## Interaction States

### LocalNetworkBanner

| State | Trigger | Visual |
|-------|---------|--------|
| Hidden | `webServerMode !== 'local'` | Component not rendered |
| Visible | `webServerMode === 'local'` | Full banner rendered, no animation |
| CTA hover | Mouse over "Install Tailscale" button | `background-color: #89b4fa` (matches existing button hover pattern) |
| CTA active | Click | `BrowserOpenURL` fires; no loading state needed |

### Password Field

| State | Trigger | Visual |
|-------|---------|--------|
| Default | Rendered | Password visible, "(click to copy)" hint shown |
| Copied | Click anywhere on field | "(click to copy)" replaced by "Copied!" in #9ece6a for 1500ms, then reverts |
| Loading | `GetLocalNetworkPassword()` in flight | Field shows "Loading…" in color `#565f89` |
| Error | `GetLocalNetworkPassword()` rejects | Field shows error copy in `#f7768e` |

## App.tsx State Additions

Phase 60 requires two new state variables in `App.tsx`:

| State variable | Type | Initial value | Purpose |
|---------------|------|---------------|---------|
| `webServerMode` | `'tailscale' \| 'local' \| null` | `null` | Controls banner visibility and settings password section visibility |

The `webServerMode` state is populated from `GetWebServerStatus()` response (which gains a `Mode` field in this phase). It is refreshed on the same polling interval as `webServerRunning`.
