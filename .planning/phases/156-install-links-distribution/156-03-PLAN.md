| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-156-08 | Repudiation | continue-on-error masks submit failures after acceptance | medium | mitigate | Runbook + M-26 require removing `continue-on-error: true` from the submit-winget job post-acceptance so future submission failures surface instead of silently passing |
| T-156-09 | Tampering | Dry-run validates wrong/garbage manifest values | low | mitigate | dry-run-first-submission.sh asserts PackageIdentifier `scottkw.agenthub` and the windows installer URL in generated output, and parses every manifest with yaml.safe_load before reporting PASS |
