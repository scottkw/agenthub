# Phase 17 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Character: No New UI

Phase 17 is a pure deletion phase. No new components are introduced, no existing visual layouts change, and no user-facing interactions are added or modified. All frontend work is limited to removing dead TypeScript binding exports from Wails-generated files and cleaning a mock entry in a test file.

**Consequence for this spec:** All design contract values are inherited from the established codebase. The executor must not introduce any new styles, components, or layouts. This spec functions as a "do not deviate" contract — confirming existing tokens rather than prescribing new ones.

## Color

Palette is TokyoNight Dark (established across all prior phases).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #1a1b26 | App background, terminal container, active tab |
| Secondary (30%) | #16161e | Tab bar, status bar, settings panel tabs, input backgrounds |
| Accent (10%) | #7aa2f7 | Active tab border, active tab indicator, links, focused input borders, primary action buttons, active state borders |

Accent reserved for: active tab bottom border, active settings tab bottom border, focused input border-color, primary CTA button background (Save Paths, I Understand, Start Web Server), URL link color, active server running state

- #565f89 — muted text, inactive icons, placeholder content
- #a9b1d6 — secondary text, non-active interactive labels
- #292e42 — border color for panels, dividers, and table rows
- #1e2030 — card/modal surface (settings panel, new session modal, context menu)
- #3b4261 — hover surface for destructive/close areas
