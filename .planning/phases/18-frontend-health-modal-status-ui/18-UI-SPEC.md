## Interaction Contract

### HealthModal — Three-State Logic

| Priority | Condition | Panel shown | Interactive elements |
|----------|-----------|-------------|---------------------|
| 1 (highest) | `!health.installed` | NotInstalledPanel | None — informational only |
| 2 | `health.installed && !health.connected` | NotConnectedPanel | None — informational only |
| 3 (lowest) | `health.installed && health.connected && !health.hasCerts` | NoCertsPanel | "Check Again" button |
| — | `health === null` | No modal (loading) | — |
| — | All flags true | No modal | — |

Only one panel is visible at a time. Priority is determined by the order above — not-installed takes precedence over not-connected, which takes precedence over no-certs.

### "Check Again" Button

- Label: "Check Again"
- Visible only in NoCertsPanel
- On click: calls `GetTailscaleStatus()` directly via `onCheckAgain` prop (App.tsx handler), updates `tailscaleHealth` state immediately without waiting for next 10s poll
- Loading state: button shows "Checking…" during the async call; re-enabled on completion
- Disabled state: disabled while the check is in-flight

### `tailscale:health` Event

The modal auto-dismisses when the backend emits a `tailscale:health` event with all flags true. No user action needed — this is the primary resolution path.

### TailscaleStatusIndicator

- Read-only at all times
- Reflects current `tailscaleHealth` prop value from App.tsx state
- Three states: "Connected" (ok dot), "Not Connected" (warn dot), "Not Installed" (error dot)
- When `tailscaleHealth === null` (loading): show "Checking…" with no dot, color `#565f89`
