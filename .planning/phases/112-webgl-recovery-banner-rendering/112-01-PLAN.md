<objective>
Fix GitHub Issue #55: WebGL recovery banner does not render when the terminal's WebGL context is lost. Root cause (per 112-RESEARCH.md) is **call ordering** inside `TerminalPanel.tsx:391-395` — `webglAddon.dispose()` tears down the xterm emitter chain mid-fire and aborts the continuation that would call `onWebGLContextLost?.('context-loss')`. The closure-rot hypothesis in 112-CONTEXT.md is REFUTED by RESEARCH §1 (React `useState` setters are identity-stable). The fix is a 5-line reorder + microtask-deferred dispose, local to one block.

Purpose: Restore the Phase 93 user-visible recovery flow on both desktop (Wails) and web surfaces. Patch release — surgical scope.
Output: Reordered handler, RED-first behavioral + source-inspection tests, cross-surface UAT verification scaffold. UI-01 + UI-02 satisfied.
