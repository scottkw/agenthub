## Interaction Contract

### Sidebar Toggle (SIDE-02)

| State | Width | Content |
|-------|-------|---------|
| Expanded (default) | 200px | `Bars3Icon` toggle + nav item icons + text labels |
| Collapsed | 48px | `Bars3Icon` toggle + nav item icons only (labels hidden) |

- Toggle button: `Bars3Icon` 20px, 38px touch target, top of sidebar
- Transition: `width 0.15s ease` on `.sidebar`
- Label visibility: conditional render `{!collapsed && <span className="sidebar__label">...</span>}` — do NOT use `display: none` (breaks transitions if labels contribute to width)
- Collapsed state stored as string `'true'`/`'false'` in `localStorage` key `sidebar-collapsed`
- Initial state: lazy `useState(() => localStorage.getItem('sidebar-collapsed') === 'true')` — defaults to `false` (expanded) when key absent

### Sidebar Item Hover

- Background: `#1e2030`
- Icon color: `#c0caf5`
- Label color: `#c0caf5`
- Transition: `background-color 0.1s, color 0.1s` (matches existing `.tab-bar__btn` transition)

### Terminal Refit on Toggle

- After sidebar width transition completes, the FitAddon ResizeObserver should fire automatically because the terminal container width changes
- If it does not fire (Wails WebView edge case): add `window.dispatchEvent(new Event('resize'))` in the toggle handler as fallback
- Sidebar component exposes an optional `onToggle` callback so App.tsx can react if needed
