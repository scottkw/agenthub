## Interaction Contract

### Paths Section — Unified Table

**Before (broken):** Two separate `<table>` elements. Column widths calculated independently.
Column 1 header: "CLI" (table 1), "Tool" (table 2) — misaligned.

**After (correct):**
- Single `<table className="settings-panel__table">` with one `<thead>`
- Header row: `<th>CLI</th>` | `<th>Path</th>` — applies to ALL rows including tailscale
- Column 1 width set by the widest cell in the entire table (browser auto-layout)
- CLI path inputs and tailscale path input all flush in the same column

**Tailscale row conditional:**
- Render tailscale row when `!clis.find(c => c.Name === 'tailscale')`
- Tailscale row uses `.settings-panel__cli-name` class for the name cell (same as CLI rows)
- No `style={{ marginTop: '0.75rem' }}` on the merged table

### Inline Style Removal

Remove inline `style={{ marginTop: '0.25rem', fontSize: '0.8rem' }}` from Tailscale status `<p>`:
- `marginTop: '0.25rem'` — remove; let standard field-group spacing apply
- `fontSize: '0.8rem'` — remove; let `.settings-panel__description` (12px) apply

### Section Headers

No changes required. `.settings-panel__body h3` is already a single consistent rule across all four sections (Behavior, Appearance, Web Server, Paths). The `h3:first-child` override (no top border/margin for Behavior) is correct and must not be changed.

### Scroll Behavior

Settings body is already scrollable (`overflow-y: auto`). No scroll behavior changes in this phase.
