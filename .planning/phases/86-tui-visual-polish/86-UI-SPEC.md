# Phase 86 — UI Design Contract: TUI Visual Polish

> Visual and interaction contract for Phase 86. Generated by gsd-ui-researcher.
> This is a terminal UI (TUI) phase — all design tokens are terminal color values
> (ANSI/hex), not CSS. The "design system" is lipgloss + Bubble Tea v2, not shadcn.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (lipgloss + Bubble Tea v2) |
| Preset | not applicable — terminal UI |
| Component library | `charm.land/lipgloss/v2`, `charm.land/bubbletea/v2`, `charm.land/bubbles/v2` |
| Icon library | Unicode box-drawing + block glyphs (no external icon library) |
| Font | Terminal default (monospace); no font injection |

## Spacing Scale

TUI spacing is measured in terminal cell columns/rows, not pixels.
The following table maps pixel-scale intent to character-cell equivalents.

| Token | Cell Value | Usage |
|-------|-----------|-------|
| xs | 1 char | Icon gap, inline glyph padding |
| sm | 2 chars | Cursor column, status glyph column |
| md | 4 chars | Frame inner padding (lipgloss `Padding(0, 2)`) |
| lg | 8 chars | Sidebar width floor |
| xl | 16 chars | Min sidebar expanded width |
| 2xl | 20 chars | HOST column width |

Exceptions:
- Sidebar width (character count) is left to executor discretion per CONTEXT.md
- Column widths are computed from terminal width: `nameColWidth = width - 53` (existing formula, keep)
- Minimum terminal size enforced at 60 columns × 10 rows (from existing view.go)

## Typography

TUI typography is expressed as lipgloss style attributes on monospace cells.

| Role | Weight | Style | Usage |
|------|--------|-------|-------|
| Body | normal (400) | `lipgloss.NewStyle().Foreground(FgNormal)` | Session names, values |
| Label | bold | `lipgloss.NewStyle().Bold(true).Foreground(FgMuted)` | Column headers, section titles |
| Heading | bold | `lipgloss.NewStyle().Bold(true).Foreground(FgNormal)` | App title, tab bar active |
| Muted | normal | `lipgloss.NewStyle().Foreground(FgMuted)` | Hints, placeholders, dividers |

Line height: 1 row per line (terminal standard; no multi-line rows).

Source: Existing patterns from view.go renderHeader(), renderColumnHeaders(), renderHintBar()

### Color Role Distribution (60/30/10 mapping to terminal cells)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `BgSurface` `#1a1b26` | Main content area background (terminal surface) |
| Secondary (30%) | `BgSidebar` `#16161e` | Sidebar pane, modal overlay, frame interiors |
| Accent (10%) | `FgAccent` `#7aa2f7` | Active tab indicator, focused pane border, divider labels, active sidebar item, border titles only |
| Destructive | `FgDanger` `#f7768e` | Kill confirm modal text and border — no other usage |

Accent reserved for: active tab underline/highlight, focused pane lipgloss border, `injectBorderTitle` frame labels, active sidebar highlight, divider labels.
Accent is NOT used for: normal text, inactive borders, body content, placeholder text.

## Layout Contract

### Overall Screen Structure

```
┌─────────────────────────────────────────────────────┐
│ [Sidebar 16ch] │ [Tab Bar                          ] │
│                │ ─────────────────────────────────── │
│  Home          │ [Content Pane — active tab]          │
│  Sessions      │                                      │
│  Remote        │                                      │
│  Settings      │                                      │
│                │                                      │
│                ├─────────────────────────────────────┤
│                │ [Footer: Web status | hints       ] │
└─────────────────────────────────────────────────────┘
```

- Sidebar: fixed left pane, 16 chars wide (expanded), 3 chars wide (collapsed or min-terminal mode)
- Tab bar: horizontal row above content; one line tall
- Content pane: remaining width × (height - tab bar - footer)
- Footer: 2 lines (web status + hint bar), spans full width below content

### Sidebar Pane

- Background: `BgSidebar`
- Items: 4 entries — Home, Sessions, Remote, Settings
- Active/focused sidebar item: `FgAccent` foreground + `BgSelected` background
- Inactive items: `FgNormal` foreground, no background
- Vertical separator between sidebar and content: `BorderNormal` single `│` char
- Focus indicator when sidebar has focus: `BorderAccent` colored left `│` on active item
- Source: CONTEXT.md D-01, D-02, D-03

### Tab Bar

- Position: top of content area, one line
- Active tab: bold + `FgAccent` foreground, underline character (─) below tab name
- Inactive tabs: `FgMuted` foreground, no decoration
- Tab separator: single space between tab names
- Format: `  Home  Sessions  Remote  Settings  ` with active tab in `FgAccent` bold
- Cycle with `[` / `]` keys (CONTEXT.md D-05)
- Source: CONTEXT.md D-04, specifics section

### Session List Frame (TUI-01, CONTEXT.md D-08)

- Outer border: `lipgloss.RoundedBorder()`, color `BorderNormal` when inactive, `BorderAccent` when content pane has focus
- Border title: section name injected via `injectBorderTitle()` in `FgAccent` bold
- Column headers row: bold `FgMuted`, first row inside frame, followed by thin `─` separator line in `BorderNormal`
- Local/remote group divider: thin `─` rule in `BorderNormal`, with `FgAccent` remote label (reuse renderDividerRow pattern)
- Source: CONTEXT.md D-08, D-09, D-10

### Session Row Layout (TUI-03, CONTEXT.md D-11)

Column order (same as current, enhanced):

```
> ● [claude]  session-name    macbook-pro          2 viewers
  ↑ ↑ ↑       ↑               ↑                    ↑
  │ │ badge   name (flex)     host (20ch)          viewers (7ch)
  │ glyph (2ch)
  cursor (2ch)
```

- Badge: `[agent]` tag, 10 chars wide, colored per per-agent badge table above
- Badge replaces the plain `agent` text column (existing 12-char agent column becomes badge column)
- Status glyph: bold weight + color per `StatusRunning/Idle/Waiting/Errored`
- Selected row: `BgSelected` background, `FgSelected` foreground, full-width fill
- Cursor: `> ` when selected, `  ` otherwise (existing pattern, keep)

### Home Tab Content (CONTEXT.md D-13, D-14)

Line-by-line layout:

```
  AgentHub  v{version}
  AI coding terminal sessions
  ────────────────────────────────
  Sessions  {N} running  {N} idle
  Web       ● Running — {URL}   (or ○ Stopped)
  Tailscale ● Connected — {host}  (or ✗ not detected)
  ────────────────────────────────
  n new session   Enter attach   q QR   ? help
```

- Title "AgentHub": bold `FgNormal`
- Version: `FgMuted` same line, right-aligned
- Tagline: `FgMuted` (source: CONTEXT.md specifics — "AI coding terminal sessions")
- Separator: `─` chars in `BorderNormal`
- Stat labels: `FgMuted`
- Stat values: `FgNormal`
- Status glyphs: use same `StatusRunning` / `StatusErrored` colors
- Quick-action hints: `FgAccent` key, `FgMuted` description

### Settings Tab Content (CONTEXT.md Claude's Discretion)

Read-only display of current settings. Format:

```
  Settings  (read-only — run 'agenthub settings' to edit)
  ────────────────────────────────
  Claude Path   /usr/bin/claude
  Web Port      8080
  Auto-close    enabled
  ...
```

- Label: `FgMuted`, Value: `FgNormal`
- Note line: `FgMuted` italic (using `lipgloss.NewStyle().Italic(true)`)

### Remote Tab Content (CONTEXT.md Claude's Discretion)

Reuse session list frame pattern with a `Remote Sessions` border title:
- Same bordered frame as Sessions tab
- Same column headers (NAME, AGENT, HOST) — no VIEWERS column for remote rows
- Remote-only: no `n` new session hint; replace with `r` QR access hint

## Interaction Contract

### Focus Model (CONTEXT.md D-03)

Two focus states: **sidebar focused** vs **content pane focused**.

| State | Visual Indicator |
|-------|-----------------|
| Sidebar focused | `BorderAccent` highlight on active sidebar item left edge |
| Content focused | Frame border switches from `BorderNormal` to `BorderAccent` |

`Tab` toggles focus between sidebar and content pane.

### Keyboard Navigation

| Key | Action | Scope |
|-----|--------|-------|
| `Tab` | Toggle sidebar/content focus | Global |
| `↑` / `k` | Move up | Sidebar items (when sidebar focused), session rows (when content focused) |
| `↓` / `j` | Move down | Sidebar items (when sidebar focused), session rows (when content focused) |
| `Enter` | Select sidebar section / attach to session | Context-sensitive |
| `[` | Previous open tab | Global |
| `]` | Next open tab | Global |
| `n` | New session | Sessions tab |
| `d` | Kill session (with confirm) | Sessions tab |
| `r` | Rename session | Sessions tab |
| `q` | QR code overlay | Sessions/Remote tab |
| `R` | Refresh list | Sessions/Remote tab |
| `?` | Toggle help overlay | Global |
| `Q` / `Ctrl-C` | Quit | Global |

Source: CONTEXT.md D-02, D-03, D-05, keys.go (existing bindings preserved)

### Attach/Detach (CONTEXT.md D-06)

- Attaching to a session: `tea.Exec` full-screen PTY (existing `attachCmd`, unchanged)
- On return from attach: restore exact tab and cursor position that was active before attach
- Visual feedback on attach: no interstitial screen — instant `tea.Exec` handoff
- On detach (`Ctrl-\`): restore TUI with sidebar state and active tab intact

### Modal Overlays (existing patterns preserved)

- New session modal: existing `renderNewSessionModal()` — no visual changes
- Kill confirm modal: existing `renderKillConfirmModal()` — no visual changes
- QR overlay: existing `renderQROverlay()` — no visual changes
- Help overlay: existing `renderHelpOverlay()` — update keybinding list to include `Tab`, `[`, `]`
