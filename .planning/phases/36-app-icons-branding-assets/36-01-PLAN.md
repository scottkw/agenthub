    This task creates the square logomark from the title logo, then generates all icon formats.

    **Step 1: Extract the "A" logomark from the title logo and create 1024x1024 appicon.png**

    The title logo (docs/agenthub-title-logo.png) is 805x208 with a grey background. The blue "A" logomark is on the left side of the image, roughly in the leftmost ~208px.

    Use ImageMagick to:
    1. Visually inspect the logo to find the exact "A" mark bounding box: `identify -verbose docs/agenthub-title-logo.png` and examine pixel content to find the mark boundaries
    2. Crop the "A" logomark region from the title logo (approximately 208x208 from the left, adjust based on visual inspection)
    3. Remove the grey background (the grey is approximately #dfe0e2) and make it transparent: use `-fuzz 15% -transparent '#dfe0e2'`
    4. Place the transparent logomark centered on a 1024x1024 canvas with a transparent (RGBA) background
    5. The logomark should have generous padding (roughly 15-20% on each side) so it looks good at small sizes

    Example command sequence:
    ```bash
    # Crop the "A" mark from left side (adjust coordinates after inspection)
    convert docs/agenthub-title-logo.png -crop 208x208+0+0 +repage /tmp/mark_raw.png

    # Remove grey background
    convert /tmp/mark_raw.png -fuzz 15% -transparent '#dfe0e2' /tmp/mark_transparent.png

    # Center on 1024x1024 transparent canvas with padding
    convert /tmp/mark_transparent.png -resize 700x700 -gravity center -background none -extent 1024x1024 build/appicon.png
    ```

    After generating, visually inspect `build/appicon.png` to confirm:
    - The "A" mark is clearly visible and centered
    - Background is transparent (or transparent RGBA)
    - No grey background remnants around the mark
    - The mark looks recognizable when viewed at thumbnail size

    If the crop/extraction doesn't produce a clean result (grey artifacts, partial mark), try alternative approaches:
    - Widen the crop region (e.g., 250x208 to capture the full mark with padding)
    - Increase fuzz factor for background removal
    - Use `-trim` to auto-detect mark boundaries before centering

    **Step 2: Generate macOS .iconset and compile to ICNS**

    Create the AppIcon.iconset directory with all 10 required entries (5 logical sizes x 2 densities):

    ```bash
    mkdir -p build/AppIcon.iconset

    sips -z 16   16   build/appicon.png --out build/AppIcon.iconset/icon_16x16.png
    sips -z 32   32   build/appicon.png --out build/AppIcon.iconset/icon_16x16@2x.png
    sips -z 32   32   build/appicon.png --out build/AppIcon.iconset/icon_32x32.png
    sips -z 64   64   build/appicon.png --out build/AppIcon.iconset/icon_32x32@2x.png
    sips -z 128  128  build/appicon.png --out build/AppIcon.iconset/icon_128x128.png
    sips -z 256  256  build/appicon.png --out build/AppIcon.iconset/icon_128x128@2x.png
    sips -z 256  256  build/appicon.png --out build/AppIcon.iconset/icon_256x256.png
    sips -z 512  512  build/appicon.png --out build/AppIcon.iconset/icon_256x256@2x.png
    sips -z 512  512  build/appicon.png --out build/AppIcon.iconset/icon_512x512.png
    sips -z 1024 1024 build/appicon.png --out build/AppIcon.iconset/icon_512x512@2x.png

    iconutil -c icns build/AppIcon.iconset -o build/darwin/iconfile.icns
    ```

    The output file MUST be named `iconfile.icns` (matching CFBundleIconFile="iconfile" in Info.plist).

    **Step 3: Generate Windows ICO with ImageMagick**

    Delete the old placeholder ICO and create a new multi-frame ICO:

    ```bash
    rm build/windows/icon.ico

    convert build/appicon.png \
      \( -clone 0 -resize 16x16 \) \
      \( -clone 0 -resize 32x32 \) \
      \( -clone 0 -resize 48x48 \) \
      \( -clone 0 -resize 64x64 \) \
      \( -clone 0 -resize 128x128 \) \
      \( -clone 0 -resize 256x256 \) \
      -delete 0 build/windows/icon.ico
    ```

    **Step 4: Generate Linux PNGs**

    ```bash
    mkdir -p build/linux
    for size in 16 32 48 128 256 512; do
      sips -z $size $size build/appicon.png --out build/linux/${size}x${size}.png
    done
    ```

    **Step 6: Create verification script**

    Create `scripts/verify-icons.sh` with the following exact content:

    ```bash
    #!/usr/bin/env bash
    set -e

    PASS=0
    FAIL=0
    ERRORS=""

    check() {
      local desc="$1"
      shift
      if eval "$@" >/dev/null 2>&1; then
        echo "  PASS: $desc"
        ((PASS++))
      else
        echo "  FAIL: $desc"
        ERRORS="$ERRORS\n  - $desc"
        ((FAIL++))
      fi
    }

    echo "=== AgentHub Icon Verification ==="
    echo ""

    # SC1: appicon.png is 1024x1024
    check "appicon.png is 1024x1024" \
      "identify build/appicon.png | grep -q '1024x1024'"

    # SC2: iconfile.icns exists and has content
    check "iconfile.icns exists" \
      "test -s build/darwin/iconfile.icns"

    # SC2: iconfile.icns has multiple entries (check file size > 100KB as proxy for 10 entries)
    check "iconfile.icns has substantial content (>100KB = multi-entry)" \
      "test $(stat -f%z build/darwin/iconfile.icns 2>/dev/null || stat -c%s build/darwin/iconfile.icns 2>/dev/null) -gt 100000"

    # SC3: icon.ico exists and has multiple frames
    check "icon.ico exists" \
      "test -s build/windows/icon.ico"

    check "icon.ico has >=4 frames" \
      "test $(identify build/windows/icon.ico 2>/dev/null | wc -l) -ge 4"

    # SC4: Linux PNGs
    for size in 16 32 48 128 256 512; do
      check "Linux ${size}x${size}.png exists" \
        "test -f build/linux/${size}x${size}.png"
    done

    # SC5: Title logo in frontend assets
    check "frontend title logo exists" \
      "test -f frontend/src/assets/agenthub-title-logo.png"

    # iconset folder has 10 entries
    check "AppIcon.iconset has 10 entries" \
      "test $(ls build/AppIcon.iconset/*.png 2>/dev/null | wc -l) -eq 10"

    echo ""
    echo "=== Results: $PASS passed, $FAIL failed ==="
    if [ $FAIL -gt 0 ]; then
      echo -e "Failures:$ERRORS"
      exit 1
    fi
    echo "All checks passed."
    ```

    ```bash
    cp build/darwin/iconfile.icns build/bin/agenthub.app/Contents/Resources/iconfile.icns
    ```

    The `touch` forces macOS to notice the bundle changed and reload the icon cache.

    **Step 3: Verify the bundle ICNS is the full version**

    Compare file sizes:
    ```bash
    ls -la build/darwin/iconfile.icns
    ls -la build/bin/agenthub.app/Contents/Resources/iconfile.icns
    ```

    Both should be the same size (the full 10-entry ICNS, > 100KB). If the bundle version is much smaller (~50KB), the copy failed.

    Also verify the bundle structure:
    ```bash
    ls -la build/bin/agenthub.app/Contents/Resources/
    ```

    Should show `iconfile.icns` matching our pre-built file.
