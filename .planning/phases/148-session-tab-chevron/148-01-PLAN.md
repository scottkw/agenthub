<objective>
Add a down-chevron affordance to each session tab in the AgentHub desktop GUI's `TabBar.tsx`, making the right-click-only context menu (Rename / Save Terminal As… / Browse files) discoverable via a visible left-click button. Fold in the light-theme fix for that menu by tokenizing its hardcoded dark colors. Register the new behavior in the regression suite.

Purpose: #68 — new users miss the tab context menu because right-click isn't self-advertising. A visible chevron advertises it. Since the chevron makes the menu materially more discoverable, its broken light-theme colors are fixed in the same pass (D-07, Success Criterion #3).

Output: A `tab__chevron` button (session tabs only) that opens the existing menu anchored below itself; a tokenized `.tab__context-menu` that renders correctly in light + dark; vitest coverage; TESTING.md registration.
</objective>
