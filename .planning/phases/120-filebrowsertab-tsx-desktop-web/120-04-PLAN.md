Race protection (Pitfall 3): capture path at request issue time; in `.then` ignore the result if `path !== currentPathAtRequestTime`. Use AbortController in cleanup. Error mapping:

    **Selection effect:** useEffect deps `[selected, entries]`. When selected changes to a file entry:
    1. setPreview({kind:'loading'})
    2. Call `client.headFile(sessionId, joinPath(path, selected))` first to learn size + contentType
    3. Decision:
       - HEAD fails 413 → setPreview({kind:'over-cap', filename:selected, humanSize:humanSize(size), downloadUrl: client.buildDownloadUrl(...)})
       - HEAD ok + size === 0 → setPreview({kind:'empty', filename:selected})
       - HEAD ok + contentType starts 'text/markdown' OR filename matches /\.(md|markdown)$/i → call readFileText then setPreview({kind:'markdown', text, size, mtime})
       - HEAD ok + contentType starts 'text/' (any other text) → call readFileText → setPreview({kind:'text', text, size, mtime})
       - HEAD ok + contentType starts 'image/' AND extension in {png,jpg,jpeg,webp,gif,svg} → setPreview({kind:'image', url: client.buildImageUrl(...), filename, size, mtime})
       - HEAD ok + everything else (binary) → setPreview({kind:'unsupported', filename, humanSize, downloadUrl: client.buildDownloadUrl(...)})
       - HEAD fails 403 → setPreview({kind:'forbidden-file', filename})
       - HEAD fails (network) → setPreview({kind:'read-error', filename, message:'network error', onRetry: () => setSelected(s => s)}) — retry triggers re-fetch via state churn

    **Document-level '/' filter activation:** useEffect mounted iff `isActive`:
    ```ts
    useEffect(() => {
      if (!isActive) return
      const onKey = (e: KeyboardEvent) => {
        if (e.target instanceof HTMLInputElement) return
        if (!tabRef.current?.contains(e.target as Node)) return
        if (e.key === '/') { e.preventDefault(); setFilterActive(true) }
        if ((e.key === 'r' || e.key === 'R') && !filterActive) { e.preventDefault(); refresh() }
      }
      document.addEventListener('keydown', onKey)
      return () => document.removeEventListener('keydown', onKey)
    }, [isActive, filterActive])
    ```
