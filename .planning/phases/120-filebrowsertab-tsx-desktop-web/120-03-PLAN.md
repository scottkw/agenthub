    2. Within {directories} and within {files}, apply the active sort key:
       - `name` — locale-independent comparison by `entry.name.localeCompare(b.name)` — case-INSENSITIVE first pass; tie-break case-sensitive
       - `size` — numeric compare; entries with size==0 (List endpoint default) compare equal; tie-break by name asc
       - `modified` — string compare on `entry.mtime` (RFC3339 strings sort correctly lexically); entries with mtime=="" compare oldest (sort to bottom on asc, top on desc); tie-break by name asc
    3. `sortDir === 'desc'` reverses the within-group ordering (but does NOT move directories below files).
    4. Returns a NEW array (no in-place mutation).
    `defaultSortDir(key: SortKey): SortDir` — name → 'asc'; size → 'desc'; modified → 'desc'. Used by FileListPane on first click of an inactive column header.

    2. directories sticky on name desc (dirs still on top)
    3. directories sticky on size asc (still on top even when "smallest file" sort would put a big dir below)
    4. files sort by size desc when sortKey=size, sortDir=desc
    5. files sort by name asc within group
    6. mtime=="" entries sink under asc, rise to top of group under desc
    7. case-insensitive name compare puts "Apple.txt" before "banana.txt"
    8. returns new array (input not mutated — `Object.is(input, output) === false`)
    9. defaultSortDir(name) === 'asc'
    10. defaultSortDir(size) === 'desc'
    11. defaultSortDir(modified) === 'desc'
