The user must perform these steps. This requires a Windows machine with winget CLI installed and access to the latest GitHub Release.

**Step A: Populate manifests using the helper script**
1. Download `checksums.txt` from the latest GitHub Release (e.g., https://github.com/scottkw/agenthub/releases/latest)
2. Determine the bare version (strip `v` prefix from the release tag, e.g., `v1.8.0` -> `1.8.0`)
3. Run the helper script from repo root:
   ```bash
   ./packaging/winget/populate-manifests.sh 1.8.0 /path/to/checksums.txt
   ```
4. Verify the output files in `packaging/winget/output/1.8.0/` have no `{{` placeholders remaining

**Step B: Validate manifests on Windows**
1. Copy the populated manifest files to a Windows machine
2. Place them at a local path (e.g., `C:\temp\manifests\`)
3. Run: `winget validate C:\temp\manifests\`
4. All three manifests must pass validation with no errors

**Step C: Submit PR to microsoft/winget-pkgs**
1. On Windows (or via GitHub web), sparse clone the scottkw/winget-pkgs fork:
   ```powershell
   git clone --filter=blob:none --no-checkout https://github.com/scottkw/winget-pkgs
   cd winget-pkgs
   git sparse-checkout set manifests\s\scottkw
   git checkout
   ```
2. Create a branch: `git checkout -b scottkw-agenthub-1.8.0`
3. Create directory: `mkdir -p manifests\s\scottkw\agenthub\1.8.0`
4. Copy the three populated manifest files into that directory
5. Commit: `git add . && git commit -m "Add scottkw.agenthub version 1.8.0"`
6. Push: `git push -u origin scottkw-agenthub-1.8.0`
7. Open PR from `scottkw/winget-pkgs:scottkw-agenthub-1.8.0` to `microsoft/winget-pkgs:master`
8. PR title: `Add scottkw.agenthub version 1.8.0`

**Step D: Wait for validation**
- Azure Pipeline automated validation runs (~30-40 min)
- A human moderator reviews (hours to ~1 day)
- The PR will get labels indicating status
- After merge, `winget install scottkw.agenthub` will work

NOTE: The PR merge is async — it does NOT block milestone completion. The code changes (Plan 01) are complete regardless.
