  <action>
Add a second job `submit-winget` to `.github/workflows/distribute.yml` that runs in parallel with the existing `update-homebrew-tap` job. The job uses the same `release:published` trigger already configured.

The new job must be:

```yaml
  submit-winget:
    runs-on: ubuntu-latest
    steps:
      - uses: vedantmgoyal9/winget-releaser@main
        with:
          identifier: scottkw.agenthub
          installers-regex: 'agenthub-v[\d.]+-windows-amd64-installer\.exe$'
          token: ${{ secrets.WINGET_TOKEN }}
```

Key details:
- `identifier` is `scottkw.agenthub` (matches PackageIdentifier in manifests exactly)
- `installers-regex` MUST use `agenthub-v[\d.]+-windows-amd64-installer\.exe$` to exclude the bare EXE artifact (`agenthub-v*-windows-amd64.exe`) — the default regex would match both
- `token` references `WINGET_TOKEN` secret (classic PAT with public_repo scope)
- No `fork-user` needed — defaults to repo owner `scottkw`
- Runs on `ubuntu-latest` — winget-releaser uses Komac which is cross-platform
- Job is independent of `update-homebrew-tap` — no `needs` dependency

  <action>
Create `packaging/winget/populate-manifests.sh` — a bash script that takes a version string and checksums.txt path, then produces populated manifest files ready for manual submission.

The script must:

1. Accept two arguments: VERSION (e.g., "1.8.0" — no v prefix) and CHECKSUMS_FILE path
2. Validate that both arguments are provided; exit 1 with usage message if not
3. Validate VERSION does not start with "v" — exit 1 with error if it does (Pitfall 3 from research)
4. Extract WINDOWS_SHA256 from the checksums file: `grep "agenthub-v${VERSION}-windows-amd64-installer.exe" "$CHECKSUMS_FILE" | awk '{print $1}'`
5. Validate SHA256 was found — exit 1 if empty
6. Create output directory: `output/${VERSION}/`
7. For each file in `packaging/winget/manifests/*.yaml`:
   - sed replace `{{VERSION}}` with `$VERSION`
   - sed replace `{{WINDOWS_SHA256}}` with `$WINDOWS_SHA256`
   - Write to `output/${VERSION}/$(basename $f)`
8. Print summary: version, SHA256, output directory, and reminder that files go to `manifests/s/scottkw/agenthub/${VERSION}/` in the winget-pkgs fork
9. Make the script executable (chmod +x)

Script header:
```bash
#!/usr/bin/env bash
set -euo pipefail
```

Add a .gitignore in `packaging/winget/` with content `output/` to prevent populated manifests from being committed.
