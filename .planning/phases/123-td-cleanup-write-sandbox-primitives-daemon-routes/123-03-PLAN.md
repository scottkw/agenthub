<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| in-process consumer to daemon Unix socket | auth-less loopback surface (WEB-01); request body, multipart filename, and path query are untrusted |
| HTTP handler to Sandbox | the handler must route every path through the sandbox (no direct os.* writes) |
| multipart upload to disk | FileHeader.Filename and body size are attacker-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-123-12 | Tampering | multipart FileHeader.Filename injection (../) | mitigate | filepath.Base then Sandbox.validateAndClean via WriteFileAtomic (Task 1); TestHandlerUpload_FilenameSanitized |
| T-123-13 | DoS | unbounded upload disk-fill | mitigate | http.MaxBytesReader(50 MiB) BEFORE ParseMultipartForm; 413 before bytes hit disk (Task 1); TestHandlerUpload_OverCap413 |
| T-123-14 | Elevation of Privilege | denylisted file write via HTTP route | mitigate | Sandbox denylist propagates to writeWriteError 403 "Protected system file" (Task 1); TestHandlerWrite_DenylistForbidden |
| T-123-15 | Spoofing / Tampering | wrong-verb route reaching a write handler | mitigate | method-prefixed mux returns 405 for the wrong verb (Task 1); TestFilesWriteRoutes_WrongVerb405 |
| T-123-16 | Information Disclosure | route exposed beyond loopback | accept | daemon socket is a local Unix socket / named pipe (WEB-01 precedent); webserver/CSRF gating is Phase 124, explicitly out of scope here |
| T-123-SC | Tampering | npm/pip/cargo installs | accept | no package-manager installs in this phase — stdlib only; RESEARCH Package Legitimacy Audit: N/A (zero external packages) |
