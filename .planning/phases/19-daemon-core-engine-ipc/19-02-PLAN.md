   - `webServer *webserver.WebServer`

2. **Change NewApp():**
   ```go
   func NewApp() *App {
       engine := daemon.NewSessionEngine()
       api := daemon.NewAPI(engine)
       server := relay.NewServer(engine.Manager(), engine.Backend())
       socketPath := daemon.DefaultSocketPath()

       return &App{
           engine:     engine,
           api:        api,
           server:     server,
           socketPath: socketPath,
       }
   }
   ```

3. **Change startup():**
   After the existing TCP listener allocation, start the daemon API:
   ```go
   if err := a.api.Start(a.socketPath); err != nil {
       panic(fmt.Sprintf("agenthub: daemon api: %v", err))
   }
   a.client = daemon.NewDaemonClient(a.socketPath)
   ```
   Keep existing: relay listener, initTray, startHealthPoller.

4. **Change shutdown():**
   Add daemon API stop after existing cleanup:
   ```go
   if a.api != nil {
       _ = a.api.Stop()
   }
   ```
   Change `a.manager.Shutdown()` to `a.engine.Manager().Shutdown()`.

5. **Migrate every Wails-bound method** to delegate through `a.client`:

   **CreateSession** — delegate to client, but also inject the Wails EventsEmit callback:
   ```go
   func (a *App) CreateSession(cli, name, workDir string) (string, error) {
       // Use engine directly for CreateSession because we need to pass the onStatus callback
       // that wraps runtime.EventsEmit. The HTTP API doesn't support callbacks.
       onStatus := func(sid string, s status.SessionStatus) {
           if a.ctx != nil && a.ctx.Value("frontend") != nil {
               runtime.EventsEmit(a.ctx, "session:status", map[string]string{
                   "sessionId": sid,
                   "status":    string(s),
               })
           }
       }
       return a.engine.CreateSession(a.ctx, cli, name, workDir, onStatus)
   }
   ```
   NOTE: CreateSession is the ONE method that calls engine directly (not through client) because the status callback cannot be serialized over HTTP. This is the recommended approach from 19-RESEARCH.md Open Question 1. All other methods go through the client.

   **ListSessions:**
   ```go
   func (a *App) ListSessions() []SessionInfo {
       sessions, err := a.client.ListSessions()
       if err != nil {
           return []SessionInfo{}
       }
       // Convert daemon.SessionInfo to main.SessionInfo
       result := make([]SessionInfo, len(sessions))
       for i, s := range sessions {
           result[i] = SessionInfo{ID: s.ID, CLI: s.CLI, Name: s.Name, State: s.State, CreatedAt: s.CreatedAt}
       }
       return result
   }
   ```

   **KillSession:**
   ```go
   func (a *App) KillSession(id string) error {
       err := a.client.KillSession(id)
       if err != nil {
           return err
       }
       // Emit the status event for the frontend (same as before)
       if a.ctx != nil && a.ctx.Value("frontend") != nil {
           runtime.EventsEmit(a.ctx, "session:status", map[string]string{
               "sessionId": id,
               "status":    string(status.StatusErrored),
           })
       }
       return nil
   }
   ```

   **RenameSession:** `return a.client.RenameSession(id, name)`

   **GetSessionStatus:**
   ```go
   func (a *App) GetSessionStatus(sessionID string) string {
       s, err := a.client.GetSessionStatus(sessionID)
       if err != nil {
           return string(status.StatusRunning) // conservative default
       }
       return s
   }
   ```

   **UpdateCLIPath:** `return a.client.UpdateCLIPath(name, path)`

   **resolveCLI:** `return a.engine.ResolveCLI(name)` (only called from CreateSession which uses engine directly)

   **DetectCLIs:** unchanged — static function, no state

   **GetRelayPort:** unchanged — uses a.listener (relay, not daemon)

   **StartWebServer:** change `a.manager` references to `a.engine.Manager()`. Change `a.tabNames`, `a.registry`, `a.sessionStatuses` references in SetSessionResolver to use engine methods:
   ```go
   ws.SetSessionResolver(func(id string) (string, string, string) {
       // Get session info from engine through client
       sessions, _ := a.client.ListSessions()
       var name, cliType string
       for _, s := range sessions {
           if s.ID == id {
               name = s.Name
               cliType = s.CLI
               break
           }
       }
       st, _ := a.client.GetSessionStatus(id)
       return name, cliType, st
   })
   ```

   **StopWebServer, ToggleWebServing, GetWebServerURL, IsWebServerRunning:** unchanged — these only access a.webServer behind a.mu, no session state.

   **GetSessionQRCode:** unchanged — only accesses a.webServer.

   **GetTailscaleStatus, HasCTDisclosure, AcknowledgeCTDisclosure, OpenDirectoryDialog, startHealthPoller, beforeClose:** unchanged — no session state accessed.

```go
func testApp(t *testing.T) *App {
    t.Helper()
    app := NewApp()
    app.ctx = context.Background()

    // Start daemon API on a temp socket
    socketPath := filepath.Join(t.TempDir(), "test.sock")
    app.socketPath = socketPath
    if err := app.api.Start(socketPath); err != nil {
        t.Fatalf("testApp: api.Start: %v", err)
    }
    app.client = daemon.NewDaemonClient(socketPath)
    // Brief sleep for server goroutine
    time.Sleep(10 * time.Millisecond)

    // Simulate the startup listener allocation
    ln, err := net.Listen("tcp", "127.0.0.1:0")
    if err != nil {
        t.Fatalf("testApp: net.Listen: %v", err)
    }
    app.listener = ln
    t.Cleanup(func() {
        ln.Close()
        app.engine.Manager().Shutdown()
        app.api.Stop()
    })
    return app
}
```
