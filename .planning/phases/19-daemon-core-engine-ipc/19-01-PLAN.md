**internal/daemon/api.go** — HTTP routes served over a Unix socket:
- `type API struct` with fields: `engine *SessionEngine`, `mux *http.ServeMux`, `ln net.Listener`
- `func NewAPI(engine *SessionEngine) *API` — creates mux, registers all routes using Go 1.22+ path parameters:
  ```
  GET    /health                       -> handleHealth
  GET    /sessions                     -> handleListSessions
  POST   /sessions                     -> handleCreateSession
  GET    /sessions/{id}                -> handleGetSession
  DELETE /sessions/{id}                -> handleDeleteSession
  PATCH  /sessions/{id}/name           -> handleRenameSession
  GET    /sessions/{id}/status         -> handleGetSessionStatus
  GET    /settings/cli-paths           -> handleGetCLIPaths
  PATCH  /settings/cli-paths/{name}    -> handleUpdateCLIPath
  ```
- `func (a *API) Start(socketPath string) error` — calls ValidateSocketPath, then CleanupStaleSocket, then creates parent dir with os.MkdirAll, then net.Listen("unix", socketPath), then `go http.Serve(a.ln, a.mux)`. Stores listener in a.ln.
- `func (a *API) Stop() error` — closes a.ln if not nil, removes socket file with os.Remove
- `func (a *API) Addr() net.Addr` — returns a.ln.Addr() for test inspection

Handler implementations:
- `handleHealth`: writes `{"status":"ok"}` with Content-Type application/json
- `handleListSessions`: calls `a.engine.ListSessions()`, json.Encode result
- `handleCreateSession`: decodes CreateRequest from body, calls `a.engine.CreateSession(r.Context(), req.CLI, req.Name, req.WorkDir, nil)` (nil onStatus for now — App provides callback in Plan 02), returns 201 with CreateResponse
- `handleGetSession`: extracts `r.PathValue("id")`, calls engine.ListSessions, finds matching ID. Returns 404 if not found.
- `handleDeleteSession`: extracts id, calls engine.KillSession, returns 204
- `handleRenameSession`: extracts id, decodes RenameRequest, calls engine.RenameSession, returns 204
- `handleGetSessionStatus`: extracts id, calls engine.GetSessionStatus, returns StatusResponse
- `handleGetCLIPaths`: calls engine.GetCLIPaths, returns map
- `handleUpdateCLIPath`: extracts name from `r.PathValue("name")`, decodes UpdateCLIPathRequest, calls engine.UpdateCLIPath(name, req.Path), returns 204

All error responses use `http.Error(w, message, code)` with JSON content type.
