<objective>
Fix the 6px horizontal icon shift when toggling the sidebar between collapsed (48px) and expanded (200px) states, closing GitHub issue #20.

Purpose: SBR-02 requires icons to stay in the same horizontal position in both sidebar states. The root cause (from 70-RESEARCH.md) is a mismatch: expanded icons center at 18px (8px padding + 10px half-icon) while collapsed icons center at 24px (flex-centered in 48px rail). The fix establishes a fixed 48px icon slot via `margin: 0 14px` on `.sidebar__icon`, producing a 24px center in both states.

Output: Updated style.css with stable icon positioning, extended Sidebar.test.tsx with CSS-contract assertions, all tests green.
</objective>
