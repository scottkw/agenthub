  <action>
Build and launch the application, then perform three visual verification tests corresponding to the Phase 71 success criteria from ROADMAP.md. Present the verification steps to the user and wait for their assessment.

What was built: OpenCode theming fix — managed tui.json forces OpenCode's "system" theme (ANSI palette colors), and OPENCODE_TUI_CONFIG env var is injected into OpenCode PTY sessions. This makes OpenCode respect the xterm.js theme selected in Settings, matching Claude Code / Codex / Gemini CLI behavior.

Verification steps to present to user:

**Test SC-1: Theme switch repaints active OpenCode session**
1. Launch AgentHub
2. Create a new OpenCode session (sidebar > New Session > OpenCode)
3. Wait for OpenCode to start and display colored UI elements
4. Go to Settings > Appearance
5. Switch to a visually distinct theme (e.g., from a dark theme to "Solarized Light" or "Dracula")
6. Return to the OpenCode session tab
7. VERIFY: The terminal colors have changed to match the newly selected theme
8. VERIFY: No session restart was needed — colors changed live

**Test SC-2: New OpenCode session starts with current theme**
1. With a non-default theme selected (e.g., "Dracula")
2. Create a new OpenCode session
3. VERIFY: The new session immediately displays with Dracula colors (not the default tokyonight palette)

**Test SC-3: Cross-agent visual consistency**
1. Select a distinctive theme (e.g., "Solarized Dark" or "Nord")
2. Open four sessions: Claude Code, Codex, Gemini CLI, OpenCode
3. VERIFY: All four terminal panels render with the same general color palette
4. Specifically: text foreground color, background color, and bright accent colors should be visually consistent across all four agents
5. NOTE: Minor differences in which ANSI colors each CLI uses are acceptable — the key is that the same palette is in effect (e.g., "red" means the same red in all four)

**Fallback checks (if SC-1 fails):**
- Check `~/.config/agenthub/opencode-tui.json` exists and contains `{"$schema":"https://opencode.ai/tui.json","theme":"system"}`
- Check daemon logs for any errors related to OPENCODE_TUI_CONFIG
- If OpenCode still shows hardcoded colors, assumption A1 may be wrong — report this
