<task type="auto">
  <name>Task 1: Create GitHub repo, mirror Gitea history, push module-path commit</name>
  <files></files>
  <read_first>.planning/phases/44-git-migration-to-github/44-RESEARCH.md</read_first>
  <action>
    Execute the following steps IN ORDER. Do not skip any step or reorder.

    1. Create the GitHub repository (public, no initial push):
       ```
       gh repo create scottkw/agenthub --public --description "Launch, manage, and share AI coding terminal sessions"
       ```
       If the repo already exists, skip this step.

    2. Mirror the full Gitea history via bare clone (MUST be done outside the working copy):
       ```
       rm -rf /tmp/agenthub-bare.git
       cd /tmp
       git clone --bare https://gitea.eightabyte.com/scottkw/agenthub.git agenthub-bare.git
       cd /tmp/agenthub-bare.git
       git push --mirror https://github.com/scottkw/agenthub.git
       ```
       IMPORTANT: The bare clone MUST be in /tmp, NOT inside /Users/ken/dev/agenthub.

    3. Push the module-path-rewrite commit from Plan 01 on top of the mirrored history:
       ```
       cd /Users/ken/dev/agenthub
       git remote add github https://github.com/scottkw/agenthub.git 2>/dev/null || true
       git push github main
       ```
       This adds the chore commit from Plan 01 as the new tip of main on GitHub.

    4. Verify the push by cloning into a temp directory:
       ```
       rm -rf /tmp/verify-agenthub-clone
       git clone https://github.com/scottkw/agenthub /tmp/verify-agenthub-clone
       ```

    5. Verify tags are present (must show v1.0 through v1.7):
       ```
       git -C /tmp/verify-agenthub-clone tag | sort -V
       ```

    6. Verify annotated tag objects are preserved:
       ```
       git -C /tmp/verify-agenthub-clone cat-file -t $(git -C /tmp/verify-agenthub-clone rev-parse v1.7)
       ```
       Output MUST be `tag` (not `commit`). If it says `commit`, the mirror push failed to preserve annotated tags.

    7. Verify the tip of main is the module-path-rewrite commit:
       ```
       git -C /tmp/verify-agenthub-clone log --oneline -1
       ```
       Must show the "chore: update Go module path" commit.

    8. Verify the cloned repo builds:
       ```
       cd /tmp/verify-agenthub-clone && go build ./...
       ```

    9. Update the local origin remote to point to GitHub:
       ```
       cd /Users/ken/dev/agenthub
       git remote set-url origin https://github.com/scottkw/agenthub.git
       ```

    10. Clean up temporary files:
        ```
        rm -rf /tmp/agenthub-bare.git /tmp/verify-agenthub-clone
        ```
  </action>
  <verify>
    <automated>git remote -v | grep origin | head -1 | grep "github.com/scottkw/agenthub"</automated>
  </verify>

    - The latest commit on GitHub main contains "update Go module path" in its message
