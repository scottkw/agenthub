<objective>
Phase 107 collapsed the GUI new-session modal to a single "Shell" row reading
the daemon-resolved binary from the GetShellPath() Wails binding. The TUI side
still iterates m.detectedShells and renders "Shell — system default" / "Shell
— bash" / "Shell — zsh" / ... — a release-blocking cross-surface inconsistency
surfaced during 101-UAT Test 3.

entry (cliKey="shell", displayLabel="Shell"); sortShellsForPicker is deleted;
the detectedShells field is removed from Model; pty.DiscoverShells() is no
longer called at TUI startup; and the three agent-picker tests are rewritten
to lock the new contract.

The CLI flag removal is the next plan (108-02). README + help-text updates are
108-03. Daemon resolution (engine.go:500-530, GetShellPath/SetShellPath) is
untouched — it already routes cli="shell" through shellPath from Phase 107.
</objective>

```go
func (m Model) agentEntries() []agentEntry {
    if len(m.detectedCLIs) == 0 && len(m.detectedShells) == 0 {
        return nil
    }
    entries := make([]agentEntry, 0, len(m.detectedCLIs)+len(m.detectedShells))
    for _, c := range m.detectedCLIs {
        entries = append(entries, agentEntry{cliKey: c.Name, displayLabel: c.DisplayName})
    }
    for _, sh := range sortShellsForPicker(m.detectedShells) {
        entries = append(entries, agentEntry{
            cliKey:       sh.Name,
            displayLabel: "Shell — " + sh.DisplayName,
        })
    }
    return entries
}
```
