## States and Interactions

### Version display states (VER-02)

| State | Display | When |
|-------|---------|------|
| Loading | `dev` (initial `useState` value) | During the brief async gap before `GetVersion()` resolves |
| Loaded | `v1.9.0` (or whatever ldflags injected) | After `GetVersion()` Promise resolves |
| Error fallback | `dev` | If `GetVersion()` rejects (catch handler) |

The version paragraph element `<p className="welcome-tab__version">{version}</p>` must not flash empty. Initial state `'dev'` ensures the element always has visible content.

### Menu bar states (MENU-01, MENU-02)

The menu bar is native macOS UI — no React state involved. It appears automatically when `options.App.Menu` is set. No loading or error states apply.

Keyboard shortcut appearance contract:

| Menu | Items | Shortcut |
|------|-------|----------|
| AgentHub (AppMenu) | About AgentHub, Services, Hide AgentHub, Hide Others, Quit AgentHub | OS-managed |
| File | New Session | Cmd+N |
| File | Close Tab | Cmd+W |
| Edit (EditMenu) | Undo, Cut, Copy, Paste, Select All | OS-managed |
| Window (WindowMenu) | Minimize, Zoom, etc. | OS-managed |
| Help | AgentHub on GitHub | none |

Menu item labels use title case. Separator between "New Session" and "Close Tab" in File menu.

## Implementation Notes for Executor

1. **No new CSS classes.** Only modify the existing `.welcome-tab__logo` rule. Do not add classes.

2. **Version loading state `'dev'` not `'...'`.** The RESEARCH.md example shows `'...'` as a loading state — use `'dev'` instead. In local dev, `GetVersion()` returns `"dev"` anyway, so the loading flash shows the same value as the resolved state in development. This avoids a visible "..." text in dev builds.

3. **Do not change the version paragraph element structure.** Only replace `v{VERSION}` with `{version}` (where `version` is the state variable). The `v` prefix in `v{VERSION}` becomes implicit in the injected string itself (e.g., `"v1.9.0"`) — remove the hardcoded `v` prefix from the JSX when switching to the bound method. The `GetVersion()` Go method should return the full `"v1.9.0"` string including the `v` prefix.

4. **Menu callbacks.** File menu item callbacks are `nil` for v1.9 — MENU-01 requires menu items to appear with conventional shortcuts, not that the shortcuts trigger tab actions. Help menu "AgentHub on GitHub" requires a `runtime.BrowserOpenURL` callback. Source: RESEARCH.md Open Questions.

5. **`border-radius: 8px` matches existing modal radius.** This value was confirmed consistent with `.modal-container` (line 265 of `style.css`). Do not use a different value.
