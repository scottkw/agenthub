func appMenu() *menu.Menu {
    m := menu.NewMenu()
    // 1. AppMenu MUST be first on macOS (STATE.md pitfall)
    m.Append(menu.AppMenu())
    // 2. File menu (custom — FileMenuRole is commented out in v2.10.2)

    fileMenu.AddSeparator()

    // 3. EditMenu — enables Cmd+C/V/X/Z via native NSMenu

    // 5. Help menu (custom — HelpSubMenuRole is commented out in v2.10.2)

    return m

4. In `main.go`, add the callback function for the Help menu GitHub link:
```go
func openGitHubCallback(_ *menu.CallbackData) {
    // runtime.BrowserOpenURL requires the app context; use a package-level ref
    // The menu callback fires from the main thread where the app context is available
}
```

IMPORTANT: The menu callback needs access to the Wails runtime context. Since `appMenu()` is called before `wails.Run()`, the runtime context is not yet available. There are two approaches:
- Store the `runtime.BrowserOpenURL` call in a closure that captures a context variable set during `OnStartup`
- Use a simpler approach: store a package-level `appCtx context.Context` set in `app.startup`, and reference it in the callback

Use the package-level approach. Add `var appCtx context.Context` at package level in `main.go`. In the `openGitHubCallback`:
```go
var appCtx context.Context

func openGitHubCallback(_ *menu.CallbackData) {
    if appCtx != nil {
        runtime.BrowserOpenURL(appCtx, "https://github.com/agenthub-dev/agenthub")
    }
}
```

Then in `app.go`, in the existing `startup` method, add `appCtx = ctx` at the beginning. Read `app.go` fully to find the exact `startup` method signature and add the assignment there.

1. In `build.sh`, modify `build_macos()`:
```bash
build_macos() {
  local VERSION="${BUILD_VERSION:-dev}"
  echo "==> Building macOS (darwin/universal) version=${VERSION}"
  "$WAILS" build -platform darwin/universal -clean \
    -ldflags "-X main.Version=${VERSION}" \
    -tags wailsassets
  echo "==> macOS build complete: build/bin/agenthub.app"

  if [[ "$SIGN" == "true" ]]; then
    sign_and_notarize "build/bin/agenthub.app"
  fi
}
```

2. In `build.sh`, modify `build_windows()`:
```bash
build_windows() {
  local MINGW_CC="x86_64-w64-mingw32-gcc"
  if ! command -v "$MINGW_CC" &>/dev/null; then
    echo "ERROR: $MINGW_CC not found. Install: brew install mingw-w64"
    exit 1
  fi

  local VERSION="${BUILD_VERSION:-dev}"
  echo "==> Building Windows (windows/amd64) version=${VERSION}"
  CC="$MINGW_CC" CGO_ENABLED=1 "$WAILS" build -platform windows/amd64 -clean \
    -ldflags "-X main.Version=${VERSION}"
  echo "==> Windows build complete: build/bin/agenthub.exe"
}
```
