## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| settings.json on disk → engine | Persisted state; a stale/old-schema file must migrate safely (fail-safe to write-disabled) |
| GUI per-session toggle → engine write map | Intent crosses here; only the owner can flip a session's write state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-124-06 | Elevation of Privilege | write-enable defaulting to true on migration | mitigate | `FilesWrite bool` (plain, zero-value false); migration test `TestSettingsMigration_FilesWriteDefaultsFalse` asserts false default. A v3 file with no key migrates to write-disabled (opt-in for all). |
| T-124-07 | Elevation of Privilege | per-session write leaking across sessions | mitigate | Per-session map keyed by sessionID under e.mu; `filesWriteEnabledFor(sid)` reads only that session's entry. Cap mint reads per-session, never a global. |
| T-124-08 | Spoofing | macOS $HOME symlink mismatch hiding the warning (CAP-06) | mitigate | EvalSymlinks($HOME) before comparing to the already-resolved GetSessionWorkDir — exact denylist normalization (sandbox.go:96). |
| T-124-09 | Tampering | reordering Claims struct fields when adding the bit | mitigate | Only append to the ownerPerms STRING before Sign; never touch the Claims struct field order (HMAC-load-bearing). Old tokens still verify; lacking the bit, they fail-safe to 403. |
