<objective>
Create the `.github/workflows/release.yml` workflow that triggers on `v*` tag pushes (from release-please) and builds multi-platform artifacts: macOS signed/notarized DMG, Windows NSIS installer + bare EXE, Linux amd64 tar.gz + deb. Create `.github/workflows/release.yml` with the following structure. The research provides a complete verified skeleton — implement it faithfully with these specifics:

**Workflow trigger:**
```yaml
name: Release
on:
  push:
    tags:
      - 'v*'
```

**Job 1: build-macos** (runs-on: macos-latest, environment: release)
- Declare all 7 macOS secrets as env vars: MACOS_CERTIFICATE, MACOS_CERTIFICATE_NAME, MACOS_CERTIFICATE_PWD, MACOS_CI_KEYCHAIN_PWD, MACOS_NOTARIZATION_APPLE_ID, MACOS_NOTARIZATION_PWD, MACOS_NOTARIZATION_TEAM_ID — all from `${{ secrets.MACOS_* }}`
- Step: checkout with `submodules: true`
- Step: wails-build-action with `build-name: agenthub`, `build-platform: darwin/universal` (no sign flag — manual signing below)
- Step: Import certificate — decode base64 .p12, create build.keychain, import with `-T /usr/bin/codesign`, call `security set-key-partition-list`
- Step: Sign .app — `codesign --deep --force --verbose --options runtime --timestamp --entitlements build/entitlements.plist --sign "$MACOS_CERTIFICATE_NAME" build/bin/agenthub.app`
- Step: Notarize .app — store credentials with `xcrun notarytool store-credentials "agenthub-notarize"`, zip with `ditto -c -k --keepParent` (NOT zip -r), submit with `--wait`, staple with `xcrun stapler staple`
- Step: Create DMG — `brew install create-dmg`, set `DMG_NAME="agenthub-${GITHUB_REF_NAME}-darwin-universal.dmg"`, run `create-dmg --volname "AgentHub" --codesign "$MACOS_CERTIFICATE_NAME" "${DMG_NAME}" build/bin/agenthub.app`, move to build/bin/
- Step: Cleanup (if: always()) — delete build.keychain, remove certificate.p12 and notarize zip
- Step: upload-artifact@v4 with name `macos-dmg`, path `build/bin/agenthub-*.dmg`, if-no-files-found: error

**Job 2: build-windows** (runs-on: windows-latest)
- Step: checkout with `submodules: true`
- Step: wails-build-action with `build-name: agenthub`, `build-platform: windows/amd64`, `build-webview2: embed`, `nsis: true`
- Step: Rename artifacts (shell: bash) — `VERSION="${GITHUB_REF_NAME}"`, rename `build/bin/agenthub-amd64-installer.exe` to `build/bin/agenthub-${VERSION}-windows-amd64-installer.exe`, rename `build/bin/agenthub.exe` to `build/bin/agenthub-${VERSION}-windows-amd64.exe`
- Step: upload-artifact@v4 with name `windows-artifacts`, path `build/bin/agenthub-*.exe`, if-no-files-found: error

**Job 3: build-linux** (runs-on: ubuntu-latest)
- Step: checkout with `submodules: true`
- Step: Install deps — `sudo apt-get update && sudo apt-get install -y build-essential pkg-config libgtk-3-dev libwebkit2gtk-4.1-dev`
- Step: wails-build-action with `build-name: agenthub`, `build-platform: linux/amd64`, `build-flags: -tags webkit2_41` (CRITICAL: must match build.yml webkit tag)
- Step: Package — create tar.gz: `tar -czf "build/bin/agenthub-${GITHUB_REF_NAME}-linux-amd64.tar.gz" -C build/bin agenthub`
- Step: Create .deb — `go install github.com/goreleaser/nfpm/v2/cmd/nfpm@latest`, write nfpm.yaml with `version: "${GITHUB_REF_NAME#v}"` (strip leading v — Pitfall 4), contents mapping `build/bin/agenthub` to `/usr/bin/agenthub`, package with `--packager deb --target "build/bin/agenthub-${GITHUB_REF_NAME}-linux-amd64.deb"`
- Step: upload-artifact@v4 with name `linux-artifacts`, path pattern matching both .tar.gz and .deb, if-no-files-found: error

**Job 4: publish** (needs: [build-macos, build-windows, build-linux], runs-on: ubuntu-latest)
- Declare `permissions: contents: write`
- Step: download-artifact@v4 with `path: artifacts`, `merge-multiple: true`
- Step: Generate checksums — `cd artifacts && sha256sum * > checksums.txt && cat checksums.txt`
- Step: softprops/action-gh-release@v2 with files glob matching `artifacts/*.dmg`, `artifacts/*.exe`, `artifacts/*.tar.gz`, `artifacts/*.deb`, `artifacts/checksums.txt` — set `fail_on_unmatched_files: true`

**Naming convention (all artifacts):**
- macOS: `agenthub-v1.8.0-darwin-universal.dmg`
- Windows installer: `agenthub-v1.8.0-windows-amd64-installer.exe`
- Windows EXE: `agenthub-v1.8.0-windows-amd64.exe`
- Linux tar.gz: `agenthub-v1.8.0-linux-amd64.tar.gz`
- Linux deb: `agenthub-v1.8.0-linux-amd64.deb`
- Checksums: `checksums.txt`
