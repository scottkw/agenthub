From internal/relay/protocol.go (constants for framing client):
```
MsgOutput  = 0x01  // server -> client: PTY output
MsgResize  = 0x02  // server -> client: resize notification
MsgInput   = 0x10  // client -> server: keyboard input
MsgResize2 = 0x11  // client -> server: resize request
MsgPing    = 0x12  // client -> server: keep-alive
```

    - Test parseServerFrame: parseServerFrame with [0x01, ...data] returns {type: 'output', payload: data}

  <action>
    1. Create `frontend/src/lib/relayClient.ts` with:

       Constants matching protocol.go:
       ```typescript
       export const MSG_OUTPUT  = 0x01
       export const MSG_RESIZE  = 0x02
       export const MSG_INPUT   = 0x10
       export const MSG_RESIZE2 = 0x11
       export const MSG_PING    = 0x12
       ```

       Pure functions (testable without WebSocket):
       - `encodeInputFrame(text: string): Uint8Array` — prepends MSG_INPUT byte to UTF-8 encoded text
       - `encodeResizeFrame(cols: number, rows: number): Uint8Array` — 5-byte frame [MSG_RESIZE2, cols_hi, cols_lo, rows_hi, rows_lo]
       - `parseServerFrame(data: Uint8Array): ServerFrame` — parses type byte, returns typed union:
         `{ type: 'output', payload: Uint8Array } | { type: 'resize', cols: number, rows: number } | { type: 'unknown' }`

       `RelayClient` class:
       - Constructor: `(port: number, sessionId: string, callbacks: { onOutput: (data: Uint8Array) => void, onOpen?: () => void, onClose?: () => void })`
       - Creates WebSocket to `ws://127.0.0.1:${port}/sessions/${sessionId}/ws` with binaryType='arraybuffer'
       - `ws.onmessage` parses frame via parseServerFrame; calls callbacks.onOutput for output frames
       - `sendInput(text: string)` — sends encodeInputFrame result
       - `sendResize(cols: number, rows: number)` — sends encodeResizeFrame result
       - `close()` — closes WebSocket
       - Keep-alive: setInterval sending MSG_PING every 30s; clear on close

    2. Create `frontend/src/lib/relayClient.test.ts` with vitest tests for the pure functions (encodeInputFrame, encodeResizeFrame, parseServerFrame). These tests do NOT require a WebSocket — they test framing logic only.
