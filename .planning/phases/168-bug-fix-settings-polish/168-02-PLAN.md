<objective>
FIX-01 (#112): restore live plugin-config + SSE hot-swap for web-share guests on the /app/
surface, lost after the Phase 159 /sessions/{id} → /app/ redirect.

Purpose: The backend already ships capability-gated /api/plugin-config and its SSE stream;
the gap is purely client-side — WebShareSessionView only ever received pluginConfig as a
Wails prop and never self-fetched (D-16). This plan adds the client self-fetch + EventSource,
and — critically — introduces the baseURL prop seam so plan 03 (FIX-03) can point the same
component at a remote peer's origin rather than window.location.
Output: A parameterized WebShareSessionView that self-fetches plugin-config for web guests,
plus a vitest suite mocking fetch + EventSource.
</objective>
