<objective>
Close the single diagnosed UAT gap in Phase 168: the footer StatusBar pill drifts to "WEB OFF" while a session is actively web-shared, once the user has dismissed the one-time shell-web-share warning banner.

Root cause (confirmed, 168-UAT.md Gap): the footer pill reads App-level `webEnabled[sessionId]` (App.tsx:1925). After 168-05 the modal is the single toggle surface, but the modal's normal "Share the session" toggle (`SessionShareModal.handleShareToggle`, lines 222-244) only updates its own local `shareEnabled` — it never notifies App. `webEnabled[sessionId]` is set true ONLY by the mount/reconnect seed effects (App.tsx:598-609, 1495-1504) and by the one-time warning-confirm path `handleShellWebShareConfirm` (App.tsx:968). So once `shellWebShareWarned` is persisted true, every subsequent modal toggle falls through the warning guard (SessionShareModal.tsx:229→234) and leaves `webEnabled[sessionId]` stale-false → pill stuck on "WEB OFF" despite a live share.

Fix (Option A — callback, chosen over Option B — poll reconciliation): add an `onShareEnabledChange(sessionId, enabled)` callback prop to SessionShareModal, invoked from `handleShareToggle` on BOTH the ON and OFF transitions, wired in App.tsx to `setWebEnabled`. Because after 168-05 the single `<SessionShareModal>` instance is the only surface that calls `ToggleWebServing`, this one wiring point covers every toggle path (footer-opened + Hub-card-opened, warned + un-warned) with minimal surface area and makes `webEnabled` track server truth the instant the toggle succeeds. Option B was rejected as the sole fix: the CR-02 poll (App.tsx:1049-1070) only runs while the modal is open from a non-Hub tab, so it cannot cover the Hub-card-open case, and it would race the immediate callback.

Purpose: fully deliver the UX-02/#115 "state can no longer drift" goal that 168-05 left one record short of.
Output: onShareEnabledChange prop + App wiring; a mounted-modal regression test proving the warned-path ON→"WEB ON"/OFF→"WEB OFF" chain; App source-inspection wiring test; TESTING.md updates.
</objective>
