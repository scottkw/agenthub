<objective>
FIX-04 (#121): make the Hub session-card viewer count reflect only real remote/shared
viewers, excluding the app's own internal WebSocket subscribers (TerminalPanel, ChatPanel,
status watcher, Hub-card preview — all Origin=="local").

Purpose: A never-shared local session currently shows phantom viewers because the count is
the raw subscriber-map length. Filtering on Origin=="web" (D-01/D-02/D-03) makes 0 mean 0.
Output: New Hub.RemoteViewerCount() method + one call-site swap in engine.go + a comment
update in types.go, all covered by a new Go unit test.
</objective>
