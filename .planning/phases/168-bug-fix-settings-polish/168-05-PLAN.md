<objective>
UX-02 (#115): rename the footer "Enable Web" button to "Share Session" and make it open the Hub
Share modal for the active session instead of directly toggling web serving — eliminating the
button↔modal state drift.

Purpose: The footer currently calls ToggleWebServing directly, drifting from the modal's state.
D-13/D-14 make the modal the single writer. The integration gap (RESEARCH): SessionShareModal's
open-state lives only inside HubPanel; StatusBar renders per active tab outside HubPanel, so the
state must be lifted to App.tsx and threaded into HubPanel as a controlled prop (Pattern 4).
Output: Lifted modal state, a renamed/rewired footer button gated on tab type, and vitest coverage.
</objective>
