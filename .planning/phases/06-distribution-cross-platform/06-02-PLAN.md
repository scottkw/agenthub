Create `.github/workflows/build.yml` with a CI matrix covering all 4 platform variants. Use `dAppServer/wails-build-action@main` as the build action.

**Workflow trigger:** `on: [push, pull_request]`

**Matrix entries (4 jobs):**

1. **macOS universal** — `macos-latest`, platform `darwin/universal`
2. **Linux Ubuntu 24.04** — `ubuntu-latest`, platform `linux/amd64`, webkit tag `webkit2_41`, package `libwebkit2gtk-4.1-dev`
3. **Linux Ubuntu 22.04** — `ubuntu-22.04`, platform `linux/amd64`, package `libwebkit2gtk-4.0-dev`
4. **Windows** — `windows-latest`, platform `windows/amd64`

**Strategy:** `fail-fast: false` so all platforms attempt even if one fails.

**Steps for ALL jobs:**
1. `actions/checkout@v4` with `submodules: true`
2. Conditional Linux deps: `sudo apt-get update && sudo apt-get install -y build-essential pkg-config libgtk-3-dev ${{ matrix.build.webkit_pkg }}` (only when `runner.os == 'Linux'`)
3. `dAppServer/wails-build-action@main` with:
   - `build-name: agenthub`
   - `build-platform: ${{ matrix.build.platform }}`
   - `build-flags: ${{ matrix.build.webkit_tag && format('-tags {0}', matrix.build.webkit_tag) || '' }}`
   - `build-webview2: embed` (Windows only — ignored on others)
   - `nsis: ${{ matrix.build.os == 'windows-latest' }}` to produce NSIS installer on Windows
4. Run `go test ./...` BEFORE the wails build step — ensures all unit tests pass on each platform
5. Upload build artifacts with `actions/upload-artifact@v4`

**macOS signing + notarization (conditional on macOS AND secrets available):**
After the Wails build step, add conditional steps gated on `if: runner.os == 'macOS' && env.MACOS_CERTIFICATE != ''`:

a. **Import certificate into CI keychain:**
```bash
echo $MACOS_CERTIFICATE | base64 --decode > certificate.p12
security create-keychain -p "$MACOS_CI_KEYCHAIN_PWD" build.keychain
security default-keychain -s build.keychain
security unlock-keychain -p "$MACOS_CI_KEYCHAIN_PWD" build.keychain
security import certificate.p12 -k build.keychain -P "$MACOS_CERTIFICATE_PWD" -T /usr/bin/codesign
security set-key-partition-list -S apple-tool:,apple:,codesign: -s -k "$MACOS_CI_KEYCHAIN_PWD" build.keychain
```

b. **Sign with hardened runtime:**
```bash
/usr/bin/codesign --force -s "$MACOS_CERTIFICATE_NAME" \
  --options runtime \
  --entitlements build/entitlements.plist \
  build/bin/agenthub.app -v
```

c. **Notarize:**
```bash
xcrun notarytool store-credentials "notarytool-profile" \
  --apple-id "$MACOS_NOTARIZATION_APPLE_ID" \
  --team-id "$MACOS_NOTARIZATION_TEAM_ID" \
  --password "$MACOS_NOTARIZATION_PWD"
ditto -c -k --keepParent build/bin/agenthub.app notarization.zip
xcrun notarytool submit notarization.zip --keychain-profile "notarytool-profile" --wait
xcrun stapler staple build/bin/agenthub.app
```

d. **Cleanup:** Remove certificate.p12 and CI keychain.

All MACOS_* values come from GitHub secrets (`secrets.MACOS_CERTIFICATE`, etc.). The signing steps are conditional — if secrets aren't configured yet, CI still builds successfully, just without signing.

Use `env:` block at job level to map secrets to environment variables.

**Artifact upload matrix:**
- macOS: upload `build/bin/agenthub.app` (as zip)
- Linux: upload `build/bin/agenthub`
- Windows: upload `build/bin/agenthub-amd64-installer.exe` and `build/bin/agenthub.exe`
