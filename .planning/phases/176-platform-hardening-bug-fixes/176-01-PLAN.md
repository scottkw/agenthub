<objective>
Fix BUG-05 (#124): the Linux desktop GUI is dead-on-arrival. Two independent root causes, both in `main.go`:
1. Wails' GTK backend dereferences the `nil` SubMenu of the macOS role menus (`menu.AppMenu()`, `menu.EditMenu()`, `menu.WindowMenu()`) → segfault on launch.
2. WebKit2GTK's DMABUF GPU renderer hangs on first interaction under Wayland compositors.

Purpose: make the Linux `.deb`/`wails build` GUI launch and stay responsive — the last platform blocker before v4.2 ships.
Output: a single-file `main.go` change (menu darwin-guard + Linux DMABUF env guard).
</objective>
