<objective>
Consolidate the Hub session card's three inconsistent metadata treatments (`Running`/`Local`
icon+text, `/bin/zsh` outlined pill, `INTERNET` filled pill on its own row) into ONE consistent
chip row `agent · origin · exposure` in the locked outlined-ghost-pill style, tightening vertical
rhythm — while keeping the INTERNET / FULL ACCESS exposure badges the prominent FILLED chips so
they pop MORE by contrast. Build to Sketch 001 Variant B.

Purpose: Design-polish per the 2026-07-05 critique (commit 4402b44e). The quiet-chip direction
is locked (D-01) and the discretionary values are pinned by the winning sketch (Variant B). This
is frontend-only (SessionCard.tsx markup + style.css); no backend, no new data, no change to the
exposure semantics — only the DOM position and styling of existing elements moves.

Output: A restructured SessionCard with a `.hub-card__chiprow` (agent + origin quiet chips) + a
dedicated `.hub-card__exposure` line (INTERNET/FULL ACCESS filled badges) + a muted
`.hub-card__meta` line (uptime · viewers · Connected), styled for both themes via --hub-* tokens,
with extended vitest structure coverage and a reconciled TESTING.md.
</objective>
