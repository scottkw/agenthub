<objective>
Add a CLI `tailscale status --json` fallback to `checkHealth` in `internal/webserver/tailscale.go`. The fallback engages ONLY when the SDK read `local.Client.StatusWithoutPeers(ctx)` returns an error (D-03), on all platforms (D-04), reconstructing the full `TailscaleHealth` struct from CLI output (D-01) so non-admin macOS accounts — where the `macsys` `sameuserproof` file is root:admin 0640 and unreadable — report "Connected" instead of "installed but not connected" (Issue #120, FIX-05).

Purpose: Clear Issue #120 without altering the SDK-success path (SC2) or introducing new UI/error surfaces (D-05, purely additive).
Output: Updated `checkHealth` with an injected CLI-fallback seam, real CLI implementation wired through both public entrypoints, unit tests using injected fakes (no live daemon), and TESTING.md registration.
</objective>
