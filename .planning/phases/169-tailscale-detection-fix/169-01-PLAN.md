<objective>
Revert the invalidated CLI-`status`-fallback (169-01, CR-01) and replace it with honest,
permission-aware detection: on macOS macsys installs where the `sameuserproof` file is
`0640 root:admin` and unreadable by a non-admin account, distinguish "daemon running but
status unreadable" from "daemon genuinely down" — without ever reporting a false Connected.

Purpose: Close Issue #120 accurately. The prior CLI shell-out ran as the same OS user and
hit the identical per-user permission gate (CR-01); it could report a FALSE Connected on the
exact case it targeted, so it is misleading dead code that must be removed first (D-01).

Output: A reverted-plus-extended `internal/webserver/tailscale.go` carrying a `permProbeFunc`
injectable seam and an additive `PermissionLimited` field, with unit tests proving the
branch logic via injected fakes (a real `0640 root:admin` file cannot be constructed in CI).

Prohibitions (hard constraints):
- MUST NOT set Connected=true in the permission-limited state (SC).
- MUST NOT introduce a privileged helper / LaunchDaemon (Deferred — out of scope).
- MUST NOT read the `sameuserproof` token contents — the probe only observes that `open`
  fails with EACCES; it never obtains the file's bytes (info-disclosure boundary).
- MUST NOT touch the SDK-success path (Steps 3-4) — byte-for-byte unchanged (D-06, SC2).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS filesystem permission boundary | tailscaled-owned `/Library/Tailscale/sameuserproof-*` (`0640 root:admin`) crossed by an unprivileged AgentHub process; the probe observes the boundary, never circumvents it |
| localapi TCP listener (127.0.0.1) | AgentHub dials the `ipnport` port only to confirm liveness; no data read, no auth token used |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-169-01 | Tampering | `ipnport` symlink target in `macsysDaemonAlive` | low | mitigate | Target parsed as integer via `strconv.Atoi` only, then used solely in a fixed `127.0.0.1:<port>` dial; never used as a filesystem path. Bad/hostile target means Atoi fails means returns false (safe) |
| T-169-02 | Information disclosure | `sameuserproof` token file | low | mitigate | The probe only `os.Open`s to observe EACCES; it NEVER `ReadFile`s the token bytes. AgentHub cannot and does not obtain the secret (V2/V6 N/A by design) |
| T-169-03 | Spoofing / Elevation of privilege | `TailscaleHealth.Connected` driving exposure decisions | high | mitigate | Permission-limited NEVER sets Connected=true (hard SC + unit-asserted); the daemon restart gate additionally requires `HasCerts && IP`, both unreachable in this state (`process.go`) |
| T-169-04 | Tampering | `/Library/Tailscale` path + glob pattern (V12) | low | mitigate | Hardcoded constant path; no user input in the glob; no path traversal. Any non-EACCES/non-ENOENT error becomes unknown becomes false (fail-safe), logged at slog.Debug |

No package-manager installs in this plan (no `go get`, no `npm install`) — supply-chain threat
(T-169-SC) is not applicable; no legitimacy checkpoint required.
