<objective>
Wire a real, persisted light/dark UI-theme control in Settings → Appearance. The light-theme CSS
(`[data-ui-theme="light"]` overrides) already exists, but NOTHING in the app sets that attribute on
`<html>`, so users currently cannot reach the light theme at all. This plan adds the control, the
state, the `document.documentElement` attribute wiring, and localStorage persistence.

Purpose: Explicitly user-requested. The light palette is dead code until a control sets the attribute.
This is independent of the CSS token work (141-06/07) — it touches TSX only, so it runs in parallel.

Output: Working, persisted Light/Dark switch in Settings → Appearance.
</objective>
