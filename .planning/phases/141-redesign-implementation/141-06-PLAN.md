<objective>
Vendor the comp's two fonts locally and re-value the entire `--hub-*` token system to the
comp palette — without touching any surface selectors yet. This is the foundation: define the
NEW design language as tokens (fonts, colors, radii, type scale) in `:root` and
`[data-ui-theme="light"]`. Plan 141-07 then applies these tokens across the surface selectors.

Purpose: Phase 141's original plans tokenized hex to the SAME TokyoNight values, so the app is
pixel-identical to pre-141. The fonts (Plus Jakarta Sans + JetBrains Mono) were never adopted —
the user's #1 flagged miss. This plan changes the token VALUES so adopting them actually restyles
the app to match the canonical comp.

Output: Vendored woff2 fonts, `@font-face` rules, font/color/radii/type-scale tokens re-valued in
both theme blocks. Blue accent stays locked.
</objective>
