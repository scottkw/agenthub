## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React state -> daemon | The cap token must NEVER enter React state or a webview-visible URL; the daemon looks it up by sessionID. |
| untrusted respond text -> PTY | maxLength=4096 bounds size; timing/intent bounded by the settled guard (CR-03). |
| remote WS snapshot -> rendered tail | Scrollback bytes are ANSI-stripped and rendered as React text (auto-escaped; no dangerouslySetInnerHTML). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-134-07-01 | Information Disclosure | cap in React state/URL | mitigate | remote seam carries only a boolean; the daemon resolves the cap by sessionID; constructed URL contains no cap (asserted in FE-URL-01) |
| T-134-07-02 | Tampering | untrusted text late-delivery (CR-03) | mitigate | settled flag + clearTimeout + onOpen guard so abandoned text is never written post-timeout |
| T-134-07-03 | Denial of Service | leaked RelayClient/WS + ping interval | mitigate | clientRef + reject-path close + useEffect unmount cleanup; tail socket closed after snapshot capture |
| T-134-07-04 | Tampering | XSS via rendered tail | mitigate | ANSI-strip + render as React text content (auto-escaped); no dangerouslySetInnerHTML |
| T-134-07-05 | Elevation of Privilege | read-only cap silently swallows input | accept | Read/write decided by signed claims.Perms on the peer (Pitfall 2); full read-only banner deferred — colorblind-safe (non-color) badge belongs to the a11y pass; documented, not silently shipped as guaranteed delivery |
| T-134-07-SC | Tampering | npm installs | accept | No new frontend dependencies; reuses existing RelayClient + xterm |
</threat_model>
