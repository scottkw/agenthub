<objective>
Complete scope item 2 of the M-41 gap closure on the frontend: when macOS denies notification authorization, surface a user-facing remediation hint so a silent denial is no longer a dead end. During UAT the app showed as "Off" in System Settings with no prompt ever seen; 167-06 now proactively requests authorization on toggle-enable and emits a `notification:permission-denied` Wails event when the OS reports denial. Purpose: A proactively-requested permission that gets denied must tell the user how to fix it, otherwise the feature is silently dead (the exact UAT condition).
Output: A denial hint wired to the backend event in SettingsTab.tsx, a vitest test proving it renders on the event, and TESTING.md registration. The live M-41 signed-build re-test remains a manual UAT item tracked in TESTING.md Category U (registered in 167-06).
