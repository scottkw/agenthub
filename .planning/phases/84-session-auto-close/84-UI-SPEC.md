## Interaction States

### Session exits (exit code 0, auto-close enabled)

1. `session:exit` event arrives
2. ExitToast appears (bottom-right, clean variant, green left border)
3. ExitCountdownBanner appears inside TerminalPanel of that session
4. Tab receives `.tab--exiting` class (opacity 0.5) + `.tab__countdown` showing "5s"
5. Countdown ticks 5 → 4 → 3 → 2 → 1 (each tick updates toast, banner, and tab badge)
6. At 0: tab fades to opacity 0 (150ms transition), then `handleCloseTab` executes, toast is removed

### User clicks "Keep Open" (toast or banner)

1. Countdown cancelled immediately
2. Tab opacity restores to 1.0 (`.tab--exiting` class removed)
3. ExitCountdownBanner unmounts
4. Toast dismisses (or transitions to a static exit notification without countdown)
5. Tab remains open; terminal remains interactive (D-08)

### Session exits (exit code non-zero)

1. `session:exit` event arrives
2. ExitToast appears (bottom-right, error variant, red left border)
3. No countdown, no banner, no tab fade
4. Toast persists until user manually dismisses it
5. Tab stays open (D-09)

### Auto-close disabled in settings

1. `session:exit` event arrives for clean exit
2. ExitToast appears (clean variant) without countdown row
3. No banner, no tab fade, no auto-close
4. Toast persists until dismissed

### Terminal during countdown (D-08)

Terminal is fully scrollable, selectable, and copyable during countdown. No overlay, no pointer-events blocking. Banner appears below terminal output, not over it.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Toast heading (clean) | "{sessionName}" |
| Toast meta line (clean) | "{cli} · exited · {finalStatus}" |
| Toast exit code (clean) | "Exit code: 0 · Duration: {n}s" |
| Toast countdown row | "Closing in {n}s" + [Keep Open] button |
| Toast heading (error) | "{sessionName}" |
| Toast meta line (error) | "{cli} · exited with error · {finalStatus}" |
| Toast exit code (error) | "Exit code: {n} · Duration: {n}s" |
| Inline banner message | "Agent exited cleanly. Tab closes in {n}s." |
| "Keep Open" button label | "Keep Open" |
| Dismiss button aria-label | "Dismiss exit notification for {sessionName}" |
| Settings toggle label | "Auto-close tab on exit" |
| Settings toggle description | "Automatically close the tab 5 seconds after an agent exits with code 0." |
| Settings section heading | "Session Behavior" |

Notes:
- Session name and cli values are passed from the `session:exit` event payload (D-06)
- "finalStatus" maps to: "running" / "idle" / "waiting" / "errored" — display as-is (lowercase)
- Exit code 0: no destructive confirmation required (auto-close is the expected outcome)
- Non-zero exit: no confirmation; tab stays open automatically (D-09)

Source: CONTEXT.md D-04, D-05, D-06; RESEARCH.md Pattern 5/6.

## Destructive Actions

No destructive actions in this phase. The auto-close flow does not prompt the user — it provides a cancellable countdown instead. Manual tab close (already existing) is out of scope for this phase.

## Animation Contract

| Animation | Property | Duration | Easing | Trigger |
|-----------|----------|----------|--------|---------|
| Tab fade on exiting | `opacity: 1 → 0.5` | 150ms | ease | `.tab--exiting` class added at countdown start |
| Tab fade on close | `opacity: 0.5 → 0` | 150ms | ease | countdown reaches 0 |
| Banner enter | implicit (component mounts) | — | — | session:exit event |
| Toast enter | implicit (component mounts) | — | — | session:exit event |
| Banner/Toast exit | `.banner-exit` pattern (`opacity: 0; max-height: 0`) | 150ms opacity / 200ms max-height | ease | "Keep Open" clicked or tab closed |

Source: RESEARCH.md Pattern 5 CSS; existing `.banner-exit` in style.css lines 1571–1578.
