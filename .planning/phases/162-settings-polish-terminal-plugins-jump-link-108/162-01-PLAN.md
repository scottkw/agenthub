<objective>
Resolve GitHub issue #108. The Settings "Plugins" jump link currently sits FIRST in the
sticky jump bar while its section renders LAST, so clicking the first link jumps to the
bottom of the page. The label "Plugins" also misleads — these are terminal/shell plugins.

This plan (1) moves the jump link to the LAST position so it matches render order, (2)
renames it to "Terminal Plugins" in both the jump-bar label and the section header, and
(3) keeps the `settings-plugins` anchor id stable so scroll/scroll-spy keeps working. The
fix lives entirely in the shared React frontend, so it applies to both the GUI and the
web-share surfaces with no per-surface duplication.

Purpose: Closes #108 (bug: misordered + mislabeled Settings jump link). Satisfies
SETTINGS-UI-01.
Output: Two modified source files + one updated test; full frontend gate green.
</objective>
