- Char string  `json:"c"`            // Unicode grapheme

HTTP route (Plan 03): GET /sessions/{id}/styled-tail?n=N → 200 + {"lines": [[{c,fg,bg,b},...],...]}

Frontend lib (Plan 04): resolveColor(val: string | undefined, theme: ITheme, isFg: boolean): string | undefined
  - undefined/"" + isFg → theme.foreground; undefined/"" + !isFg → undefined
  - "ansi:N" where N<16 → theme[ANSI_THEME_KEYS[N]]; N>=16 → theme.extendedAnsi?.[N-16]
  - "#rrggbb" → passthrough
