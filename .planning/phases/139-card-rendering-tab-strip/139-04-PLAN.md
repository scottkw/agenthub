| Boundary | Description |
|----------|-------------|
| daemon → frontend | StyledSpan[][] crosses the Wails binding; carries only color strings, never HTML |
| remote agent bytes → headless xterm → DOM | Remote PTY bytes are serialized to HTML by addon-serialize and injected via dangerouslySetInnerHTML |
| ITheme → inline style | Theme-resolved color strings become React inline style props |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-139-07 | Tampering | StyledSpan color strings reaching the DOM (local path) | mitigate | Local path renders via React children (auto-escaped); color strings used only as inline style values; NO dangerouslySetInnerHTML on the local path |
| T-139-08 | Tampering | XSS via serializeAsHTML for the remote briefing tail | accept | Output comes from the agent-owned PTY session the user chose to view; addon-serialize emits span-tagged terminal output, not arbitrary user HTML; scope limited to the briefing modal (not the main terminal); same trust level as xterm already rendering the session |
| T-139-09 | Denial | Per-card xterm instances exhausting resources on the 3s poll | mitigate | MiniPreview imports type-only ITheme and mounts NO Terminal (CARD-07); the no-xterm guard test enforces it; only the briefing modal (single, on-demand) instantiates a headless Terminal, which is disposed immediately after serialize |
| T-139-SC | Tampering | npm installs | accept | No new packages — @xterm/xterm and @xterm/addon-serialize already installed; A2 verified in Plan 01 |
