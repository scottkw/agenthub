<objective>
Complete the `ChatStore` with Markdown `Export()` and `Delete()`, then wire the store into `SessionEngine`: a `chatStores` map populated on `CreateSession` and torn down on `KillSession` with zero orphaned files.

Purpose: Closes the durability lifecycle — a thread lives exactly as long as its session and is fully exportable. This satisfies the teardown half of PERSIST-03 (delete on session delete) and the lifetime half of PERSIST-01 (the store exists for the session's life), and provides the `Export()` the REST endpoint in Plan 03 will serve.

Output: `Export()` + `Delete()` on ChatStore; `chatStores` map + accessor + lifecycle wiring in `engine.go`; teardown tests proving no orphans.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| session lifecycle → disk | A session's chat file must be created with the session and removed when the session is deleted; leftover files are an information-retention/orphan risk. |
| recycled session ID → stale thread | A new session reusing a prior ID must not inherit the prior thread. |
