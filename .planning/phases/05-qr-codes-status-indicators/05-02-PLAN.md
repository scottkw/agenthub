    Create internal/status/detector.go:

    1. Define types:
       ```go
       type SessionStatus string
       const (
           StatusRunning  SessionStatus = "running"
           StatusWaiting  SessionStatus = "waiting"
           StatusIdle     SessionStatus = "idle"
           StatusErrored  SessionStatus = "errored"
       )
       ```

    2. Define PatternSet struct with fields: Working, Idle, Waiting — each a []*regexp.Regexp. Provide DefaultClaudePatterns() that returns the empirically-known Claude Code patterns from RESEARCH.md. Provide FallbackPatterns() that returns an empty set (conservative running-only default for unknown CLIs).

    3. Define PatternsForCLI(cliName string) PatternSet that returns DefaultClaudePatterns() for "claude" and FallbackPatterns() for everything else.

    4. Define Detector struct: sessionID string, patterns PatternSet, tail []byte (max 4096 bytes), current SessionStatus, onTransit func(string, SessionStatus).

    5. Implement stripANSI(b []byte) []byte using regexp `\x1b\[[0-9;]*[a-zA-Z]|\x1b[()][AB012]|\x1b[=>]` (compile once at package init).

    6. Implement appendTail(existing, new []byte, maxLen int) []byte — appends new to existing, trims from the front if over maxLen.

    7. Implement Feed(raw []byte) — strips ANSI, appends to tail, calls classify(), emits onTransit if state changed.

    8. Implement classify() SessionStatus — check patterns in priority order: Waiting > Working(Running) > Idle > default Running.

    9. Implement Watch(hub HubLike, sessionID string, cli string, onTransit func(string, SessionStatus)) — creates a Subscriber, subscribes to hub, runs a select loop reading from sub.Msgs and hub.Done(). On each message, calls detector.Feed(). On hub.Done(), unsubscribes and returns. Define HubLike interface: Subscribe(*relay.Subscriber), Unsubscribe(*relay.Subscriber), Done() <-chan struct{}, ScrollbackSnapshot() []byte. This avoids importing the concrete Hub type if needed, but using relay.Hub directly is also fine since it satisfies the interface.

    10. On Watch start, feed the ScrollbackSnapshot through the detector first so the initial status is correct (not always "running" on reconnect).

    1. In app.go, add to App struct:
       - sessionStatuses map[string]status.SessionStatus (init in NewApp)
       - statusMu sync.RWMutex (separate from main mu to avoid contention)

    2. Add GetSessionStatus(sessionID string) string method:
       - Lock statusMu.RLock, read sessionStatuses[sessionID], unlock
       - Return string(status) or "running" if not found

    3. In CreateSession, after `go hub.Run()`, start the status detector:
       ```go
       go status.Watch(hub, id, cli, func(sid string, s status.SessionStatus) {
           a.statusMu.Lock()
           a.sessionStatuses[sid] = s
           a.statusMu.Unlock()
           if a.ctx != nil {
               runtime.EventsEmit(a.ctx, "session:status", map[string]string{
                   "sessionId": sid,
                   "status":    string(s),
               })
           }
       })
       ```
       Pass the cli name so PatternsForCLI selects the right pattern set.

    4. In KillSession, after cleanup, set sessionStatuses[id] = status.StatusErrored and emit the event. Then delete the entry.
