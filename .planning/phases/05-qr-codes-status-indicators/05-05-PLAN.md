**Change 2: Replace the window resize listener with a ResizeObserver and defer the activation fit().**

Replace the entire isActive effect:

```tsx
// Fit when this panel becomes active, and track container size changes.
useEffect(() => {
  if (!isActive || !containerRef.current) return

  const container = containerRef.current

  // Defer initial fit to ensure layout is complete after display:none → display:flex transition.
  const rafId = requestAnimationFrame(() => {
    fitAddonRef.current?.fit()
  })

  // ResizeObserver fires whenever the container dimensions change (window resize,
  // sidebar open/close, etc.).
  const ro = new ResizeObserver(() => {
    fitAddonRef.current?.fit()
  })
  ro.observe(container)

  return () => {
    cancelAnimationFrame(rafId)
    ro.disconnect()
  }
}, [isActive])
```

Remove the `window.addEventListener('resize', handleResize)` listener and its associated cleanup — ResizeObserver handles this more reliably.
