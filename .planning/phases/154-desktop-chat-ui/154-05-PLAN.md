## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-154-01 | Tampering | rendered message bodies | high | mitigate | Message bodies render through ChatMessage's rehype-sanitize pipeline (plan 154-03, SEC-03); ChatPanel passes content unmodified — no dangerouslySetInnerHTML. |
| T-154-09 | Denial of Service | unbounded thread growth | low | accept | The daemon enforces the 10k per-session cap (Phase 151); the virtualizer bounds DOM nodes regardless of message count. |
| T-154-10 | Information Disclosure | history fetch URL | low | mitigate | History is fetched only from 127.0.0.1:{relayPort} loopback; no external origin. |
