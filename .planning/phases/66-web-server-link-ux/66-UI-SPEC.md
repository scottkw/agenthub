## Interaction Contract

### URL Action Row

**Trigger:** Rendered only when `isServerRunning && serverURL` (same condition as the existing URL paragraph).

**Layout:** Single flex row. Left: URL text (truncated with ellipsis at full Tailscale hostname lengths). Right: three compact buttons in order: Open, Copy, QR.

**Button labels and icons:**

| Button | Label | Icon | Notes |
|--------|-------|------|-------|
| Open | "Open" | `ArrowTopRightOnSquareIcon` (Heroicon 24/outline) | Opens URL in system browser via `BrowserOpenURL(serverURL)`. Full label "Open in Browser" is too long for compact row — use "Open" with icon. |
| Copy | "Copy" / "Copied!" | `ClipboardDocumentIcon` (Heroicon 24/outline) | Calls `ClipboardSetText(serverURL)`. Label changes to "Copied!" for 1500ms, then reverts. |
| QR | "QR" / "Hide QR" | `QrCodeIcon` (Heroicon 24/outline) | Toggles inline QR block below the row. Label = "QR" when hidden, "Hide QR" when shown. Button adopts active/on state style when QR is visible. |

Icons are 14×14px (size-3.5 equivalent) within the compact action buttons.

### Copy Feedback

- On click: call `ClipboardSetText(serverURL)`, then `setUrlCopied(true)`, then `setTimeout(() => setUrlCopied(false), 1500)`.
- During copied state: button text = "Copied!", button class gains `settings-web-server__action-btn--copy-done` (green tint).
- No toast, no modal — inline label feedback only. Mirrors existing password copy pattern.

### QR Toggle

- First toggle-on: call `GetWebServerQRCode()`, cache result in `dashQRb64` state, set `showDashQR = true`.
- Subsequent toggle-on: reuse cached `dashQRb64` (no re-fetch).
- Toggle-off: set `showDashQR = false`. Do NOT clear `dashQRb64`.
- Server restart invalidation: a `useEffect([isServerRunning])` resets both `showDashQR` and `dashQRb64` when `isServerRunning` becomes false.
- While QR is fetching: show button in loading state — label "Loading..." (no spinner needed; fetch is fast on localhost Go call).
- If fetch fails: show inline error text below the URL row: "QR unavailable" in `#f7768e`.

### Open Button

- Click: `BrowserOpenURL(serverURL)`. No loading state, no feedback (browser opens immediately or silently fails at OS level).
- The existing `<a href={serverURL} target="_blank">` anchor is removed from the DOM — replaced by the URL text in the action row + the Open button handling the click.

### QR Image Accessibility

- `alt="QR code for dashboard URL"` on the `<img>` element.
- `aria-label="Show QR code"` / `aria-label="Hide QR code"` on the toggle button (label text alone is sufficient, but aria-label makes intent unambiguous when icon-only rendering is considered in future).

## States

| State | What the User Sees |
|-------|--------------------|
| Server not running | URL row hidden. No buttons rendered. Existing "Start Web Server" button visible. |
| Server running, QR hidden (default) | URL action row visible: truncated URL + Open + Copy + QR buttons. |
| Server running, copy just clicked | Copy button shows "Copied!" in green for 1500ms, then reverts. |
| Server running, QR fetching | QR button shows "Loading...", disabled. |
| Server running, QR visible | QR button shows "Hide QR" (active style). 200×200 QR image renders below the URL row. |
| Server running, QR fetch failed | "QR unavailable" error text in `#f7768e` below URL row. QR button reverts to "QR" (no active style). |
| Server stopped while QR visible | QR image disappears, QR button resets to "QR", `dashQRb64` cleared. |
