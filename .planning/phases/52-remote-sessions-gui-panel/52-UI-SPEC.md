## Interaction Contracts

### 1. Tab Navigation
- Clicking the globe button (`.tab-bar__btn--remote`) in the tab bar controls opens the Remote Sessions tab.
- If the tab already exists, it is activated (not duplicated). Mirrors `handleOpenDaemonManager` pattern exactly.
- Tab type: `'remote-sessions'` added to `Tab.type` union in `TabBar.tsx`.

### 2. Auto-Refresh Polling
- Polling interval: 30 seconds (`setInterval(refresh, 30_000)`).
- Loading spinner: shown only when `loading === true && peers.length === 0` (first load or post-tab-activation empty state).
- Silent refresh: when `peers.length > 0`, subsequent 30s refreshes update data without showing spinner (no flicker).
- Polling stops immediately when the Remote Sessions tab is deactivated (useEffect cleanup clears interval and sets `cancelled = true`).

### 3. Open Button
- Clicking `Open` on a session row calls `BrowserOpenURL(session.url)` from the Wails runtime.
- `session.url` is a fully-constructed HTTPS URL (`https://{fqdn}:7443/sessions/{id}`) returned by the Go binding.
- No confirmation dialog — opening a URL in a browser is non-destructive.

### 4. Keyboard / Accessibility
- All buttons have `title` and `aria-label` attributes (matches existing pattern from `TabBar.tsx`).
- Loading state uses a visible text label `Probing peers...` alongside the spinner (not spinner-only).
- Peer header elements use semantic section grouping (div with peer hostname as visible text label).
- No modal or overlay interactions in this phase.
