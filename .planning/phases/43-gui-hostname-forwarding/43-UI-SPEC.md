## Component Inventory

### New element: `.daemon-panel__hostname`

This is the only new UI element in Phase 43. It renders the hostname per session row inside `DaemonManagerPanel`, positioned after `.daemon-panel__cli` and before `.daemon-panel__actions`.

**Specification:**

```css
.daemon-panel__hostname {
  font-size: 11px;
  color: #565f89;
  background: #1e2030;
  padding: 2px 8px;
  border-radius: 3px;
  flex-shrink: 0;
  max-width: 160px;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

This matches the existing `.daemon-panel__cli` badge treatment exactly. The two badges appear side by side in the row.

**Row order (left to right):**
1. Status dot (`.daemon-panel__status`) — 8px circle
2. Session name (`.daemon-panel__name`) — flex:1, truncated
3. CLI badge (`.daemon-panel__cli`) — e.g. "claude"
4. Hostname badge (`.daemon-panel__hostname`) — e.g. "macbook-pro.local"  **[NEW]**
5. Actions (`.daemon-panel__actions`) — "Web On/Off" + "Kill" buttons

**Fallback copy:** When `s.hostname` is empty string or undefined, render `—` (em dash `\u2014`). Do not render an empty badge. Source: RESEARCH.md Pattern 4 — em dash fallback consistent with Phase 41 tray tooltip pattern.

**Tooltip:** `title={s.hostname || ''}` — show full hostname on hover when it might be truncated.

## Interaction Contract

### Hostname display (read-only)

- Rendered as a non-interactive pill badge — no click, no hover state change
- `title` attribute provides native browser tooltip with full hostname on hover (for truncation recovery)
- No loading state needed — hostname is available synchronously from `ListSessions()` response
- No error state needed — empty string degrades to `—` em dash fallback

### No new interactions introduced

Phase 43 is display-only. The only change to user-facing behavior is that session rows in DaemonManagerPanel now show a hostname badge. All existing interactions (Kill, Web On/Off, tab navigation) are unchanged.

## Accessibility

- Hostname badge uses `title` attribute for full text when truncated — accessible to screen readers as tooltip text
- Color `#565f89` on `#1e2030` background: contrast ratio ~3.5:1 — acceptable for non-critical metadata at 11px (consistent with existing `.daemon-panel__cli` which uses identical treatment)
- No keyboard interaction introduced — element is display-only
