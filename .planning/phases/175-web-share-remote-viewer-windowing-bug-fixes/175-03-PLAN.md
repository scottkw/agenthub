<objective>
Fix BUG-01 (#128): a web-share guest on a narrow phone viewport currently sees the 80-column grid downscaled via `transform: scale()` with NO floor — it just keeps shrinking as the viewport narrows until the text is unreadable. Add a readability floor + horizontal-scroll fallback to the guest scale pipeline, staying entirely within the guest-only, downscale-only, never-resize-the-host contract (VIEW-04/05, Phase 157).

Purpose: A mobile guest must be able to READ the terminal. Per RESEARCH the real fix site is the React SPA (`terminalScale.ts` + `TerminalPanel.tsx`), NOT the dead `web/assets/terminal.js` (unreachable since Phase 159's `/sessions/{id}` → `/app/` redirect).
Output: a new floor-aware pure scale function (fully unit-tested) and a recomputeScale that scrolls instead of shrinking below the floor.
</objective>
