### 2. M-49 — live owner-ends-session disconnect notice (BUG-02, #125)

  guest sees the accessible (colorblind-safe, text-labelled, role=status) disconnect

  actions: exit session, "disconnect all viewers", AND disable sharing.
result: [PASS 2026-07-08 (rebuilt daemon): banner "Session ended — the owner stopped this session."
  fires on all three owner actions — exit, disconnect-viewers, AND disable-sharing (fix 501aef9e confirmed live)]

### 3. M-51 — live two-client alt-screen reconnect (BUG-04, #119 Problem 2)
expected: A long-running full-screen TUI (Claude/Gemini-CLI/OpenCode) runs long enough
  that the raw 256 KiB scrollback ring wraps past the one-time ESC[?1049h; a late-joining
  or reconnecting guest sees the current screen correctly (emulator-derived RenderSnapshot
  preamble re-establishes alt-screen mode + content), not a blank/garbled window. Also
  confirm no duplicated content on connect (CR-03 fan-out fix) and correct geometry after
  a second guest joins with a smaller viewport (CR-01 resize fix).
result: [PASS (agents) 2026-07-08 (rebuilt prod app): ALL agent TUIs (Claude Code, Gemini CLI,
  OpenCode) — AgentHub's primary use case — render CLEANLY on late-join after ring wrap, alt-screen
  mode + content correct, no dup content, correct geometry after a smaller second guest. Three landed
  fixes: ring-wrap discriminator (fbf5dd8e), eager-emulator build from first PTY byte (8268155c), and
  rebuild-emulator-empty-on-resize (44078d41). KNOWN EDGE CASE, DEFERRED (low priority): macOS `top`
  specifically still garbles its HEADER on late-join after ring wrap — process rows bleed into the
  header region. Root cause (unlike agents): top draws its header once, protects it with a scroll
  region, and only patches numbers in place, so a reconstruction fidelity gap in the headless emulator
  (charmbracelet/x/vt) never self-heals — whereas agents full-repaint every frame and self-heal.
  Tracked as issue #130 (low priority). Full investigation: .planning/debug/m51-top-header-garble.md.
  Not a regression (pre-175 this case was blank/garble); accepted by user 2026-07-08 to pass 175.]
