<objective>
Fix BUG-03 (#126): exiting from inside a shared session does not auto-close its tab (unshared sessions do). Per the phase's locked decision this fix is GATED on the 175-01 live diagnosis — the plan implements the branch the diagnosis selected. The primary hypothesis is `app.go:386`'s fixed 300s exit-poll deadline (measured from poll start, no re-arm), which silently expires for any session that lives past 5 minutes before exiting, so no `session:exit` event is ever emitted.

Purpose: A shared session must clean up its own tab exactly like an unshared one. Ship the fix for the CONFIRMED cause, not a guessed one (RESEARCH Pitfall 4).
Output: the deadline removed/re-armed (CONFIRMED branch) or the stall instrumented (DISPROVED branch), with updated tests.
</objective>
