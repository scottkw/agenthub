## Component Inventory

### New: Tab Context Menu (`tab__context-menu`)

**Trigger:** `onContextMenu` on `.tab__name` span (right-click). Suppresses native browser menu via `e.preventDefault()`.

**Anatomy:**
```
div.tab__context-menu           -- position: fixed, anchored at clientX/clientY
  button.tab__context-menu__item  -- "Rename"
```

**Visual spec:**
- Background: `#1e2030`
- Border: `1px solid #292e42`
- Border-radius: `4px`
- Box-shadow: `0 4px 12px rgba(0,0,0,0.4)`
- Min-width: `120px`
- z-index: `500` (below modals at 1000)

**Item spec:**
- Padding: `8px 12px`
- Font-size: `13px`
- Font-weight: `400`
- Color default: `#a9b1d6`
- Color hover: `#c0caf5`
- Background hover: `#292e42`
- Cursor: `pointer`
- Border: none
- Width: `100%`
- Text-align: `left`

**Dismiss behavior:**
- `mousedown` outside the menu div → close
- `Escape` keydown → close
- Tab is closed while menu open → close (clear `contextMenu` state in `handleCloseTab`)

**Accessibility:** `role="menu"` on container, `role="menuitem"` on each button.

### Modified: Tab (`TabBar.tsx`)

Existing double-click rename behavior is unchanged. Addition only: `onContextMenu` handler on `.tab__name` span. The `.tab__rename-input` interaction (Enter commits, Escape cancels, blur commits) is unchanged.

**New title attribute on `.tab__name`:** Change from `"Double-click to rename"` → `"Double-click or right-click to rename"`.

## Interaction States

### Tab Rename via Right-Click

| Step | State | Visual |
|------|-------|--------|
| 1 | User right-clicks tab label | Context menu appears at cursor, native menu suppressed |
| 2 | User clicks "Rename" | Context menu closes, tab name span → `tab__rename-input` (existing double-click behavior) |
| 3 | User types and presses Enter | Input → span, new name committed via `onRename` |
| 4 | User presses Escape | Input → span, original name restored |
| 5 | User clicks outside menu (not "Rename") | Context menu closes, no rename starts |

### Tab Rename Input (existing, for reference)

- Input width: fills available tab space (`flex: 1`)
- Background: `#1e2030`, border: `1px solid #7aa2f7` (accent), border-radius: `2px`
- Font-size: `13px`, color: `#c0caf5`
- Padding: `1px 4px`
- Focus: auto-focus + select-all on mount

### Dashboard Session Name Display (WEBUI-02)

- Sessions with a tab rename: display the custom name in `span.session-name`
- Sessions never renamed: display the default name (e.g. "claude 1") — never the raw UUID
- Fallback if name is empty string: display session ID (handled in Go handler, not JS)
