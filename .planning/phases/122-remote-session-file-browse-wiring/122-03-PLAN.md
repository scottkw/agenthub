NOTE on baseURL shape for the proxy: FilesApiClient builds `${baseURL}/api/files/<op>?...`. For the proxy, we want the resulting URL to be `http://127.0.0.1:{relayPort}/api/files/remote/{sid}/<op>?...`. The cleanest way is to set `baseURL = http://127.0.0.1:{relayPort}/api/files/remote/{sid}` and let FilesApiClient append `/api/files/<op>`. That produces `.../api/files/remote/{sid}/api/files/<op>` which is WRONG.

OPTION A (PREFERRED): Teach FilesApiClient to accept a `pathPrefix` or `urlBuilder` config so the proxy path shape can be `${baseURL}${pathPrefix}/<op>`. Set `pathPrefix = /api/files/remote/{sid}` for remote, default `/api/files` for local.

OPTION B: Set `baseURL = http://127.0.0.1:{relayPort}` and have App.tsx pass a different prop — but that's a wider FileBrowserTab API change.

EXECUTOR DECISION: Use Option A. Extend `FilesApiConfig` with optional `pathPrefix?: string` (default `/api/files`). For remote, App.tsx passes `pathPrefix=/api/files/remote/{sessionId}` and `baseURL=http://127.0.0.1:{relayPort}`. The local-daemon path remains unchanged (default prefix). This is a non-breaking config addition.

    ```
    import type { RemotePeerSessions, RemoteSession } from '../components/RemoteSessionsPanel'

    export interface RemoteSessionWithHost extends RemoteSession {
      hostname: string
    }

    /** Derive the remote base URL from a session URL of the shape
     *  `https://{fqdn}:{port}/sessions/{id}`. Uses URL.origin so trailing
     *  paths / query strings are dropped. Phase 122 / RESEARCH §Pattern 3. */
    export function remoteBaseURLFor(session: { url: string }): string {
      return new URL(session.url).origin
    }

    /** Find a remote session by id across all peers. Returns the session
     *  enriched with its peer hostname, or undefined. */
    export function findRemoteSession(
      sessionId: string,
      remotePeers: RemotePeerSessions[],
    ): RemoteSessionWithHost | undefined {
      for (const peer of remotePeers) {
        const match = peer.sessions.find((s) => s.id === sessionId)
        if (match) return { ...match, hostname: peer.hostname }
      }
      return undefined
    }

    /** True iff the session id is in any peer's remote sessions list. */
    export function isRemoteSessionId(
      sessionId: string,
      remotePeers: RemotePeerSessions[],
    ): boolean {
      return findRemoteSession(sessionId, remotePeers) !== undefined
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Wails Webview → Local Daemon (relay TCP) | Trusted same-origin; FilesApiClient targets `http://127.0.0.1:{relayPort}` |
| Wails Webview ↛ Remote Tailnet Peer (HTTPS) | EXPLICITLY BLOCKED by design (Pitfall 1 — no CORS headers on remote webserver). All remote file fetches must traverse the local daemon proxy. |
| Modal-entered Join Code | Untrusted user input; treated as opaque token; flows directly to remote `/join/exchange` via the Plan 01 helper, which validates it server-side. |
| Cap Token | Generated by remote webserver; never displayed in UI; never written to disk on Machine B; lives only in the daemon's in-memory `RemoteCapStore`. |
