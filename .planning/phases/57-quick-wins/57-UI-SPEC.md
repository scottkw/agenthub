## Interaction Contract

### UI-01: Sidebar "New Session" button

| State | Visual | Behavior |
|-------|--------|----------|
| Default | Icon (`PlusIcon 20x20`) + label "New Session" at 13px, color `#9aa5ce` | Visible only when sidebar is expanded (collapsed === false) |
| Hover | Background `#1e2030`, color `#c0caf5` | 0.1s transition (inherited, do not change) |
| Collapsed | Icon only; `aria-label="New Session"` serves as screen reader / keyboard label | No visible label span rendered |
| Focus | Browser default focus ring | Do not suppress focus ring |

No click animation or loading state required — click dispatches `onAdd()` which is already wired.

### DET-01: Backend path fix (no UI surface)

This requirement has zero UI impact. The user experience is: Claude Code sessions that previously failed to start (because `~/.local/bin/claude` was not on PATH) now succeed. No new loading states, error states, or success indicators are needed — the existing session creation flow handles all outcomes.
