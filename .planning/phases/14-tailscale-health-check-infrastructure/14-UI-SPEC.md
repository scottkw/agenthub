## Wails Binding Contract

Phase 14 exposes the following surface to the frontend. Phase 18 depends on this exact shape.

### `GetTailscaleStatus()` — Wails-bound method

Return type (JSON-serialised from `TailscaleHealth` struct):

```typescript
interface TailscaleHealth {
  installed: boolean  // tailscaled socket reachable
  connected: boolean  // BackendState == "Running"
  hasCerts: boolean   // len(CertDomains) > 0
  ip: string          // first TailscaleIP, empty if not connected
  domain: string      // first CertDomain e.g. "hostname.tail46d69a.ts.net", empty if none
}
```

### `tailscale:health` — Wails event (push)

Payload: same `TailscaleHealth` shape above.

Emitted: when state changes (change-detected diff on every 10-second poll tick).

Frontend subscription (Phase 18 pattern):

```typescript
EventsOn('tailscale:health', (health: TailscaleHealth) => { /* update UI */ })
```

### Four health states the frontend must handle

| `installed` | `connected` | `hasCerts` | UI Action (Phase 18) |
|-------------|-------------|------------|----------------------|
| false | — | — | Show "Install or start Tailscale" modal |
| true | false | — | Show "Connect to your tailnet" modal |
| true | true | false | Show "Enable HTTPS in Tailscale admin" modal |
| true | true | true | No modal — all conditions satisfied |

Source: `14-RESEARCH.md` — architecture patterns, three-state health table.
