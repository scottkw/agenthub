Lock placement (RESEARCH §Per-Path Lock Placement):
- Acquire AFTER validateAndClean + denylistCheck (reject invalid paths cheaply, before touching the lock map).
- Acquire BEFORE os.OpenRoot (so temp-create + stat-check + rename are all inside the critical section).
- Lock key = absolute path `filepath.Join(s.rootPath, cleaned)` — NOT the relative `cleaned` (avoids cross-sandbox-root false contention).
- Use `defer mu.Unlock()` immediately after `mu.Lock()` so every early-return error path releases the lock (RESEARCH §Pitfall 5).
