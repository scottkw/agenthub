## Interaction Contract

### Save Button (SET-03)

Three states in sequence:

| State | Button text | CSS class | Disabled | Duration |
|-------|-------------|-----------|----------|----------|
| Idle | "Save Paths" | `--save` | no | until click |
| Saving | "Saving…" | `--save` + `disabled` | yes | async duration |
| Saved | "Saved!" | `--saved` | yes | 1500ms |
| Idle (return) | "Save Paths" | `--save` | no | — |

The "Saved!" state is the only positive feedback mechanism for SET-03. No toast, modal, or banner. Inline button state change only.

### Browse Button (SET-04, SET-05)

- One browse button per path row (both CLI table and tailscale table).
- Button label: "Browse"
- Button position: immediately to the right of the path input, same table cell, inside `.settings-panel__path-row`.
- On click: calls `OpenFileDialog(currentDirOfPath)` — native OS file picker.
- On selection: populates the corresponding path input field. No confirmation modal.
- On cancel (user closes picker without selecting): input field unchanged. Empty string from Wails is falsy — guard with `if (selected)`.
- Browse button is never disabled (user can browse even with an empty current path).

### Path Input (existing, unchanged)

- On focus: border changes to `#7aa2f7` (blue accent).
- Placeholder text: existing path or `"Path to {name}"`.
- Input width: `flex: 1` (fills remaining cell width after browse button).

### Error State

- Inline `<p className="settings-panel__error">` below the table, above the Save row.
- Color: `#f7768e`.
- Font: 12px, weight 400.
- Copy: the raw error message from the Go backend. No custom wrapping copy.

## Layout Specification

### Path Row Layout (table `<td>`)

Before (existing):
```
[ path input (full width)                        ]
```

After (this phase):
```
[ path input (flex: 1)              ] [ Browse ]
```

- `.settings-panel__path-row` wraps both.
- Input loses `width: 100%` when inside `.settings-panel__path-row`; set to `flex: 1` instead.
- Browse button is `flex-shrink: 0` — never wraps.
- Both tables affected: detected CLIs table and tailscale-only table.

### Save Button Row

The `.settings-panel__save-paths-row` (already exists, `justify-content: flex-end`) is unchanged. The Save button swaps modifier class from `--save` to `--saved` for 1500ms, then back.

## Accessibility Notes

- Browse button: `title="Browse for executable"` for tooltip on hover; `aria-label` not required when title is present but recommended: `aria-label="Browse for executable"`.
- Saved confirmation: button remains visible (not hidden), color change alone is not sufficient — text also changes to "Saved!" to satisfy color-blind accessibility.
- Error message: plain `<p>` tag; no `role="alert"` needed for non-critical path errors (save failure is visible inline).
- Path inputs: existing `placeholder` provides context without additional `aria-label`.
