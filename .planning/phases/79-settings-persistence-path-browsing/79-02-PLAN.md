## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> path state | Browse result and manual input both set customPaths state |
| Frontend -> Wails bindings | GetCLIPaths and OpenFileDialog calls cross process boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-79-05 | Spoofing | OpenFileDialog result | accept | Result is from native OS dialog — user selected the file themselves. Path validated server-side by os.Stat in UpdateCLIPath before persistence. |
| T-79-06 | Tampering | customPaths state | accept | In-memory React state; not persisted until user clicks Save which triggers server-side validation. |
| T-79-07 | Denial of Service | GetCLIPaths on mount | mitigate | `.catch(() => {})` prevents uncaught promise rejection if daemon is not connected. Silent failure is appropriate — daemon connectivity is handled elsewhere in the app. |
</threat_model>
