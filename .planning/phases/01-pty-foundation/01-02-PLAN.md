    - TestSpawnPTY_RealPTY: the spawned process is in a real PTY — write to session, read output back (using "cat" which echoes input)
    - TestSpawnPTY_EnvSet: spawned process receives TERM=xterm-256color in its environment (spawn "env" and read output, grep for TERM)
    - TestResize: calling Resize on an active session returns nil error (verify resize does not crash; SIGWINCH propagation verified by absence of error)
    - TestResize_NotFound: calling Resize with a bad ID returns ErrSessionNotFound
    - TestList: after creating 2 sessions, List returns 2 entries
  </behavior>
  <action>
    1. Create `internal/pty/native.go`:
       - `NativePTYBackend` struct: `registry *SessionRegistry`
       - `NewNativePTYBackend() *NativePTYBackend` — creates a new SessionRegistry internally
       - `Create(ctx context.Context, req CreateRequest) (*Session, error)`:
         - Open PTY via `gopty.New()`
         - Build command: `p.CommandContext(ctx, req.CLI, req.Args...)`
         - Set env: merge `os.Environ()` with `req.Env`, always include `TERM=xterm-256color` and `COLORTERM=truecolor`
         - On POSIX (`runtime.GOOS != "windows"`): set `cmd.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}`
         - Call `cmd.Start()`, handle error (close PTY on failure)
         - Call `p.Resize(req.Cols, req.Rows)` — ignore error on Windows (log warning)
         - Generate UUID for session ID (use `crypto/rand` + hex encoding, 16 bytes)
         - Create Session struct, add to registry, return it
       - `Resize(id string, cols, rows int) error`: get session from registry, call `s.pty.Resize(cols, rows)`
       - `Kill(id string) error`: get session from registry, call `killSession(s)` (from cleanup.go), remove from registry, set state to StateStopped
       - `List() []*Session`: delegate to registry.List()
       - Helper `mergeEnv(base []string, extra []string, required ...string) []string`: merge without duplicating keys; required vars override everything
    2. Create `internal/pty/native_test.go`:
       - All tests use `"cat"` or `"echo"` as the CLI (available on all POSIX systems).
       - `TestSpawnPTY`: Create with CLI="cat", verify session ID is not empty, State is StateRunning
       - `TestSpawnPTY_RealPTY`: Create with CLI="cat", write "hello\n" to session, read back, verify output contains "hello"
       - `TestSpawnPTY_EnvSet`: Create with CLI="env", read output, verify it contains "TERM=xterm-256color"
       - `TestResize`: Create a session, call Resize(120, 40), verify nil error
       - `TestResize_NotFound`: Call Resize("nonexistent", 80, 24), verify ErrSessionNotFound
       - `TestList`: Create 2 sessions, verify List returns 2
       - Each test defers Kill on created sessions to avoid leaking processes
       - Use a 5-second timeout context for all spawns
  </action>

  <name>Task 2: Implement clean kill, graceful shutdown, and win32-input parser</name>
  <files>internal/pty/cleanup.go, internal/pty/cleanup_windows.go, internal/pty/win32input.go, internal/pty/win32input_other.go, internal/pty/win32input_test.go</files>
  <behavior>
    - TestKillClean: after Kill, the session's process is no longer running (cmd.Wait returns)
    - TestKillClean_NoOrphans: spawning a CLI that itself spawns a child ("sh -c 'sleep 300 & cat'"), killing the session, verifying the sleep process is also gone
    - TestKillClean_NotFound: Kill with bad ID returns ErrSessionNotFound
    - TestWin32Input_BasicKeystrokes: ESC[65;30;97;1;0;1_ (key-down for 'a') produces byte 0x61 ('a')
    - TestWin32Input_KeyUpFiltered: ESC[65;30;97;0;0;1_ (key-up, Kd=0) produces no output
    - TestWin32Input_Passthrough: non-ESC bytes pass through unchanged
    - TestWin32Input_IncompleteSequence: partial ESC sequence at buffer end is buffered until next read
  </behavior>
  <action>
    1. Create `internal/pty/cleanup.go` with build tag `//go:build !windows`:
       - `killSession(s *Session) error`:
         - If `s.cmd.Process == nil`, return nil
         - Get pgid (`s.cmd.Process.Pid` — because Setpgid: true, pgid == pid)
         - Send `syscall.Kill(-pgid, syscall.SIGHUP)` for graceful shutdown
         - Start goroutine calling `s.cmd.Wait()`, wait up to 2 seconds via select
         - If timeout, send `syscall.Kill(-pgid, syscall.SIGKILL)`
         - Close PTY: `s.pty.Close()`
         - Call cancel function if set
    2. Create `internal/pty/cleanup_windows.go` with build tag `//go:build windows`:
       - `jobObject` struct with `handle windows.Handle`
       - `newJobObject() (*jobObject, error)`: create Job Object with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`
       - `(j *jobObject) Assign(p *os.Process) error`: assign process to job
       - `(j *jobObject) Close() error`: close handle (triggers kill of all assigned processes)
       - `killSession(s *Session) error`: close the job object handle (if assigned), then close PTY, call cancel
       - Note: Job Object is created and assigned in native.go's Create path when `runtime.GOOS == "windows"`
    3. Create `internal/pty/win32input.go` with build tag `//go:build windows`:
       - `ParseWin32Input(r io.Reader, w io.Writer) error`: streaming parser per Research Pattern 8
       - `parseWin32Chunk(data []byte) (out []byte, remainder []byte)`: stateless chunk parser
       - Handles: ESC detection, CSI sequence finding, parameter extraction (6 semicolon-separated values), key-down filtering (Kd at index 3 must be "1"), Unicode char emission (Uc at index 2)
       - Focus event sequences (`ESC[I`, `ESC[O`) are dropped silently
    4. Create `internal/pty/win32input_other.go` with build tag `//go:build !windows`:
       - `ParseWin32Input(r io.Reader, w io.Writer) error`: simple `io.Copy(w, r)` passthrough
    5. Create `internal/pty/win32input_test.go` (NO build tag — tests the parser logic on all platforms):
       - To test on all platforms, extract `parseWin32Chunk` into a separate file `internal/pty/win32input_parse.go` with NO build tags, and put only the `ParseWin32Input` wrapper in the build-tagged files.
       - `TestWin32Input_BasicKeystrokes`: input `\x1b[65;30;97;1;0;1_` → output `[]byte{0x61}`
       - `TestWin32Input_KeyUpFiltered`: input `\x1b[65;30;97;0;0;1_` → output `[]byte{}` (Kd=0, filtered)
       - `TestWin32Input_Passthrough`: input `"hello"` → output `"hello"` (no ESC sequences)
       - `TestWin32Input_IncompleteSequence`: input `"abc\x1b[65;30"` → output `"abc"`, remainder `"\x1b[65;30"`
       - `TestWin32Input_MixedContent`: input `"pre\x1b[65;30;97;1;0;1_post"` → output `"pre" + 0x61 + "post"`
    6. Update `internal/pty/native.go`: in the Create method, add Session fields for the Job Object on Windows (use an interface or store as `any` to avoid build tag issues in the main file). Wire `killSession` into the `Kill` method.
  </action>

  </verify>
