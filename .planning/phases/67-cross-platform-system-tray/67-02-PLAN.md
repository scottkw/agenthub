**Icon strategy: Runtime PNG-to-HICON conversion** -- reuse the existing PNG assets. No separate .ico files needed.

Implementation of `createIconFromPNG(pngData []byte) (uintptr, error)`:
1. Decode PNG via `image/png` to `image.Image`
2. Get bounds (width, height)
3. Create a BITMAPINFOHEADER for a 32-bit DIB (BGRA format)
4. Call `CreateDIBSection` (gdi32.dll) to create a device-independent bitmap
5. Copy pixel data: for each pixel, convert RGBA to BGRA (swap R and B channels), write into DIB memory
6. Create a monochrome mask bitmap via `CreateBitmap` (gdi32.dll) -- all zeros for fully opaque
7. Build ICONINFO struct: fIcon=TRUE, hbmMask=mask, hbmColor=colorDIB
8. Call `CreateIconIndirect` (user32.dll) to get HICON
9. Clean up intermediate bitmaps via `DeleteObject`
10. Return HICON handle

**Implementation of initTray():**
- Embed icons: `//go:embed assets/tray_icon.png` and `//go:embed assets/tray_icon_error.png`
- Create windowsTray struct, set `globalWinTray = wt`
- Convert PNGs to HICONs: `createIconFromPNG(trayIconBytes)`, `createIconFromPNG(trayIconErrorBytes)`
- If icon creation fails, log warning and set disabled=true, return
- Launch goroutine:
  a. `runtime.LockOSThread()` -- Win32 message pump MUST run on locked OS thread
  b. `GetModuleHandleW(nil)` for hInstance
  c. Register window class "AgentHubTrayClass" with `wndProc` callback via `RegisterClassExW`
  d. Create message-only window with parent HWND_MESSAGE via `CreateWindowExW`
  e. Populate notifyIconData: CbSize, HWnd, UID=1, UFlags=NIF_ICON|NIF_TIP|NIF_MESSAGE, UCallbackMessage=WM_TRAYICON, HIcon, SzTip
  f. Call `Shell_NotifyIconW(NIM_ADD, &nid)` -- if fails, set disabled=true
  g. Close `ready` channel
  h. Enter GetMessage/TranslateMessage/DispatchMessage loop until WM_QUIT
- Main goroutine waits on `<-ready` before returning

**Implementation of wndProc(hwnd, msg, wParam, lParam uintptr) uintptr:**
- `WM_TRAYICON` (msg == WM_TRAYICON):
  - lParam low word == WM_RBUTTONUP: call `showPopupMenu()`
  - lParam low word == WM_LBUTTONDBLCLK: dispatch show callback
- `WM_COMMAND`:
  - Extract menuID = wParam & 0xFFFF
  - menuID == IDM_OPEN: dispatch show callback via goroutine
  - menuID == IDM_QUIT: dispatch quit callback via goroutine
  - menuID >= IDM_SESSION: dispatch session callback with index = menuID - IDM_SESSION via goroutine
- Default: `DefWindowProcW(hwnd, msg, wParam, lParam)`

**Implementation of showPopupMenu():**
- Lock mutex, copy menuItems
- `CreatePopupMenu()`
- For each item: if Separator, `AppendMenuW(hmenu, MF_SEPARATOR, 0, nil)`; else assign ID based on Label ("Open AgentHub"=IDM_OPEN, "Quit"=IDM_QUIT, session=IDM_SESSION+Index), `AppendMenuW(hmenu, MF_STRING, id, utf16Label)`
- `GetCursorPos(&pt)` for position
- `SetForegroundWindow(hwnd)` -- required for correct menu dismissal
- `TrackPopupMenu(hmenu, TPM_BOTTOMALIGN|TPM_LEFTALIGN, pt.X, pt.Y, 0, hwnd, nil)`
- `DestroyMenu(hmenu)`
- Unlock mutex

**Implementation of updateTray(sessions, connected):**
- If disabled, return
- Lock mutex
- Set nid.HIcon = hIcon (connected) or hIconErr (error)
- Encode tooltip: `trayTooltip(len(sessions))` -> UTF-16 -> copy into nid.SzTip
- `Shell_NotifyIconW(NIM_MODIFY, &nid)`
- menuItems = BuildMenuItems(sessions)
- Unlock mutex

**Implementation of cleanupTray():**
- If disabled, return
- `Shell_NotifyIconW(NIM_DELETE, &nid)`
- `DestroyIcon(hIcon)`, `DestroyIcon(hIconErr)`
- `PostMessageW(hwnd, WM_QUIT, 0, 0)` to exit message loop
- `DestroyWindow(hwnd)`

**Implementation of setDockVisible(visible bool):**
- No-op: `// Windows has no Dock equivalent; Wails manages taskbar visibility`

**Callback dispatch pattern** (from wndProc, always via goroutines to avoid blocking the Win32 message thread):
- **Show**: `go func() { if wt.app != nil && wt.app.ctx != nil { runtime.WindowShow(wt.app.ctx); wt.app.setDockVisible(true) } }()`
- **Quit**: `go func() { app := wt.app; if app != nil && app.client != nil { _ = app.client.ShutdownDaemon() }; if app != nil { app.quitting = true; if app.ctx != nil { runtime.Quit(app.ctx) } } }()`
- **Session(idx)**: `go func() { if wt.app == nil || wt.app.ctx == nil { return }; sessions := wt.app.ListSessions(); if idx >= 0 && idx < len(sessions) { runtime.WindowShow(wt.app.ctx); wt.app.setDockVisible(true); runtime.EventsEmit(wt.app.ctx, "tray:focus-session", sessions[idx].ID) } }()`

**Graceful degradation:**
- If D-Bus/Shell_NotifyIcon fails at init, log: `log.Printf("system tray: Shell_NotifyIcon failed, tray icon disabled")`
- Set disabled=true
- All subsequent calls become no-ops

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App -> Win32 Shell API | Tray registers with Windows shell; shell sends WM messages to the hidden window |
| WM_COMMAND -> App callbacks | Menu item clicks from the shell dispatch to app actions (show, quit, focus session) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-05 | Spoofing | WM_TRAYICON messages | accept | Only the Windows shell sends messages to the message-only window (HWND_MESSAGE). Other apps cannot post to it without the HWND. Low risk for a desktop app. |
| T-67-06 | Tampering | WM_COMMAND menu IDs | mitigate | Validate menu item ID bounds in wndProc: session index = wParam - IDM_SESSION must be >= 0 and < len(menuItems). Prevents out-of-bounds access. |
| T-67-07 | Denial of Service | Win32 message flood | accept | Windows message queue has OS-level limits. Message-only window processes only tray events. Low risk. |
| T-67-08 | Information Disclosure | Session names in popup menu | accept | Session names visible to local user only. Same data shown in the GUI window. Same privilege level. |
</threat_model>
