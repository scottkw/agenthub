## Phase 15 UI Scope

Phase 15 has one focused frontend change: modify `SettingsPanel.tsx` → Web Server tab.

### What changes
1. **Remove** the Network Interface dropdown (`settings-panel__select`, `GetNetworkInterfaces` call, `selectedInterface` state)
2. **Remove** the CA Certificate section from the Security tab (no CA cert after TLS-05)
3. **Add** CT Disclosure banner to the Web Server tab — one-time acknowledgement gate before "Start Web Server" is enabled
4. **Change** `StartWebServer` call signature from `StartWebServer(selectedInterface, selectedPort)` to `StartWebServer(selectedPort)`
5. **Update** Wails binding imports: remove `GetNetworkInterfaces`, `GetCACertPath`; add `HasCTDisclosure`, `AcknowledgeCTDisclosure`

### What stays
- Port input (unchanged)
- Start/Stop Web Server button (logic unchanged; gate condition changes)
- Server running URL display
- CLI Paths tab (untouched)
- Security tab password section (untouched — auth removal is Phase 16)

## Interaction States

### "Start Web Server" button gate (updated logic)

| Condition | Button State |
|-----------|-------------|
| CT disclosure not acknowledged | Disabled + `title="Acknowledge the Certificate Transparency disclosure first"` |
| CT acknowledged + server not running | Enabled (accent blue fill) |
| Server starting | Disabled + label "Starting…" |
| Server running | Enabled (cancel style) + label "Stop Web Server" |
| Server stopping | Disabled + label "Stopping…" |

**Note:** Password gate is removed from this button in Phase 15 (auth removal is Phase 16; keep password gate logic for now — the executor must retain `!isPasswordSet` in the disabled condition alongside the CT gate).

### CT Disclosure interaction

1. Banner displays with "I Understand" button
2. User clicks "I Understand" → calls `AcknowledgeCTDisclosure()` → on success, banner transitions to acknowledged state (green checkmark row)
3. On next panel open, `HasCTDisclosure()` returns true → banner shows acknowledged state immediately (no loading flash)

### Error display

- `serverError` string displayed as `<p className="settings-panel__error">` below the Start/Stop button — unchanged pattern
- CT acknowledgement error (if `AcknowledgeCTDisclosure()` fails): display as `.settings-panel__error` below the CT banner
