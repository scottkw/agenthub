## Decisions Made
- Trigger: `release:published` over `push:tags` — tag push fires before artifacts exist in release; `release:published` fires after `softprops/action-gh-release` has uploaded all assets
- SHA256 source: parse `checksums.txt` (already generated by Phase 46's publish job) rather than re-downloading DMG — avoids binary download, avoids notarization timing window
- sed pattern: `[^"]*` instead of literal version string — dots are regex metacharacters; character class is safe
- Empty commit guard: `git diff --cached --quiet` exit 0 — prevents workflow failure if formula already reflects current version
