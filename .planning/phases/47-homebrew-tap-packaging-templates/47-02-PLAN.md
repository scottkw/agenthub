Create `.github/workflows/distribute.yml` with the following exact content:

```yaml
name: Distribute

on:
  release:
    types: [published]

jobs:
  update-homebrew-tap:
    runs-on: ubuntu-latest
    steps:
      - name: Extract version
        id: version
        run: |
          VERSION="${GITHUB_REF_NAME#v}"
          echo "version=${VERSION}" >> "$GITHUB_OUTPUT"
          echo "tag=${GITHUB_REF_NAME}" >> "$GITHUB_OUTPUT"

      - name: Download checksums with retry
        uses: nick-fields/retry@v3
        with:
          timeout_seconds: 30
          max_attempts: 5
          retry_wait_seconds: 60
          command: |
            curl -fsSL \
              "https://github.com/scottkw/agenthub/releases/download/${{ github.ref_name }}/checksums.txt" \
              -o checksums.txt

      - name: Extract DMG SHA256
        id: sha256
        run: |
          SHA256=$(grep "agenthub-${{ github.ref_name }}-darwin-universal.dmg" checksums.txt | awk '{ print $1 }')
          if [ -z "$SHA256" ]; then
            echo "ERROR: SHA256 not found in checksums.txt"
            cat checksums.txt
            exit 1
          fi
          echo "sha256=${SHA256}" >> "$GITHUB_OUTPUT"

      - name: Checkout tap repo
        uses: actions/checkout@v4
        with:
          repository: scottkw/homebrew-agenthub
          token: ${{ secrets.TAP_DEPLOY_TOKEN }}
          path: tap

      - name: Update cask formula
        run: |
          VERSION="${{ steps.version.outputs.version }}"
          SHA256="${{ steps.sha256.outputs.sha256 }}"
          sed -i "s/version \"[^\"]*\"/version \"${VERSION}\"/" tap/Casks/agenthub.rb
          sed -i "s/sha256 \"[^\"]*\"/sha256 \"${SHA256}\"/" tap/Casks/agenthub.rb

      - name: Commit and push formula update
        run: |
          cd tap
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add Casks/agenthub.rb
          git diff --cached --quiet && echo "No changes to commit" && exit 0
          git commit -m "agenthub ${{ steps.version.outputs.version }}"
          git push
```

Key design decisions and pitfall avoidance:
- `on: release: types: [published]` -- NOT `on: push: tags:` (Pitfall 1: tag push fires before artifacts are uploaded)
- `nick-fields/retry@v3` with 5 attempts and 60s wait -- handles CDN propagation delay after release.yml completes
- Uses `${{ github.ref_name }}` in curl URL (resolves to tag like `v1.8.0`) -- GITHUB_REF_NAME env var also works but context expression is more explicit in YAML
- grep pattern `agenthub-${{ github.ref_name }}-darwin-universal.dmg` matches checksums.txt exactly (tag includes `v` prefix)
- sed pattern `[^"]*` avoids regex metacharacter issues with dots in version strings (Pitfall 3)
- `awk '{ print $1 }'` handles variable spacing in sha256sum output (Pitfall 4)
- `git diff --cached --quiet` guard prevents empty commit error if formula already up to date
- No re-download of the DMG binary -- SHA256 extracted from checksums.txt (Don't Hand-Roll: cross-platform SHA256)
- Uses `TAP_DEPLOY_TOKEN` (classic PAT with repo scope) for cross-repo push -- GITHUB_TOKEN cannot push to other repos

Two manual steps are required before the distribute.yml workflow can function:

1. **Create the tap repo:** Go to https://github.com/new and create `homebrew-agenthub` under the `scottkw` account. Settings: Public, initialize with README. The name MUST be `homebrew-agenthub` (not `agenthub-tap` or `agenthub`) -- Homebrew's `brew tap scottkw/agenthub` short form requires the `homebrew-` prefix.

2. **Create initial Casks/agenthub.rb in the tap repo:** After creating the repo, create `Casks/agenthub.rb` with placeholder content (this is the file distribute.yml will update via sed). Use the GitHub UI or git clone. Content:

```ruby
cask "agenthub" do
  version "0.0.0"
  sha256 "placeholder"

  url "https://github.com/scottkw/agenthub/releases/download/v#{version}/agenthub-v#{version}-darwin-universal.dmg"
  name "AgentHub"
  desc "AI coding session manager with tabbed terminals and Tailscale web access"
  homepage "https://github.com/scottkw/agenthub"

  depends_on macos: ">= :ventura"

  app "agenthub.app"

  zap trash: [
    "~/Library/Application Support/agenthub",
    "~/Library/Preferences/com.scottkw.agenthub.plist",
    "~/Library/Caches/com.scottkw.agenthub",
    "~/Library/Logs/agenthub",
  ]
end
```

3. **Create TAP_DEPLOY_TOKEN secret:** Go to https://github.com/settings/tokens and generate a classic PAT with `repo` scope. Then go to https://github.com/scottkw/agenthub/settings/secrets/actions and add it as `TAP_DEPLOY_TOKEN`. MUST be a classic PAT (fine-grained PATs are incompatible with cross-repo push).
