<objective>
Generalize `internal/webserver/vendor_drift_test.go` from its current addon-fit-only regex into a load-bearing CI gate that enforces version parity between `frontend/pnpm-lock.yaml` and `web/vendor/xterm/VERSION` for **every** `@xterm/addon-*` package vendored under `web/vendor/xterm/`.

Purpose: Phase 93 ships three additional vendored addons (webgl, unicode11, clipboard) and Phases 94–98 will add five more. Without a generalized gate, a `pnpm update` that bumps an addon version in the lockfile but forgets to re-copy the vendored `.js` would ship silently. WEB-02 closes this loop.

Output: A modified `vendor_drift_test.go` whose regex captures every `@xterm/addon-*` line in pnpm-lock and whose minimum-count guard requires ≥ 5 packages (xterm + addon-fit + the three Phase 93 addons). Plan 93-02 ships the three new VERSION lines that this gate will then enforce.
