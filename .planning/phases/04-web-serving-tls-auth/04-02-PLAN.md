<task type="auto" tdd="true">
  <name>Task 1: Password hashing and cookie session auth</name>
  <files>internal/webserver/auth.go, internal/webserver/auth_test.go</files>
  <behavior>
    - TestHashPassword: HashPassword("test123") returns a bcrypt hash that bcrypt.CompareHashAndPassword succeeds against
    - TestCheckPassword: CheckPassword(hash, "test123") returns true; CheckPassword(hash, "wrong") returns false
    - TestAuthManagerSetPassword: SetPassword stores bcrypt hash; IsPasswordSet returns true after set, false before
    - TestAuthManagerLogin: Login with correct password returns a session cookie value (non-empty string); Login with wrong password returns empty string and error
    - TestAuthManagerIsAuthenticated: after Login, IsAuthenticated with the returned cookie returns true; random cookie returns false; empty cookie returns false
    - TestSessionCookieProperties: cookie name is "agenthub_session", httpOnly=true, secure=true, sameSite=Strict, path="/"
  </behavior>
  <action>
Implement in `auth.go`:

1. `HashPassword(plaintext string) ([]byte, error)` -- `bcrypt.GenerateFromPassword([]byte(plaintext), bcrypt.DefaultCost)`.

2. `CheckPassword(hash []byte, plaintext string) bool` -- `bcrypt.CompareHashAndPassword(hash, []byte(plaintext)) == nil`.

3. `type AuthManager struct` with fields:
   - `mu sync.RWMutex`
   - `passwordHash []byte` (bcrypt hash of dashboard password)
   - `sessions map[string]time.Time` (cookie value -> creation time)

4. `NewAuthManager() *AuthManager` -- initializes with empty sessions map.

5. `(am *AuthManager) SetPassword(plaintext string) error` -- hashes and stores.

6. `(am *AuthManager) LoadPasswordHash(hash []byte)` -- loads pre-existing hash (from config file).

7. `(am *AuthManager) IsPasswordSet() bool` -- returns true if passwordHash is non-nil.

8. `(am *AuthManager) Login(plaintext string) (cookieValue string, err error)` -- checks password, if correct generates a 32-byte random cookie via `crypto/rand.Read` + `base64.RawURLEncoding.EncodeToString`, stores in sessions map, returns value. If wrong, returns `"", ErrInvalidPassword`.

9. `(am *AuthManager) IsAuthenticated(cookieValue string) bool` -- checks sessions map.

10. `(am *AuthManager) MakeSessionCookie(value string) *http.Cookie` -- returns `&http.Cookie{Name: "agenthub_session", Value: value, HttpOnly: true, Secure: true, SameSite: http.SameSiteStrictMode, Path: "/"}`.

11. `var ErrInvalidPassword = errors.New("invalid password")`.

Use `golang.org/x/crypto/bcrypt` (already a transitive dep in go.sum via Wails). Do NOT store passwords in plaintext. Do NOT use sequential IDs for session cookies (use crypto/rand per research anti-patterns).

<task type="auto" tdd="true">
  <name>Task 2: Opaque token generation and session-scoped lookup</name>
  <files>internal/webserver/tokens.go, internal/webserver/tokens_test.go</files>
  <behavior>
    - TestGenerateToken: returns a non-empty string, two calls return different values
    - TestTokenStoreCreateAndLookup: Create(sessionID) returns token; Lookup(token) returns (sessionID, true)
    - TestTokenStoreLookupInvalid: Lookup("nonexistent") returns ("", false)
    - TestTokenStoreRevoke: after Revoke(token), Lookup returns false
    - TestTokenStoreRevokeBySession: RevokeBySession(sessionID) removes all tokens for that session; Lookup returns false for all of them
    - TestTokenStoreMultiplePerSession: can create multiple tokens for same session; each maps correctly
    - TestTokenLength: generated token base64 string is 43 chars (32 bytes base64url-encoded without padding)
  </behavior>
  <action>
Implement in `tokens.go`:

1. `func GenerateToken() (string, error)` -- `rand.Read` 32 bytes, `base64.RawURLEncoding.EncodeToString`. Return error if rand.Read fails (let it crash per project conventions -- no silent fallback).

2. `type TokenStore struct` with fields:
   - `mu sync.RWMutex`
   - `tokenToSession map[string]string` (token -> sessionID)
   - `sessionToTokens map[string][]string` (sessionID -> []token, for bulk revocation)

3. `NewTokenStore() *TokenStore` -- initializes both maps.

4. `(ts *TokenStore) Create(sessionID string) (string, error)` -- generates token, stores in both maps.

5. `(ts *TokenStore) Lookup(token string) (sessionID string, ok bool)` -- reads tokenToSession under RLock.

6. `(ts *TokenStore) Revoke(token string)` -- removes from tokenToSession, removes from sessionToTokens slice.

7. `(ts *TokenStore) RevokeBySession(sessionID string)` -- removes all tokens for session from both maps.

8. `(ts *TokenStore) TokensForSession(sessionID string) []string` -- returns copy of tokens for a session (used by UI to display existing tokens).

Use `crypto/rand` only -- never `math/rand`. Token is opaque random value that maps to sessionID internally (per Pitfall 6 in research -- never expose sessionID in URL).
