<task type="auto">
  <name>Task 1: Wails App integration with WebServer</name>
  <files>app.go, app_test.go</files>
  <action>
Add a `webServer *webserver.WebServer` field to the App struct. Update NewApp to NOT create the WebServer yet (it needs config from settings). Add the following Wails-bound methods:

1. `(a *App) SetWebPassword(password string) error` -- calls `a.webServer.auth.SetPassword(password)`. If webServer not yet initialized, create it lazily with default config. Persist the bcrypt hash to `~/.config/agenthub/web_password` file so it survives restarts.

2. `(a *App) IsWebPasswordSet() bool` -- checks if password hash exists (in memory or on disk).

3. `(a *App) GetNetworkInterfaces() []webserver.NetworkInterface` -- calls `webserver.ListInterfaces()`, returns the list. Frontend uses this for the dropdown.

4. `(a *App) StartWebServer(bindIP string, port int) error` -- creates WebServer with Config{BindIP: bindIP, Port: port, ConfigDir: configDir()}, loads persisted password hash, calls Start(). Returns error if password not set (gate web serving behind password setup per research recommendation #3).

5. `(a *App) StopWebServer() error` -- calls webServer.Stop(), sets webServer to nil.

6. `(a *App) ToggleWebServing(sessionID string, enabled bool) error` -- if enabled, calls webServer.EnableSession(sessionID); if disabled, calls webServer.DisableSession(sessionID). Returns error if web server not running.

7. `(a *App) GenerateSessionToken(sessionID string) (string, error)` -- calls webServer.tokens.Create(sessionID), returns full URL `https://bindIP:port/sessions/{id}?token=xxx`.

8. `(a *App) GetWebServerURL() string` -- returns webServer.BaseURL() or empty string if not running.

9. `(a *App) GetCACertPath() string` -- returns `webserver.ExportCACertPath(configDir())`.

10. `(a *App) IsWebServerRunning() bool` -- returns whether webServer is non-nil and listener is active.

Helper: `func configDir() string` -- returns `~/.config/agenthub` (use `os.UserConfigDir()` + "/agenthub"). Create with `os.MkdirAll(dir, 0700)`.

Update `shutdown()` to also call `webServer.Stop()` if running.

Update app_test.go: test SetWebPassword persists and reloads, test GetNetworkInterfaces returns non-empty, test ToggleWebServing errors when server not running, test StartWebServer errors when password not set.
  </action>
