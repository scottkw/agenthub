# Phase 131 — UI Design Contract

> Visual and interaction contract for Phase 131: Hub Foundation + Static Session Cards.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn — Vue 3 + React hybrid, hand-rolled BEM CSS) |
| Preset | not applicable |
| Component library | Heroicons (already used in Sidebar.tsx and throughout the app) |
| Icon library | @heroicons/react/24/outline (already installed) |
| Font | system-ui (UI labels); "Cascadia Code", "MesloLGS NF", "Fira Code", monospace (badges/code) |

**Design system note:** The app uses a hand-rolled BEM CSS pattern throughout `style.css` with
TokyoNight Night as the base palette. There is no app-level light/dark UI theme switcher today.
Phase 131 introduces CSS custom properties on `.hub` so the surface can be themed independently.
The dark theme is the default; the light theme variant (`.hub--light` or `[data-theme="light"] .hub`)
is defined in the same block for HUB-04 compliance. No new third-party CSS framework is introduced.

## Theme Contract

custom properties rather than hardcoded hex values. The `:root` block defines the dark defaults;
a `[data-ui-theme="light"]` block (added to `<html>` by future UI-theme toggle) overrides them.
The Terminal theme (xterm palette) is separate — it is NOT affected by this UI theme contract.

## Color

### 60/30/10 Split

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--hub-bg)` = `#1a1b26` dark / `#f5f5f7` light | Hub canvas background |
| Secondary (30%) | `var(--hub-surface)` = `#16161e` dark / `#ffffff` light | Card surfaces, group headers |
| Accent (10%) | `var(--hub-accent)` = `#7aa2f7` dark / `#3d6fe8` light | See reserved list below |
| Destructive | `var(--hub-destructive)` = `#f7768e` dark / `#c0394f` light | Error exit-code text only |

**Accent reserved for ONLY these elements in Phase 131:**
1. Active filter pill background + border
2. Search input focus ring (2px outline, 2px offset)
3. Inline session-name rename input border (mirrors `.tab__rename-input`)
4. Card focus ring (keyboard navigation — 2px outline, 2px offset)
5. The Hub sidebar item active/selected state indicator

Accent is NOT used for: card borders at rest, metadata text, badges, group headers.

### Status Indicator Color Tokens (shape + icon — not color alone)

Each status MUST be differentiated by its ICON and SHAPE, not by color alone (user is colorblind).
The color below is a reinforcing signal only.

Dark-theme dot values (on `#1a1b26` / `#16161e` backgrounds):

| Status | Icon (Heroicons) | Shape | Dark hex | Text label |
|--------|-----------------|-------|----------|------------|
| running | `ArrowPathIcon` (spinning) | Circle | `#3b82f6` | "Running" |
| idle | `CheckCircleIcon` (static) | Circle with check | `#22c55e` | "Idle" |
| waiting | `PauseCircleIcon` | Circle with pause bars | `#f59e0b` | "Needs input" |
| errored | `ExclamationCircleIcon` | Circle with ! | `#ef4444` | "Error" |
| stopped (exit 0) | `StopCircleIcon` (dimmed) | Circle with square | `#565f89` | "Done" |
| stopped (exit ≠ 0) | `ExclamationCircleIcon` | Circle with ! | `#f7768e` | "Exited \{code\}" |

Light-theme dot values (on `#ffffff` / `#f5f5f7` backgrounds — WCAG AA on white):

| Status | Light hex | Contrast on white | WCAG AA |
|--------|-----------|-------------------|---------|
| running | `#1d4ed8` | 7.1:1 | passes AAA |
| idle | `#1a7f37` | 5.0:1 | passes AA |
| waiting | `#92400e` | 7.6:1 | passes AAA |
| errored | `#b91c1c` | 6.0:1 | passes AA |
| stopped (exit 0) | `#4b5563` | 7.0:1 | passes AAA |
| stopped (exit ≠ 0) | `#c0394f` | 4.7:1 | passes AA |

**Source-level hex verification rule:** The hex constants above are the authoritative source of
truth. UAT must verify by reading the hex constant in the source file — never by inspecting

### Dimmed Card State (CARD-08)

Stopped/exited (exit code 0) cards apply `opacity: var(--hub-dim-opacity)` (dark: `0.45`)
to the entire card. A "Done" label + stop icon carries the state beyond opacity.
Error-exit cards are NOT dimmed — they receive full opacity + the ExclamationCircleIcon.

## Interaction Contract

### Session Card — Normal State

| Trigger | Response |
|---------|----------|
| Card hover | Border changes to `var(--hub-border-hover)`, background lifts to `var(--hub-surface-elevated)` |
| Card click (any area) | No action in Phase 131 — card click is out of scope (Phase 134 adds modal) |
| Card keyboard focus (Tab) | 2px `var(--hub-accent)` focus ring, offset 2px |
| Session name click | Enters inline edit mode (InlineSessionName) — mirrors TabBar rename |
| Inline name Enter | Commits rename via `RenameSession` RPC, exits edit mode |
| Inline name Escape | Cancels rename, restores original name |
| Inline name blur | Commits rename if content changed; cancels if unchanged |

### Filter Bar

| Trigger | Response |
|---------|----------|
| Filter pill click | Activates pill (accent bg + border), deactivates previous, grid re-filters |
| "/" keydown (Hub surface focused) | Focuses search input, selects existing text |
| Search input: type | Filters cards in real-time by name, CLI name, or hostname |
| Search input: clear (Escape) | Clears search text, returns focus to Hub grid |
| "New session" button click | Opens NewSessionModal (existing modal, no changes needed) |

### Stopped/Dimmed Cards (CARD-08)

| State | Rendering |
|-------|-----------|
| Stopped, exit 0 | Entire card at `opacity: var(--hub-dim-opacity)` (0.45), "Done" label, StopCircleIcon |
| Stopped, exit ≠ 0 | Full opacity, ExclamationCircleIcon, "Exited {code}" red chip — NOT dimmed |

### Hub Panel Error State (session-list polling failure)

| State | Rendering |
|-------|-----------|
| Polling failed | Replace grid with centered error state: ExclamationCircleIcon + "Couldn't load sessions" heading (16px/600) + "Check that the daemon is running and try again." body (12px/400) + "Retry" button (triggers re-poll) |

### Keyboard Navigation (Phase 135 will harden, but Phase 131 must not block)

| Key | Behavior |
|-----|---------|
| Tab | Moves focus through cards in DOM order |
| Shift+Tab | Reverse |
| Enter or Space on card | No-op in Phase 131 (modal is Phase 134); card must receive focus without activating |
| "/" | Focus search |
| Escape (search focused) | Clear and blur search |

## Accessibility Contract

Phase 131 must lay the foundation. Phase 135 will audit and harden. Rules that are REQUIRED
for Phase 131:

1. Every status indicator MUST have a visible text label in addition to its icon and color.
   The color dot alone is NEVER acceptable — the user is colorblind.

2. All color pairs used for text must meet WCAG AA (4.5:1 for normal text, 3:1 for large text):
   - `#c0caf5` on `#1a1b26` ≈ 14.3:1 — passes AAA
   - `#9aa5ce` on `#1a1b26` ≈ 8.0:1 — passes AAA
   - `#a9b1d6` on `#1a1b26` ≈ 9.5:1 — passes AAA
   - `#f7768e` on `#1a1b26` ≈ 5.2:1 — passes AA
   - `#7aa2f7` on `#1a1b26` ≈ 6.0:1 — passes AA (links/accent text only)

3. Filter pills and interactive card elements must be keyboard-operable with visible focus rings.

4. `aria-label` on the search input: `"Search sessions by name, CLI, or host"`.

5. `aria-label` on each card: `"{name}, {status}, {cli}, {origin}"` (dynamically composed).

6. `role="list"` on the card grid, `role="listitem"` on each group's card row.

7. Group headers must use `<h2>` or `role="heading" aria-level="2"` semantics.

8. `prefers-reduced-motion` fallback for the `ArrowPathIcon` spin on "Running" cards:
   replace with a static icon when motion is reduced (Phase 135 hardens; Phase 131 must
   wrap animation in `@media (prefers-reduced-motion: no-preference)`).

9. Status icons must carry `aria-label` with their status text (e.g., `aria-label="Running"`).

## Motion Contract

Only motion allowed in Phase 131:

| Element | Motion | Duration | Easing |
|---------|--------|----------|--------|
| Filter pill selection | Background color transition | 100ms | ease |
| Card hover | Border color + background transition | 100ms | ease |
| Inline rename input appear | No animation — instant |
| "Running" status icon spin | CSS animation | 0.8s linear infinite |

All animations must be wrapped in `@media (prefers-reduced-motion: no-preference)`.
Under `prefers-reduced-motion: reduce`: no spin, no transitions — static states only.

Phase 131 does NOT introduce: pulse animations, scroll animations, or card position transitions.
Those are Phase 133 (Attention + Pulse).
