## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-131-03 | Tampering (XSS) | session name / hostname rendered in SessionCard | mitigate | Render only via JSX text children and aria-label string interpolation — never dangerouslySetInnerHTML. React escapes text by default, neutralizing script injection via crafted names/hostnames. |
| T-131-04 | Information disclosure | peer hostname shown on remote card origin marker | accept | Hostname is the user's own tailnet peer identity, already visible in the existing Remote Sessions panel; no new exposure. |
| T-131-05 | Tampering | npm installs | accept | No new packages (Heroicons already installed; RESEARCH audit: none). |
