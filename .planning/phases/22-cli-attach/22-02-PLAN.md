```go
func setupAttachTest(t *testing.T) (serverURL string, mgr *relay.HubManager, ptyWrite *io.PipeWriter, inputRead *io.PipeReader, sessionID string) {
    t.Helper()
    ptyOutputR, ptyOutputW := io.Pipe()
    inputCaptureR, inputCaptureW := io.Pipe()
    const sid = "attach-test-session"
    mgr = relay.NewHubManager()
    mgr.Create(sid, ptyOutputR, inputCaptureW, nil)
    srv := httptest.NewServer(relay.NewServer(mgr, nil))
    t.Cleanup(func() {
        srv.Close()
        mgr.Shutdown()
        ptyOutputW.Close()
        inputCaptureW.Close()
    })
    return srv.URL, mgr, ptyOutputW, inputCaptureR, sid
}
```

1. **TestCmdAttach_MissingArgs** (CLI-05)
   - Call `cmdAttach(client, []string{})` where client is from `testSetup(t)`
   - Assert error is non-nil
   - Assert error string contains "usage"

2. **TestMakeClientResizeFrame** (CLI-06)
   - Call `makeClientResizeFrame(120, 40)`
   - Assert result is `[]byte{0x11, 0, 120, 0, 40}` — first byte is `relay.MsgResize2` (0x11), NOT `relay.MsgResize` (0x02)
   - Test edge case: `makeClientResizeFrame(256, 512)` verifies big-endian encoding: `[]byte{0x11, 1, 0, 2, 0}`

3. **TestAttachSession_DetachKey** (CLI-07)
   - Setup: `setupAttachTest(t)` to get server URL, dial WebSocket from test
   - Create a `bytes.Buffer` for stdout
   - Create an `io.Pipe` for stdin — write the detach key byte (0x1C) to the pipe
   - Call `attachSession(ctx, conn, stdinReader, &stdout, 0x1C)` in a goroutine
   - Assert: attachSession returns nil (clean detach, no error)
   - Assert: returns within 5 seconds (not stuck)

4. **TestAttachSession_OutputReceived** (CLI-05, CLI-08)
   - Setup: `setupAttachTest(t)`, write "hello world" to ptyWrite BEFORE dialing (creates scrollback)
   - Small sleep (20ms) to let hub process
   - Dial WebSocket, create bytes.Buffer for stdout
   - Run `attachSession` with a context that cancels after 500ms
   - Assert: stdout buffer contains "hello world" (scrollback replayed)

5. **TestAttachSession_LiveOutput** (CLI-05)
   - Setup: `setupAttachTest(t)`, dial WebSocket
   - Start `attachSession` in goroutine with cancel context
   - Write "live data" to ptyWrite after small delay
   - Wait for stdout to contain "live data" (poll with timeout)
   - Cancel context to stop

6. **TestAttachSession_CtrlCPassthrough** (CLI-06)
   - Setup: `setupAttachTest(t)`, dial WebSocket
   - Create io.Pipe for stdin, bytes.Buffer for stdout
   - Start `attachSession` in goroutine
   - Write byte 0x03 (Ctrl-C) to stdin pipe
   - Read from inputRead (the PTY input capture pipe) — assert received data contains byte 0x03
   - This proves Ctrl-C was forwarded as a raw byte, not intercepted as a signal

7. **TestAttachSession_InputForwarded** (CLI-06)
   - Setup: `setupAttachTest(t)`, dial WebSocket
   - Write "hello" to stdin pipe
   - Read from inputRead — assert received bytes equal "hello"
   - This proves keyboard input reaches the PTY

**Important test considerations:**
- Use `context.WithTimeout` or `context.WithCancel` to prevent tests from hanging
- All timeouts should be 5 seconds max
- Use `t.Helper()` in all helper functions
- The relay server's read pump parses MsgInput frames and calls `hub.WriteInput(payload)`, which writes to the inputCaptureW pipe — so reading from inputCaptureR gives the raw bytes the PTY would receive
- For WebSocket dial in tests, use the same pattern as relay/server_test.go: `"ws" + strings.TrimPrefix(serverURL, "http") + "/sessions/" + sessionID + "/ws"`
