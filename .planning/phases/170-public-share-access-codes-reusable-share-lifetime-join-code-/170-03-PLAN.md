<objective>
Surface the reusable public read code in the Share modal's INTERNET (PUBLIC) section, reusing the existing
`<CodeDisplay>` component the Read-Only and Full-Access sections already render. This closes the FNL-08 UAT
dead-end: a recipient who cannot scan the QR or paste the long capability URL now has a short code to type at
`/join`, and (because 170-01/170-02 made it reusable + share-lifetime) multiple viewers can use it until the
share is disabled.

Purpose: The PUBLIC section (SessionSharePanel.tsx:313-382) shows a URL + QR + disable button today but no code
row — the one gap. The daemon already returns the code on `IssueCapabilities`; this plan threads it to the UI.
Output: models.ts sync + the code row + modal state wiring + a component test.

## Artifacts this plan produces
- `publicReadCode` on `models.ts` `IssueCapabilitiesResponse` (class field + constructor assignment)
- `publicReadCode?: string | null` prop on `SessionSharePanel` + a `<CodeDisplay>` row in the Internet block
- `publicReadCode` state in `SessionShareModal`, set in the warm-up effect, cleared on disable, passed as prop
- Extended `SessionSharePanel.test.tsx`

## UI label (resolves RESEARCH Open Question 3 + locked decision 7)
Use a label that signals reusability and differs from the bare single-use "Join code:" — render
`<CodeDisplay label="Public join code (reusable):" code={publicReadCode} />`. This sets recipient expectations
(multiple viewers may use it) versus the single-use RO/Full-Access codes.
</objective>
