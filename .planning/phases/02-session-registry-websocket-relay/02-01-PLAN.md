<task type="auto" tdd="true">
  <name>Task 2: Per-session fan-out Hub with drain goroutine</name>
  <files>internal/relay/hub.go, internal/relay/hub_test.go</files>
  <behavior>
    - Hub.Subscribe adds a subscriber; Hub.Unsubscribe removes it
    - Hub.Run drains io.Reader, wraps each read in MakeOutputFrame, appends to scrollback, broadcasts to all subscribers
    - Two subscribers both receive the same output frame from a single PTY read
    - A slow subscriber (full channel) triggers closeSlow callback and does not block other subscribers
    - Hub.Shutdown closes done channel; Run goroutine returns on reader EOF
    - Hub.WriteInput writes raw bytes to the session (io.Writer)
    - Hub.ScrollbackSnapshot returns current scrollback contents for replay
  </behavior>
  <action>
Create `internal/relay/hub.go`:
- `Subscriber` struct: `Msgs chan []byte` (buffered, 256), `CloseSlow func()`
- `Hub` struct: `sessionID string`, `reader io.Reader`, `writer io.Writer`, `scrollback *Scrollback`, `mu sync.Mutex`, `subscribers map[*Subscriber]struct{}`, `done chan struct{}`, `closed bool`
- `NewHub(sessionID string, reader io.Reader, writer io.Writer, scrollbackBytes int) *Hub`
- `Run()` — the drain goroutine: reads from reader in 32KB chunks, calls `MakeOutputFrame`, appends to scrollback, broadcasts via non-blocking select (slow client gets `go sub.CloseSlow()`)
- `Subscribe(sub *Subscriber)` — adds to map under lock
- `Unsubscribe(sub *Subscriber)` — removes from map under lock
- `Shutdown()` — marks closed, closes done channel
- `WriteInput(data []byte) error` — writes raw bytes to writer (the PTY stdin)
- `ScrollbackSnapshot() []byte` — delegates to scrollback.Snapshot()
- `Done() <-chan struct{}` — returns done channel for select

Hub.Run returns when reader returns an error (EOF from PTY close). On return, it calls Shutdown().

Tests use `io.Pipe` as the PTY substitute. Write tests first, then implement.

**Critical anti-patterns from research (do NOT violate):**
- Only one goroutine may call reader.Read (the drain goroutine)
- Subscribe BEFORE Snapshot to avoid the subscribe-after-snapshot race
- Non-blocking send in broadcast: `select { case sub.Msgs <- frame: default: go sub.CloseSlow() }`
  </action>
