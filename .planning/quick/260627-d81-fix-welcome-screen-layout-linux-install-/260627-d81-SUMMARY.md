# Phase quick-260627-d81 Plan 01: Fix Welcome Screen Layout (Linux Install) Summary

**One-liner:** CSS-only fix — `min-width:0; overflow-wrap:anywhere; white-space:normal` on `.welcome-tab__code` so the long Linux curl URL wraps in-box instead of forcing the Linux install row wider than macOS/Windows.

## What Was Built

Added three CSS properties to the `.welcome-tab__code` rule in `frontend/src/style.css` (lines 2017-2029):

- `min-width: 0` — overrides `min-width: auto` flex default; allows the `flex: 1` box to shrink below its content's min-content width, so all three install boxes settle at the same width.
- `overflow-wrap: anywhere` — permits the space-free Linux curl URL to break and wrap inside the box rather than forcing the row wider.
- `white-space: normal` — defensive explicit declaration ensuring no inherited `nowrap` prevents wrapping.

No changes to `WelcomeTab.tsx` or any install command strings.
