In `frontend/src/style.css`, add the following CSS rule immediately after the `.sidebar__item:hover` block (after line 207, before the `.sidebar__icon` block that starts at line 209):

```css
.sidebar--collapsed .sidebar__item {
  justify-content: center;
  padding: 8px 0;
}
```

This rule:
- `justify-content: center` — centers the lone SVG icon horizontally within the full-width button (overriding the `flex-start` default that was correct when a label followed the icon)
- `padding: 8px 0` — removes horizontal padding so the centering reference is the full 48px rail, not the 32px content box that `padding: 8px` would produce. Vertical padding (8px top/bottom) is retained to preserve touch target height.

Do NOT modify any other CSS rules. Do NOT touch `.sidebar__toggle` (it is already correctly centered with its own explicit `justify-content: center`). The selector `.sidebar--collapsed .sidebar__item` correctly excludes `.sidebar__toggle` because it has a different class name.
