| T-65-02 | Information Disclosure | Theme name in localStorage | accept | Theme name is a non-sensitive aesthetic preference string. No PII, no credentials, no session tokens. |
| T-65-03 | Spoofing | select onChange event | accept | The <select> is populated from `Object.keys(xtermThemes)` — a fixed set of 246 known keys. Even if a crafted value were injected, the fallback to DEFAULT_THEME_NAME prevents any issue. |
