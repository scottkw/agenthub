## Tech Debt (6 items, all polish-grade)

See `.planning/v3.2-RELEASE-BLOCKERS.md` for the discovery context (cross-phase Wails-only UAT walkthrough, commit `aa0389f`, 2026-05-11).

### Phase 95 — Web Links

- **P-1 (Major, spec gap)**: `mailto:` URLs not detected as clickable despite the documented scheme allowlist `[https, http, mailto]`.
- **P-2 (Major, security-relevant)**: Cyrillic IDN spoof URLs (e.g. `https://gооgle.com`) are silently inert — defensive-by-accident, but the spec-mandated IDN confirmation popover is unreachable.

### Phase 94 — Search

- **P-3 (Major, usability)**: Find bar will not dismiss after clicking the case-sensitive toggle (Esc + close button both stop working). Workaround = restart app.
- **P-4 (Minor, cosmetic)**: Find bar slide-OUT animation missing on Esc / close. Slide-IN works correctly.

### Phase 96 — Image

- **P-5 (Side observation)**: iTerm2 IIP protocol does not render — sixel renders correctly. Confirm sixel-only intent vs audit `iipSupport` option on `ImageAddon` construction.

### Cross-cutting (no phase ownership)

- **P-6 (Test-env debt, no prod impact)**: 20 tests in `Sidebar.test.tsx` fail under Vitest 4 + jsdom 29 due to `localStorage` not being projected as a global. Single-line setupFile fix. Pre-existing since Phase 70.
