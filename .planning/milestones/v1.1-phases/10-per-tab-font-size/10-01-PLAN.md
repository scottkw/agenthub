3. In the `[sessionId]` setup effect, AFTER `term.open(containerRef.current)` and BEFORE the RelayClient setup, add the key handler registration:
```typescript
term.attachCustomKeyEventHandler((ev: KeyboardEvent): boolean => {
  if (ev.type !== 'keydown') return true
  if (ev.shiftKey && ev.key === '=') { onFontSizeChange(+1); return false }
  if (ev.shiftKey && ev.key === '-') { onFontSizeChange(-1); return false }
  return true
})
```

CRITICAL: `onFontSizeChange` is captured in the closure. Since the handler is registered once (in the [sessionId] effect), and `onFontSizeChange` is a stable callback from App.tsx (created via useCallback with no deps that change per-session), this is safe. Do NOT add `onFontSizeChange` to the effect dependency array — that would re-run the entire terminal setup.
