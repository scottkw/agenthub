## Layout Contract

This section is Phase 7-specific and captures the precise CSS rules that constitute the deliverable.

### Required Flex Chain (TERM-01)

Every element in the vertical stack from `html` to the terminal div must satisfy:

| Element | Required CSS | Current State | Change Required |
|---------|-------------|---------------|-----------------|
| `html, body, #root` | `height: 100%; overflow: hidden` | Correct | None |
| `.app` | `display: flex; flex-direction: column; height: 100%` | Correct | None |
| `.tab-bar` | `flex-shrink: 0; height: 42px` | height: 36px | Change to 42px |
| `.terminal-container` | `flex: 1; min-height: 0; overflow: hidden` | `flex: 1; overflow: hidden` — missing `min-height: 0` | Add `min-height: 0` |
| `.terminal-wrapper` | `display: flex; flex-direction: column; width: 100%; height: 100%` | Correct | None |
| `.web-serving-bar` | `flex-shrink: 0` | Correct | None |
| `TerminalPanel div` (inline) | `flex: 1; width: 100%; minHeight: 0` | Correct (source: TerminalPanel.tsx line 121-124) | None |

**The single root-cause fix for TERM-01:** Add `min-height: 0` to `.terminal-container`. Without it, the flex item defaults to `min-height: auto`, preventing the terminal from shrinking to fill only available space.

### Required Button Dimensions (UILAY-01)

| Selector | Property | Before | After |
|----------|----------|--------|-------|
| `.tab-bar` | `height` | 36px | 42px |
| `.tab-bar__btn` | `width` | 28px | 38px |
| `.tab-bar__btn` | `height` | 28px | 38px |
| `.tab-bar__btn` | `font-size` | 16px | 18px |
| `.cli-picker-overlay` | `padding-top` (offset below tab bar) | 36px | 42px |

**No other CSS changes required.** `flex-shrink: 0` on `.tab-bar` ensures the terminal container auto-adjusts when tab bar height increases. The ResizeObserver in `TerminalPanel.tsx` will fire `fit()` automatically.

## Interaction Contract

### Tab Switch Behavior

- Switching tabs triggers `display: none → display: flex` on the inactive/active `TerminalPanel` container.
- The existing `requestAnimationFrame(() => fitAddonRef.current?.fit())` in `TerminalPanel.tsx` handles this correctly — do not remove or alter this pattern.
- Tab switching must not cause layout collapse, blank space, or dimension mismatch. This is verified by manual browser inspection after the CSS fix.

### Window Resize Behavior

- The `ResizeObserver` on `.terminal-container` fires `fit()` on every dimension change.
- Do not add `window.addEventListener('resize', ...)` — the existing ResizeObserver is the correct pattern.

### Tab Bar Height Change Impact

- When `.tab-bar` height increases from 36px to 42px, `.terminal-container` (with `flex: 1`) automatically shrinks by 6px.
- The ResizeObserver fires and calls `fit()`. No additional JavaScript is needed.
- `.cli-picker-overlay` has `padding-top: 36px` to position below the tab bar — this must be updated to `42px` alongside the tab bar height change.
