| Boundary | Description |
|----------|-------------|
| user → search input | The only user-supplied input; processed in-memory via case-insensitive substring match; no network, no eval |
| Markdown content → rendered DOM | Maintainer-authored bundled Markdown rendered to React elements |
| webview → external browser | External links must escape the webview to the system browser |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-147-03 | Tampering | HelpSearch `<mark>` highlight | mitigate | Plain-string split rendered via React JSX (auto-escaped); no dangerouslySetInnerHTML; highlight never passes through a rehype/raw-HTML path. |
| T-147-04 | Spoofing | external links / webview navigation | mitigate | All external links are `<button>` + BrowserOpenURL; zero `<a href>` in new code; aria-label discloses external destination. |
</threat_model>
