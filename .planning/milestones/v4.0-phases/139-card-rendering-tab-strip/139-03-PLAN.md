| agent PTY output → VT emulator | Untrusted agent output bytes are parsed by charmbracelet/x/vt into a bounded cell grid |
| frontend → daemon HTTP | GET /sessions/{id}/styled-tail crosses the local daemon socket boundary; `n` is attacker-influenceable |
| go module supply chain | `go get charmbracelet/x/vt` introduces new code into the build |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-139-04 | Denial | Unbounded styled grid from huge scrollback | mitigate | Emulator is fixed-size (cols × 50 rows); only the last n rows returned; n clamped to [1..20] at BOTH api.go handler and app.go binding (defense in depth) — response size bounded to ≤20 rows × cols spans |
| T-139-05 | Elevation | Remote session id spoofed to styled-tail | mitigate | Endpoint is local-only — GetSessionStyledTailLines returns [][]StyledSpan{} for any id absent from the local HubManager; no new attack surface beyond existing /tail (TestGetSessionStyledTailLines_Unknown proves it) |
| T-139-06 | Tampering | Agent output bytes drive the VT state machine | accept | Same trust level as the live xterm terminal already renders; output is the session the local user themselves launched; no code execution, only cell grid construction |
| T-139-07 | Tampering | StyledSpan color strings reaching the DOM | mitigate | Wire type carries only "#rrggbb"/"ansi:N"/"" strings (no HTML); Plan 04 local path renders via React children (auto-escaped), never dangerouslySetInnerHTML |
| T-139-SC | Tampering | `go get charmbracelet/x/vt` + ultraviolet | mitigate | [ASSUMED] packages gated by the blocking-human legitimacy checkpoint above; exact pseudo-version pinned (no `go get -u`); both are official Charmbracelet org modules |
