<objective>
Resolve POL-04: a terminal session garbles after a theme switch or tab switch.
Root cause (confirmed in RESEARCH.md): the theme-change effect in TerminalPanel.tsx
(~696-704) has no `isActive` guard and calls `refresh(0, rows-1)` instead of
`fitTerminal()` after `clearTextureAtlas()`. It fires on `display:none` panels
that have `rows=0`, corrupting the WebGL atlas for when the panel next becomes
visible.

Per D-05, harden the FULL repaint path (theme/tab/font coordination), not a
minimal patch. The fix is isolated entirely to TerminalPanel.tsx effect
coordination; no other file changes.

Verification is MANUAL in the native `wails dev` window — the `:34115` bridge has
no PTY (per 141-RENDER-COMPARE.md). The final verify task pauses for the human.

Purpose: Eliminate the most user-visible post-redesign defect; make the terminal
trustworthy across theme/tab/font transitions.
Output: A hardened TerminalPanel.tsx repaint path with a deferred-theme ref.
</objective>
