## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| viewer UI → RemoteJoinCodeModal → /join/exchange | The viewer supplies an owner-delivered out-of-band code; exchange yields a single-use cap |
| cap token → BrowserOpenURL ?cap= URL | The token rides only into the opened URL (same trust as the existing share link), never persisted in React state beyond the open call |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-146-02 | Spoofing | open-path validation | mitigate | The card "Open in browser" routes through the modal/exchange/BrowserOpenURL path that the Plan 01 behavior test exercises — a dead handler cannot pass green |
| T-146-04 | Information Disclosure | cap token in React | mitigate | open-session intent passes the cap straight into the opened URL and does not store it in component state (matches the existing share-link trust level) |
| T-146-05 | Denial of Service (UX dead-end) | remote Open with no cap | mitigate | Replace the raw 401 with the modal + informative banners (D-03); no silent no-op |
| T-146-SC | Tampering | npm/pip/cargo installs | accept | No package installs; reuses existing RemoteJoinCodeModal/ExchangeJoinCodeAtURL and vitest/tsc toolchain |
</threat_model>
