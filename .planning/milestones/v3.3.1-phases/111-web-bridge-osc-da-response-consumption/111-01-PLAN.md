## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Web Bridge | Untrusted bytes cross here. WebSocket `MsgInput` frame from a capability-token-authenticated browser tab. xterm.js generates SYNTHETIC replies (OSC 10/11/DA1) interleaved with real keystrokes — both forms enter the bridge as opaque bytes; the bridge must distinguish them. |
| Web Bridge → PTY | After absorption, filtered bytes pass to `hub.WriteInput`. The PTY treats whatever it receives as authoritative stdin. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-111-01 | Denial of Service | `InputAbsorber.Filter` — unbounded buffer growth | mitigate | `maxEnvelopeBytes = 4096` cap on `oscBuf` and `csiBuf`; on overflow, flush as passthrough (do NOT silently drop) and reset state to `stateOutside`. Researcher Pitfall 7 + §"Bounded buffer guard". Covered by unit test R1. |
| T-111-02 | Tampering | Cross-subscriber state pollution | mitigate | Per-subscriber `absorber := &InputAbsorber{}` declared on the read-pump goroutine local stack — NOT on the `WebServer` struct, NOT on the `Hub`. Multi-tab access to the same session gets independent absorbers. Researcher Pitfall 3. (No direct test — proven by code review of the wiring change in Task 2.) |
| T-111-03 | Tampering | Injection of synthesized bytes via passthrough reconstruction | mitigate | `completeOSC` passthrough branch reconstructs the envelope byte-for-byte from `oscBuf` + a known terminator (BEL).
