## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-118-01 | Tampering | sandbox.go (Sandbox.Open) | mitigate | Use `os.OpenRoot` + `root.Open` atomically; `filepath.EvalSymlinks` runs ONCE on workDir inside NewSandbox, never on relPath. Eliminates the CVE-2026-27976 Zed TOCTOU class. Verified by FuzzSandboxPath assertion "ESCAPE: input X resolved to Y outside root". |
| T-118-02 | Tampering | validateRelativePath (Windows device names) | mitigate | Cross-platform reject of CON/NUL/PRN/AUX/COM1-9/LPT1-9 (case-insensitive, dot-stripped basename) applied BEFORE os.OpenRoot on ALL platforms. CVE-2025-27210 class mitigation. |
