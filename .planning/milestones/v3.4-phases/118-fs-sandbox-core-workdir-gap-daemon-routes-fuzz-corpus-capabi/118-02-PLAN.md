FileEntry wire type (locked spec from RESEARCH.md lines 738-762):
```
type FileEntry struct {
    Name      string `json:"name"`            // basename only; forward-slash-normalized
    Size      int64  `json:"size"`            // bytes; 0 for directories
    Mtime     string `json:"mtime"`           // RFC3339 UTC
    Mode      string `json:"mode"`            // os.FileMode.String()
    IsDir     bool   `json:"isDir"`
    IsSymlink bool   `json:"isSymlink"`
    IsBinary  bool   `json:"isBinary"`        // List: extension-only; Stat: extension OR sniff
    MIME      string `json:"mime,omitempty"`  // List: extension-only; Stat: includes sniff
}

type FileListResponse struct {
    Entries   []FileEntry `json:"entries"`
    Truncated bool        `json:"truncated"`   // true if >= 10,000 entries hit the cap
}
```
