```go
package main

import "fmt"

// trayTooltip returns the tooltip string for the given session count.
// Uses an em dash (U+2014) as specified in the UI-SPEC copywriting contract.
func trayTooltip(n int) string {
    switch n {
    case 0:
        return "AgentHub \u2014 no sessions"
    case 1:
        return "AgentHub \u2014 1 session"
    default:
        return fmt.Sprintf("AgentHub \u2014 %d sessions", n)
    }
}

// MenuItemKind classifies tray menu entries.
type MenuItemKind int

const (
    MenuItemAction    MenuItemKind = iota // clickable item
    MenuItemSeparator                      // visual divider
)

// MenuItem represents a single entry in the tray context menu.
type MenuItem struct {
    Kind      MenuItemKind
    Label     string
    SessionID string // non-empty for session items
    Index     int    // session index for callback dispatch
}

// BuildMenuItems constructs the canonical tray menu structure:
// "Open AgentHub" -> separator -> [sessions] -> separator -> "Quit"
// This is the single source of truth for menu layout across all platforms.
func BuildMenuItems(sessions []SessionInfo) []MenuItem {
    items := []MenuItem{
        {Kind: MenuItemAction, Label: "Open AgentHub"},
    }
    if len(sessions) > 0 {
        items = append(items, MenuItem{Kind: MenuItemSeparator})
        for i, s := range sessions {
            items = append(items, MenuItem{
                Kind:      MenuItemAction,
                Label:     s.Name,
                SessionID: s.ID,
                Index:     i,
            })
        }
    }
    items = append(items,
        MenuItem{Kind: MenuItemSeparator},
        MenuItem{Kind: MenuItemAction, Label: "Quit"},
    )
    return items
}
```

Replace the entire `tray_linux.go` with a full D-Bus StatusNotifierItem implementation. The file MUST have `//go:build linux` tag.

**Architecture:**

The implementation uses three D-Bus interfaces:
1. `org.kde.StatusNotifierItem` — the tray icon itself (properties: Id, Category, Status, IconPixmap, ToolTip, Menu)
2. `com.canonical.dbusmenu` — the right-click menu (GetLayout, Event methods)
3. `org.kde.StatusNotifierWatcher` — registration endpoint (RegisterStatusNotifierItem method)

**Key types to define:**

```go
// linuxTray holds all D-Bus state for the Linux system tray.
type linuxTray struct {
    conn       *dbus.Conn
    busName    string
    iconPixmap [][3]interface{} // []{ int32 width, int32 height, []byte ARGB32 }
    errPixmap  [][3]interface{}
    menuItems  []MenuItem       // from tray_common.go BuildMenuItems
    menuRev    uint32           // incremented on every menu rebuild
    mu         sync.Mutex
    app        *App
}
```

**Implementation details:**

1. **Icon conversion** — `pngToARGB32Pixmap(data []byte) (width, height int32, pixels []byte, err error)`:
   - Use `image/png` to decode the embedded PNG bytes
   - Convert each pixel to network-byte-order (big-endian) ARGB32: `[A, R, G, B]`
   - The D-Bus IconPixmap property type is `a(iiay)` — array of structs with (int32 width, int32 height, []byte pixels)

2. **D-Bus service registration** in `initTray()`:
   - Connect to session bus: `dbus.SessionBusPrivate()` then `conn.Auth()` and `conn.Hello()`
   - Request bus name: `org.kde.StatusNotifierItem-{pid}-1`
   - Export StatusNotifierItem object at `/StatusNotifierItem`
   - Export dbusmenu object at `/MenuBar`
   - Register with watcher: call `org.kde.StatusNotifierWatcher.RegisterStatusNotifierItem(busName)`
   - If watcher is not available (no tray host), log a warning and return gracefully (tray becomes no-op)

3. **StatusNotifierItem interface** — implement as D-Bus introspectable properties:
   - `Id`: "agenthub"
   - `Category`: "ApplicationStatus"
   - `Status`: "Active"
   - `IconPixmap`: converted from tray_icon.png
   - `ToolTip`: `(sa(iiay)ss)` — ("", [], "AgentHub", tooltip_text)
   - `Menu`: dbus.ObjectPath("/MenuBar")
   - `ItemIsMenu`: false

4. **StatusNotifierItem methods:**
   - `Activate(x, y int32)` — call show callback (runtime.WindowShow + setDockVisible)
   - `ContextMenu(x, y int32)` — no-op (menu is handled by dbusmenu)
   - `SecondaryActivate(x, y int32)` — no-op

5. **dbusmenu interface** (`com.canonical.dbusmenu`):
   - `GetLayout(parentId int32, recursionDepth int32, propertyNames []string) (uint32, menuLayout)`:
     - Root item (id=0) with children built from `BuildMenuItems()`
     - Each item: id (sequential from 1), properties map with "label", "type" ("separator" or "standard"), "enabled"
     - Return current `menuRev` as the revision
   - `Event(id int32, eventId string, data dbus.Variant, timestamp uint32)`:
     - eventId "clicked": dispatch based on item id
     - id matching "Open AgentHub" item → show callback
     - id matching session item → session callback (onTraySession equivalent)
     - id matching "Quit" item → quit callback
   - `GetGroupProperties(ids []int32, propertyNames []string)` — return properties for requested IDs
   - `AboutToShow(id int32) bool` — return false (no dynamic submenu needed)

6. **updateTray(sessions, connected)**:
   - Lock mutex
   - Update iconPixmap to connected or error pixmap
   - Rebuild menuItems via `BuildMenuItems(sessions)`
   - Increment menuRev
   - Emit `org.kde.StatusNotifierItem.NewIcon` signal
   - Emit `org.kde.StatusNotifierItem.NewToolTip` signal
   - Emit `com.canonical.dbusmenu.LayoutUpdated(menuRev, 0)` signal
   - Unlock mutex

7. **cleanupTray()**:
   - Close D-Bus connection
   - Set conn to nil

8. **setDockVisible(visible bool)**:
   - No-op on Linux (comment: "Linux has no Dock equivalent; Wails manages taskbar visibility")

9. **Callback dispatch** (same pattern as macOS, dispatched from D-Bus Event handler via goroutines):
   - **Show**: `go func() { runtime.WindowShow(a.ctx); a.setDockVisible(true) }()`
   - **Quit**: `go func() { a.client.ShutdownDaemon(); a.quitting = true; runtime.Quit(a.ctx) }()`
   - **Session(idx)**: `go func() { sessions := a.ListSessions(); if idx valid: runtime.WindowShow + EventsEmit("tray:focus-session", id) }()`

10. **Embed icons** — add `//go:embed` directives in tray_linux.go for the same assets/tray_icon.png and assets/tray_icon_error.png files (same PNGs as macOS; they're decoded to ARGB32 at runtime)

11. **Graceful degradation** — if D-Bus session bus is not available or StatusNotifierWatcher is not registered:
    - Log warning: `log.Printf("system tray: StatusNotifierWatcher not available, tray icon disabled")`
    - Set a `disabled` flag on linuxTray
    - All subsequent updateTray/cleanupTray calls become no-ops
    - Do NOT crash or return errors to the caller

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App -> D-Bus session bus | Tray registers a service on the user's session bus; other apps on the session can send events |
| D-Bus menu Event -> App callbacks | Click events from the tray host trigger app actions (show window, quit, focus session) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-01 | Spoofing | D-Bus Event method | accept | D-Bus session bus is per-user with Unix socket auth; only processes running as the same user can send messages. No additional auth needed for desktop tray. |
| T-67-02 | Tampering | D-Bus menu item IDs | mitigate | Validate item ID bounds in Event handler: `if id < 1 || id > len(menuItems) { return }`. Prevents out-of-bounds session index access. |
| T-67-03 | Denial of Service | D-Bus GetLayout flood | accept | GetLayout is cheap (returns in-memory struct). D-Bus session bus rate limiting is handled by dbus-daemon. Low risk for a desktop app. |
| T-67-04 | Information Disclosure | Session names in tray menu | accept | Session names are already visible to the local user in the GUI window. Tray menu exposes the same data at the same privilege level. |
</threat_model>
