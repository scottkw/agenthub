## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-132-02 | DoS | n query param / large scrollback | mitigate | app.go clamps n to [1..20]; scrollback is a fixed 256 KiB ring buffer (bounded); api.go ignores non-positive n |
| T-132-03 | Information Disclosure | tail of arbitrary session id | accept | Single-user local daemon model; same trust surface as existing GetSessionStatus; no cross-tenant data |
