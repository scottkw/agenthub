### Minor Asymmetry (non-blocking)

`App.tsx retryInit()` does not replicate the `if (validMode) setWebServerRunning(true)` defensive override that `init()` has. This is a narrow timing race — if `IsWebServerRunning()` returns false but `GetWebServerMode()` returns a valid mode in the retry path, `webServerMode` is set (triggering LocalNetworkBanner) but `webServerRunning` stays false (suppressing new-session web auto-seeding). No data loss; no functional impact on daemon state.

**Affected requirements:** SERVE-02, NET-04 (display-only, transient)
