```go
func TestLockedWriter(t *testing.T) {
    var buf bytes.Buffer
    lw := NewLockedWriter(&buf)
    n, err := lw.Write([]byte("hello"))
    if err != nil {
        t.Fatalf("unexpected error: %v", err)
    }
    if n != 5 {
        t.Errorf("expected 5 bytes written, got %d", n)
    }
    if buf.String() != "hello" {
        t.Errorf("expected 'hello', got %q", buf.String())
    }
}

func TestMakeClientResizeFrame(t *testing.T) {
    frame := MakeClientResizeFrame(80, 24)
    if len(frame) != 5 {
        t.Fatalf("expected 5 bytes, got %d", len(frame))
    }
    // MsgResize2 = 0x11
    if frame[0] != 0x11 {
        t.Errorf("expected first byte 0x11 (MsgResize2), got 0x%02x", frame[0])
    }
    // 80 = 0x0050, 24 = 0x0018
    cols := uint16(frame[1])<<8 | uint16(frame[2])
    rows := uint16(frame[3])<<8 | uint16(frame[4])
    if cols != 80 {
        t.Errorf("expected cols=80, got %d", cols)
    }
    if rows != 24 {
        t.Errorf("expected rows=24, got %d", rows)
    }
}
```

Implement `attachCmd` struct:
```go
type attachCmd struct {
    client    *daemon.DaemonClient
    sessionID string
    stdin     io.Reader
    stdout    io.Writer
    stderr    io.Writer
}

func (a *attachCmd) SetStdin(r io.Reader)  { a.stdin = r }
func (a *attachCmd) SetStdout(w io.Writer) { a.stdout = w }
func (a *attachCmd) SetStderr(w io.Writer) { a.stderr = w }
```

Implement `Run()` method following 77-PATTERNS.md attach.go section exactly:

1. Get relay port: `a.client.GetRelayPort()`
2. List sessions, find session by `a.sessionID`
3. If not found: `return fmt.Errorf("session %q not found", a.sessionID)`
4. Build WebSocket URL: `fmt.Sprintf("ws://127.0.0.1:%d/sessions/%s/ws", port, a.sessionID)`
5. Dial WebSocket with `context.Background()`
6. Create `attach.NewLockedWriter(a.stdout)`
7. Status bar: type-assert `a.stdin.(*os.File)` with `ok` pattern. If it's a file and `term.IsTerminal(int(f.Fd()))`:
   - Parse `session.CreatedAt` with `time.Parse(time.RFC3339, session.CreatedAt)`, default to `time.Now()` if zero
   - Create `statusbar.New(lw, statusbar.Options{SessionName: session.Name, AgentType: session.CLI, Hostname: session.Hostname, CreatedAt: createdAt, Position: statusbar.Bottom, Fd: f.Fd()})`
   - `bar.Start()` and `defer bar.Stop()`
8. Raw mode: type-assert `a.stdin.(*os.File)` again. If file:
   - `term.MakeRaw(int(f.Fd()))` and `defer term.Restore(int(f.Fd()), oldState)`
   - Send initial resize frame: `term.GetSize(int(f.Fd()))` then `attach.MakeClientResizeFrame(cols, rows)` then `conn.Write(ctx, websocket.MessageBinary, frame)`
9. Start resize watcher: `go attach.WatchResize(ctx, conn)`
10. Run I/O pumps: `return attach.AttachSession(ctx, conn, a.stdin, lw, 0x1C, bar, nil)`
    - `0x1C` is Ctrl-\ (the detach key)

Per RESEARCH.md Pitfall 1: use `ok` pattern for type assertion — if `a.stdin` is not `*os.File`, skip raw mode and status bar (test path). In production, Bubble Tea provides `os.Stdin` via `SetStdin`.

Per RESEARCH.md Pitfall 6: `defer term.Restore` immediately after `term.MakeRaw` ensures cleanup on all exit paths.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TUI -> daemon Unix socket | WebSocket dial to localhost relay; session ID from trusted session list |
| TUI -> raw terminal | attachCmd.Run() puts terminal in raw mode; defer restores cooked mode |
| daemon API -> attach flow | Session metadata (name, hostname) rendered in status bar via Lip Gloss |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-77-PATH | Tampering | internal/tui/attach.go | accept | Session ID comes from `m.sessions[m.selected].ID` which is a UUID from the daemon's in-memory registry. The WebSocket URL is `ws://127.0.0.1:{port}/sessions/{id}/ws` — no user-provided path component. Working directory is not involved in the attach flow. |
| T-77-RACE | Information Disclosure | internal/tui/attach.go | mitigate | `attachCmd` captures `sessionID` by value at dispatch time. Even if sessions refresh during tea.Exec, the captured ID remains stable. LockedWriter serializes concurrent stdout writes (status bar tick + PTY output). |
| T-77-DOS | Denial of Service | internal/tui/attach.go | mitigate | `attachCmd.Run()` blocks until detach or error — this is by design (tea.Exec owns the terminal). Context cancellation via conn.CloseNow() in defer ensures cleanup. Status bar Stop() is deferred. term.Restore() is deferred. No unbounded goroutine leak. |
| T-77-INJ | Spoofing | internal/attach/attach.go | accept | PTY output is written directly to stdout during raw attach — this is the same trust model as any terminal emulator. No sanitization is applied or expected. Session names in status bar are rendered by the statusbar package which uses DECSTBM escape sequences, not user-controlled ANSI. |
</threat_model>
