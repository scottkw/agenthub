  <behavior>
    - "hello world" → "hello world\n" (plain passthrough, single trailing newline appended).
    - "hello  " → "hello\n" (trailing spaces trimmed before the single newline).
    - "hello\nworld" / "hello\rworld" / "hello\r\nworld" → "hello world\n" (LF/CR/CRLF each
      collapse to ONE space; CRLF must not yield two spaces or two newlines — Pitfall 1).
    - "hel\x00lo" → "hello\n" (null byte stripped); "hel\x07lo" → "hello\n" (C0 BEL stripped);
      "hel\x7flo" → "hello\n" (DEL stripped).
    - "hel\u0085lo" → "hello\n" (C1 NEL stripped); "hel\u0080lo" → "hello\n" (C1 U+0080 stripped).
    - "hello\x1b[2Jworld" → "helloworld\n" and "hel\x1b[31mlo" → "hello\n" (CSI stripped).
    - "hi\x1b]0;title\x07there" → "hithere\n" (BEL-terminated OSC) and
      "hi\x1b]0;title\x1b\\there" → "hithere\n" (ST-terminated OSC).
    - "hel\u202elo" → "hello\n" (bidi RLO) and "hel\u200elo" → "hello\n" (bidi LRM).
    - "" → "\n" and "\n\n\n" → "\n" (empty / only-newlines collapse to bare newline).
    - "cmd\x1b[A\x00\r\n;evil" → "cmd evil\n" (mixed attack vector: CSI + null + CRLF survive as
      only safe text plus one newline).
  </behavior>
  <action>
    Create internal/relay/sanitize.go in package relay. Implement SanitizePTYText(input string)
    string as a rune-scanning state machine over `[]rune(input)` with five states: normal, after
    ESC (0x1B), inside CSI, inside OSC, and OSC-after-ESC (String-Terminator detection). In normal
    state: collapse '\n' and '\r' to a single space; enter escape state on ESC; drop bytes in the
    C0 range and DEL (0x7F); drop C1 controls (runes 0x80-0x9F); drop runes for which
    isBidiOverride returns true; otherwise append the rune. In escape state, '[' enters CSI, ']'
    enters OSC, anything else returns to normal (discarding the ESC pair). In CSI state, a final
    byte in 0x40-0x7E ends the sequence (parameter/intermediate bytes 0x20-0x3F stay in CSI). In
    OSC state, BEL (0x07) ends it and ESC enters OSC-escape; in OSC-escape, '\\' ends the sequence
    (ESC backslash = ST), otherwise return to OSC. After the loop, TrimRight the accumulated
    builder of trailing spaces, then append exactly one '\n'. Add a standalone helper
    isBidiOverride(r rune) bool returning true for the Trojan-Source bidi/directional codepoints
    listed in RESEARCH Pattern 2. Write a godoc comment on SanitizePTYText stating the invariant:

    sole gate before Hub.WriteInput.
    Create internal/relay/sanitize_test.go in package relay: a single table-driven

  </action>
