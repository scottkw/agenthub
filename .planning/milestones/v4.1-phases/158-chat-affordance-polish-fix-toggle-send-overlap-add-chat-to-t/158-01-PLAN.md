<objective>
Fix the chat toggle / Send-button overlap (CHAT-FIX-01) found during v4.1 UAT.

When the chat drawer is open in the Hub interactive modal, `.hub-modal__chat-toggle`
(position:absolute; bottom:12px; right:12px; z-index:6) floats over the composer's
Send/Inject button at the drawer's bottom-right (the drawer is z-index:5, width:360px,
right:0). The toggle has the higher z-index, so it obscures Send.

Purpose: Make the toggle relocate clear of the 360px drawer while the drawer is open,
so it no longer covers Send and still closes the drawer. CSS-scoped only — no markup
or JS change.
Output: One additive CSS rule, a vitest source-gate, and TESTING.md registration.
</objective>
