<objective>
Reverse the SEC-01 read-only chat-send gate so RO-cap guests can POST chat messages, while keeping `@session` inject and PTY/terminal input RO-gated. This is the server half of the D-06 reconciliation.

Removing the `if sub.ReadOnly { return ErrChatReadOnly }` early-return there loosens both surfaces at once.

Purpose: honor D-06 ("RO clients are full chat participants") which SEC-01/PITFALLS overrode in Phase 154; close the gap surfaced by Phase 159 live UAT (Test 3).
Output: RO chat-send enabled server-side on both paths; inject + PTY gates provably intact; Go tests flipped; a regression-guard test proving RO can chat but cannot inject.
</objective>
