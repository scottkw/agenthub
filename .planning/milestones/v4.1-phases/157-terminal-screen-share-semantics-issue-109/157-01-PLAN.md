<objective>
Replace the MC-06 max-wins PTY-size arbiter in `Hub.ResizeClient` with host-authority arbitration:
the local-origin host drives the grid (min-among-local, D-02), the last host size freezes when no
host is connected (D-01), web/remote-origin resize is ignored (VIEW-02), and every host resize
broadcasts the authoritative grid to all subscribers (VIEW-01). Add the missing `Hub.Rows()` method
(needed by the VIEW-03 join-push in Plan 02). Replace the three MC-06 hub tests with host-authority
tests.

Purpose: This is the server-side root-cause fix for the Issue #109 cross-viewer garble. Centralizing
the policy in one testable gate is what makes every other change-layer (join-push, viewer honor,
CSS scale) coherent.
Output: Rewritten `internal/relay/hub.go` arbiter + new `broadcastResize`/`Rows()`, and a rewritten
host-authority test suite in `internal/relay/hub_test.go`.
</objective>
