<objective>
Wire the two server-side consumers of the host-authority arbiter: (1) on guest join, push the
authoritative host grid as a 0x02 frame BEFORE scrollback replay on both the relay and web paths
(VIEW-03 — fixes the static-screen garble case); (2) drop the web-origin client resize at the
webserver read-pump call site as defense-in-depth on top of the hub origin gate (VIEW-02). Extend
the server test suites to lock the join-push ordering and the web-origin drop.

Purpose: VIEW-03's "resize before scrollback" ordering is the fix for static (non-repainting)
screens that would otherwise garble on join. VIEW-02's call-site drop avoids a needless lock
acquisition per guest keystroke-resize and documents intent at the read-pump.
Output: Modified `relay/server.go` + `webserver/server.go` join paths, dropped web resize call,
and ordering/drop tests in the two `server_test.go` files.
</objective>
