<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Releases CDN → user's machine | install.sh downloads a tarball over the network and writes an executable to a bin dir; the download is untrusted until verified |
| `curl \| sh` transport | The script itself and the binary it fetches cross the network before execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-156-01 | Tampering | Downloaded tarball (agenthub-*.tar.gz) | high | mitigate | SHA256 of the downloaded tarball is compared against checksums.txt before `tar xzf`; mismatch hard-aborts (exit 1) and nothing is extracted or installed |
| T-156-02 | Spoofing | DNS hijack / CDN compromise / redirect to wrong host | high | mitigate | All fetches use `curl -fsSL` (HTTPS only, `-f` fails on HTTP error status); the SHA256 gate still hard-aborts even if a wrong host served a tarball, because checksums.txt comes from the same release and a spoofed pair cannot match the real binary the user expects |
| T-156-03 | Tampering | Missing/empty entry for the tarball in checksums.txt | high | mitigate | EXPECTED hash is required-non-empty (`[ -n "$EXPECTED" ]`); an absent entry aborts before any extraction rather than silently skipping verification |
| T-156-04 | Elevation of Privilege | Install to ~/.local/bin write path | low | accept | Only the known binary name is written, `chmod 755` (not 777), no SUID bit; standard user-bin convention |
| T-156-SC | Tampering | Linux binary is not code-signed (integrity only, not authenticity) | medium | accept | Documented limitation consistent with other curl-install scripts; SHA256 provides integrity against transit tampering. macOS DMG signing is unchanged. No new package-manager installs are introduced by this script. |
</threat_model>
