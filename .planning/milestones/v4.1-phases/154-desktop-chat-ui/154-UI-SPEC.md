## Spacing Scale

All values multiples of 4. From the existing `--hub-*` codebase patterns:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Avatar-to-header gap, chip inner padding, inline timestamp gap |
| sm | 8px | Composer inner padding, message row vertical rhythm (consecutive), element gaps |
| md | 16px | Drawer horizontal content padding, message group outer vertical padding |
| lg | 24px | Drawer header height (flex center), section breaks |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Chat toggle button: 44px min touch target (W3C touch accessibility minimum)
- Drawer header: 48px height (matches existing `.tab-bar` height = 42px + 6px border area; use 48px for visual weight)
- Avatar: 28×28px (non-scale value — matches design comp reference; closest to 32px scale)
- Day separator label: 11px font + 6px vertical padding = 23px — held to 11px font-size (non-scale) for visual de-emphasis
- Press-and-hold timeout: 600ms (interaction timing, not spacing)

Uses existing `--hub-*` tokens. Dark-theme primary (light-theme tokens exist for all variables).

| Role | Dark Hex | Light Hex | Token | Usage |

| Accent (10%) | `#7aa2f7` | `#3d6fe8` | `--hub-accent` | (see reserved list below) |
| Destructive | `#f7768e` | `#c0394f` | `--hub-destructive` | No destructive actions in this phase |

Accent (`--hub-accent`) reserved for exactly:
1. Composer textarea focus border
2. Send/Inject button (active + pressed state)
3. @mention-of-me: solid left accent bar (3px wide, full row height)
4. @you chip background-tint border
5. Unread badge background (normal unread count)
6. @mention badge distinct state outline/glyph
7. Mention-popover @session row glyph (CommandLineIcon)
8. Focused/active state in mention-popover keyboard navigation highlight

Color alone is NEVER the sole signal. Every accent use above has a companion shape/text/glyph channel (colorblind-safe mandate from D-05, D-06, D-10 and project standing rule).

Additional semantic colors for chat-specific states (existing palette, no new hex values):
- `--hub-text-muted` (`#9398a8` dark): timestamps, tailnet IDs, system captions, typing indicator text
- `--hub-text-dim` (`#6e7180` dark): day separator label, placeholder text in empty states
- `--hub-border` (`#41454f` dark): drawer borders, day separator rule line, composer border (resting)
- Inject indicator background: `--hub-surface` — one step above message thread to visually separate system events
- @mention row tint: `rgba(122, 162, 247, 0.08)` — mirrors `--hub-sidebar-item-hover-bg` token value

## Interaction Contracts

### 1. Chat Drawer Layout (D-01, D-02, D-03)

- **Width:** 360px fixed. The drawer is absolutely positioned over the right edge of the terminal (overlay mode, D-02) — the terminal column keeps its full width and the PTY is NOT resized. The drawer covers ~360px of the terminal while open.
- **Animation:** `translateX(360px) → translateX(0)`, 220ms ease-out. Respects `prefers-reduced-motion: reduce` (instant, no transition). Use the same 220ms timing as the existing `HubModal` open animation to maintain system-wide motion coherence.
- **Default state:** Closed. Opens on toggle button click only (D-03).
- **Structure (top-to-bottom):**
  1. Drawer header (48px): title "Chat", participant count pill, close/collapse button
  2. Message thread (flex-1, virtualizer-backed, `--hub-bg` background)
  3. Typing indicator slot (0–24px collapsible, appears above composer)
  4. Composer area (auto-height, `--hub-surface` background, top border `--hub-border`)

### 2. Chat Toggle Button

- Position: inside the session modal toolbar area, rightmost control.
- Size: 44×44px touch target (min), 36×36px visual button.
- Icon: `ChatBubbleLeftRightIcon` (heroicons outline) — shape-based, colorblind-safe.
- Badge: overlaid top-right of icon (see Unread Badge section below).
- Label: `aria-label="Open chat"` (or "Close chat" when open).

### 3. Message Thread (D-04)

**Row structure — first message in a group (new author or >5 min gap):**
```
[Avatar 28×28]  [Alias 12.5px/600]  [TailnetID 11px/muted]  [HH:MM 12.5px/muted]
               [Message body 14px/400, line-height 1.5, markdown rendered]
```

- Avatar: 28×28px, `border-radius: 50%`, background derived from `TailnetID` via deterministic hue hash (use CSS `hsl(hash(tailnetID) % 360, 55%, 45%)`). Foreground: white initials (first letter of alias, uppercase). Avatar is supplementary; alias text is always present.
- Alias: `--hub-text-primary`, weight 600
- TailnetID: `--hub-text-muted`, 11px — shown in parentheses after alias or on a sub-line, never hidden
- Timestamp: `--hub-text-muted`, 12.5px — right-aligned in the header row or inline after TailnetID. `title` attribute = full ISO-8601 datetime string.
- Row padding: 12px horizontal, 8px top (first of group), 4px bottom

**Row structure — consecutive message (same author, within 5 min):**
```
[36px indent]  [Message body 14px/400, markdown rendered]
```

- No avatar, no alias header. 36px = 28px avatar + 8px gap.
- Row padding: 12px horizontal, 2px vertical

**Markdown rendering (SEC-03):**
- `react-markdown` + `remark-gfm` + `rehype-sanitize`
- No `rehype-raw`. The `rehype-sanitize` schema starts from the GitHub default schema (allowedTags list) and may only be tightened, never loosened.
- `<script>`, `onerror`, `onclick`, and all inline event handlers must be absent from the rendered DOM.
- Rendered inline code: `JetBrains Mono` 14px, `--hub-surface-elevated` background, 2px horizontal padding, `--hub-radius-sm` border-radius (matches `.settings-panel__code` pattern).

### 4. @mention-of-me Row (D-05)

Three simultaneous, independent signals (any one alone must convey the meaning to a colorblind user):
1. **Left accent bar:** `3px` wide × full row height, `background: var(--hub-accent)`, `position: absolute; left: 0`.
2. **Background tint:** `rgba(122, 162, 247, 0.08)` — the same value as `--hub-sidebar-item-hover-bg`.
3. **`@you` chip:** small pill badge (`@` glyph, 11px, `--hub-accent` foreground, `--hub-surface-elevated` background, 1px `--hub-accent` border, `--hub-radius-pill`) placed inline after the alias in the message header row.

The row itself gains `role="listitem"` with `aria-label` including "mentioned you".

### 5. @session Inject Indicator (D-06, Phase 153 carry-forward UAT)

A `SessionInject: true` message renders as a system-style row, visually distinct from human messages:

```
[Author text with normal markdown rendering]
─────────────────────────────────────────
[CommandLineIcon 14×14]  → injected into terminal   [HH:MM]
```

- Separator: `1px solid var(--hub-border)` rule spanning the full content width, 4px margin above/below
- Caption: `CommandLineIcon` (heroicons, 14×14px) + `"→ injected into terminal"` text, 12.5px, `--hub-text-muted`, not italic
- Row background: `--hub-surface` (slightly elevated from `--hub-bg` thread area)
- No left accent bar, no avatar for the system caption line
- `aria-label` on the row: "Injected into terminal by {alias}"

### 6. Composer (CHAT-01, CHAT-03)

- Component: `react-textarea-autosize`
- `minRows={1}` — initial height ~40px (14px font + 1.5 line-height + 8px×2 padding)
- `maxRows={6}` — caps at ~148px before internal scroll
- Placeholder text (resting): `"Message…"`
- Placeholder text (when @session is in message): `"@session — hold Send to inject"`
- Border: `1px solid var(--hub-border)`, `border-radius: var(--hub-radius-sm)` (8px)
- Focus border: `1px solid var(--hub-accent)`
- Background: `--hub-surface-elevated`
- Font: `--hub-font-ui`, 14px, 400
- Padding: 8px 12px
- Keyboard: Enter → send (MsgChatSend), Shift+Enter → newline (no send)
- Keyboard: `@` typed → opens MentionPopover

### 7. Send / Inject Button (D-08, MENTION-03 carry-forward UAT)

**Normal state (no @session in message):**
- Label: "Send" (text) or `PaperAirplaneIcon` (heroicons, 20×20px) — must include `aria-label="Send message"`
- Click or Enter on composer: fires `MsgChatSend` frame
- Size: 36×36px, `border-radius: var(--hub-radius-sm)`
- Background: `--hub-accent`, foreground: `--hub-bg`

**Inject state (composer contains `@session` mention):**
- Label: "Inject" text + `CommandLineIcon` glyph (or icon-only with `aria-label="Hold to inject into terminal"`)
- A plain click (tap < 600ms) does NOTHING — no MsgChatSend, no MsgSessionInject
- Enter in the composer fires `MsgChatSend` (normal chat) — plain Enter NEVER injects
- **Press-and-hold gesture:** hold the button for 600ms to fire `MsgSessionInject (0x35)`
  - Fill animation: the button face fills with `--hub-accent` from left-to-right over 600ms using a CSS `scaleX` transform on a `::before` pseudo-element (GPU-composited, same pattern as `.tab__progress`). Respects `prefers-reduced-motion: reduce` (no animation, fires immediately at 600ms without visual fill).
  - `pointerup` before 600ms: reset fill, no frame sent
  - `pointerup` at or after 600ms: fire frame immediately at threshold crossing
- `aria-label` must include "press and hold" wording to communicate the gesture to assistive tech

### 8. @mention Autocomplete Popover (MENTION-01, D-07)

Triggers: user types `@` (or `@` + partial text) in the composer textarea.

**Layout:**
- Positioned: directly above the composer (bottom-anchored), same width as composer
- Background: `--hub-surface-elevated`
- Border: `1px solid var(--hub-border)`
- Box shadow: `0 4px 12px rgba(0, 0, 0, 0.35)` (matches `.settings-search__results`)
- Border-radius: `var(--hub-radius-sm)` (8px)
- Max height: 240px with `overflow-y: auto`
- `role="listbox"`, each item `role="option"`

**Sections:**

Section 1 — @session (always pinned, always first, never filtered away):
```
─── Agent ───────────────────
[CommandLineIcon]  @session   "Inject into terminal"
─────────────────────────────
```
- Section label: `"Agent"`, 11px, uppercase, `--hub-text-dim`, padding 6px 12px
- @session row: `CommandLineIcon` 16×16px in `--hub-accent` + `"@session"` alias 14px `--hub-text-primary` + `"Inject into terminal"` description 11px `--hub-text-muted`
- Row height: 44px minimum (touch target)
- Separator: `1px solid var(--hub-border)` below section 1

Section 2 — Live participants (filtered by typed text after `@`):
- Each row: Avatar 20×20px + alias 14px `--hub-text-primary` + tailnet ID 11px `--hub-text-muted`
- Row height: 40px minimum

**Keyboard navigation:**
- `ArrowDown` / `ArrowUp`: move focus through items (wraps)
- `Enter`: select focused item, insert `@alias` into composer, close popover
- `Escape`: close popover, return focus to composer
- `Tab`: same as Escape (do not trap focus in popover)
- Focus indicator: `background: var(--hub-sidebar-item-hover-bg)` on focused row (shape-based, not color-only)

### 9. Typing Indicator (PRESENCE-02 — visual treatment)

- Slot: 20px height, collapses to 0 when no one is typing (no layout jump — use `min-height: 0` + `transition: max-height 150ms`)
- Text: `"{Alias} is typing…"` (single), `"{A} and {B} are typing…"` (two), `"{N} people are typing…"` (3+)
- Font: 12.5px, `--hub-text-muted`, italic
- Not stored, not rendered in the message thread — lives above the composer only

### 10. Unread Badge (NOTIF-01, D-10)

Two locations: the chat toggle button and the Hub SessionCard.

**Normal unread (no @mention):**
- Shape: filled circle, 18px diameter
- Background: `--hub-accent`
- Content: count number (weight 600, 11px, `--hub-bg` foreground)
- Signal: count number (shape of badge is supplementary)

**@mention unread (any unread message @mentions current user):**
- Shape: filled circle, 18px diameter — same shape as normal, but content changes
- Background: `--hub-accent` (same color acceptable; the @ glyph is the signal)
- Content: `@` glyph (weight 600, 11px, `--hub-bg` foreground) — replaces the count
- `aria-label` on badge: "N unread messages, including a mention" (must include "mention" for SR)
- Shape + glyph = colorblind-safe (D-10 mandate: `@` symbol carries meaning independently of color)

**Clearing:** Opening the drawer and having it focused (document focus within drawer) clears the unread count for that session. The badge disappears when count reaches 0.

**SessionCard badge position:** Overlay on top-right of the session card's chat icon or status area, consistent with the existing ATTN badge pattern in SessionCard.tsx.

### 11. Day Separators (CHAT-04)

- Implementation: virtualizer-aware — day separator is a dedicated item type in the @tanstack/react-virtual list (not CSS sticky on a generic element, to avoid conflicts with the virtualizer's absolute-positioned rows).
- The separator row uses `position: sticky; top: 0; z-index: 2` relative to the virtualizer scroll container.
- Background: `--hub-surface` (opaque, same as drawer background, so it occludes text beneath while sticky)
- Layout: centered date label with horizontal rules on both sides
- Date format: `"Today"` / `"Yesterday"` / locale-short (`"Mon, Jun 23"`)
- Label: 11px, 400, `--hub-text-dim`, padding 4px 12px
- Rule: `1px solid var(--hub-border)`
- Row height: 28px (non-scale; minimum for legibility at 11px)

### 12. Presence Roster (PRESENCE-01 — visual treatment)

- Shown in the drawer header, right side
- Format: avatar stack (up to 3 avatars, 20×20px, −4px overlap) + `"+ N"` overflow label if >3
- `aria-label` on roster: `"N participants connected"`

### 13. Empty / Loading / First-Message States

These are at the executor's discretion per CONTEXT.md, but the contract defaults:

| State | Heading | Body | Visual |
|-------|---------|------|--------|
| Empty (no messages yet) | "No messages yet" | "Send a message to start the conversation." | `ChatBubbleLeftIcon` 40×40px, `--hub-border` color |
| Loading (connecting to relay) | — | "Connecting…" | Spinner (existing spinner pattern, `--hub-text-muted`) |
| Late-join scrollback loading | — | "Loading history…" | Spinner inline with message list top |
| Relay error | "Connection lost" | "Reconnecting… or try refreshing the session." | `ExclamationCircleIcon`, `--hub-text-muted` |
