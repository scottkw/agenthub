### New in Phase 27 — Help Text (CLI-04)

The `agenthub --help` command must print terminal text covering both GUI launch and all CLI subcommands.
This is a Go `fmt.Fprintf(os.Stdout, ...)` string, not a UI component. The contract below defines its content.

**Format:** Two-section layout — preamble + command table.

```
Usage: agenthub [command] [flags]

Run with no arguments to launch the desktop GUI.

Commands:
  new <name> [--dir <path>] [--cli <name>]   Create a new terminal session
  list [--json]                               List all active sessions
  kill <id>                                   Kill a session
  rename <id> <name>                          Rename a session
  attach <id>                                 Attach to a session (interactive PTY)
  serve <id>                                  Enable web sharing for a session
  unserve <id>                                Disable web sharing for a session
  web                                         Open the web dashboard
  health                                      Check Tailscale health status
  qr <id>                                     Print QR code for a session URL
  settings                                    Open the settings panel
  daemon <subcommand>                         Manage the background daemon
    daemon run                                Run daemon in foreground
    daemon install                            Install as system service
    daemon uninstall                          Uninstall system service
    daemon start                              Start the system service
    daemon stop                               Stop the system service
    daemon status [--json]                    Show daemon status

Run 'agenthub <command> --help' for command-specific flags.
```

**Copywriting rules for help text:**
- Verb first in all command descriptions (Create, List, Kill, Rename, Attach, Enable, Disable, Open, Check, Print, Manage, Run, Install, Uninstall, Start, Stop, Show)
- Monospace width — align second column at column 46
- No trailing periods on help lines
- Detach key for attach: mention in attach command help only (not in main usage)

## Phase 27 Interaction Contracts

### Dispatch Decision Tree

```
agenthub invoked
├── len(os.Args) == 1          → runGUI()
├── os.Args[1] == "--help"     → usage() → os.Exit(0)
├── os.Args[1] == "-h"         → usage() → os.Exit(0)
├── strings.HasPrefix(os.Args[1], "-") → runGUI()  [other flags passed to Wails]
└── otherwise                  → runCLI(os.Args[1:])
    ├── "daemon" (no subcommand or "run") → daemon.RunDaemon()
    ├── "daemon" + subcommand   → cmdDaemon(args[1:])
    └── any other command       → EnsureDaemon → dispatch to cmd* function
```

### Terminal Output Conventions

- All error messages: `agenthub: <message>` prefix, printed to stderr
- All success output: printed to stdout
- JSON output: compact single-line JSON objects, one per line (existing `--json` convention)
- Exit codes: 0 = success, 1 = any error (existing convention, not changed)
