## UI Changes in This Phase

This section replaces the usual "new component inventory" since Phase 16 adds no new UI. All changes are deletions to existing components.

### SettingsPanel.tsx — Security tab removal

**What is deleted:**
- The `security` tab button from the tab list (`<button role="tab">Security</button>`)
- The `security` tab body content (entire `{activeTab === 'security' && (...)}` block)
- All Security-tab-related state: `webPassword`, `isPasswordSet`, `passwordSaving`, `passwordError`
- The `handleSetPassword` async function
- Imports: `SetWebPassword`, `IsWebPasswordSet` from `wailsjs/go/main/App`
- State initialization: `IsWebPasswordSet()` call in `loadWebState` effect
- `activeTab` type narrows from `'cli-paths' | 'web-server' | 'security'` to `'cli-paths' | 'web-server'`

**What changes (not deleted):**
- Web Server tab: Start Web Server button disabled condition changes from `(!isPasswordSet || !ctDisclosed)` to `(!ctDisclosed)`. The `title` tooltip referencing "Set a password in the Security tab first" is removed. New condition: disabled only when CT not disclosed and server not running.
- Default active tab: remains `'cli-paths'` (no change needed)

**After deletion, the SettingsPanel has exactly 2 tabs:** CLI Paths, Web Server.

### StatusBar.tsx — Copy Link button removal

**What is deleted:**
- The "Copy Link" `<button>` element from the `webServerRunning && webEnabled` branch
- The `onCopyTokenLink` prop from `StatusBarProps` interface
- The `onCopyTokenLink` destructured parameter

**After deletion, the WEB ON state shows:** state badge + session URL link + Disable Web button + QR button. No token-related button.

### wailsjs/go/main/App.d.ts and App.js — binding removal

**What is deleted from App.d.ts:**
```typescript
export function SetWebPassword(password: string): Promise<void>
export function IsWebPasswordSet(): Promise<boolean>
export function GenerateSessionToken(sessionID: string): Promise<string>
```
**Same three functions deleted from App.js.**

### App.tsx — token link handler removal

**What is deleted:**
- `handleCopyTokenLink` function (or equivalent) that calls `GenerateSessionToken`
- The `onCopyTokenLink` prop passed to `StatusBar`
- Import of `GenerateSessionToken` from wailsjs

### web/dashboard.html — login and CA section removal

**What is deleted:**
- `<section id="login-section">` and all child elements (password input, login button, error div)
- `doLogin()` JavaScript function
- `#login-error` element
- `#dashboard-section` display:none rule — dashboard renders directly without auth gate
- 401-handling branch in `refreshSessions()` — remove the redirect-to-login logic
- Auto-check login on page load — replace with direct `refreshSessions()` call
- `copyTokenLink()` JavaScript function
- "Copy Token Link" button from session card rendering in `buildSessionCard()`
- `#copy-token-result` element
- `<section>` containing CA certificate installation instructions (`.ca-section`)
- All `.ca-section`, `.platform-tabs`, `.platform-tab`, `.platform-content` CSS rules (dead after section deletion)
- `input[type="password"]` CSS rule (dead after login section deletion)
- `#login-error`, `#login-section`, `#dashboard-section` CSS rules

## Interaction Model After Phase 16

### Web Server Tab flow (post-deletion)

1. User opens Settings → Web Server tab (default shows CLI Paths, user clicks Web Server)
2. CT Disclosure banner shown if not acknowledged
   - If not acknowledged: Start Web Server button is disabled; tooltip says "Acknowledge the Certificate Transparency disclosure first"
   - User clicks "I Understand" → banner transitions to acknowledged state (green border, checkmark)
3. CT acknowledged: Start Web Server button becomes enabled
4. User clicks "Start Web Server"
   - Loading state: "Starting..." (button disabled)
   - Success: button changes to "Stop Web Server"; URL appears below button
   - Error: error message below button in #f7768e
5. Server running: user clicks "Stop Web Server" → "Stopping..." → server stopped; URL cleared

### StatusBar flow (post-deletion)

WEB ON state shows: `[WEB ON badge] [session URL link] [Disable Web button] [QR button]`

Copy Link button is absent. QR modal flow is unchanged.

### Dashboard HTML flow (post-deletion)

Page loads → `refreshSessions()` called directly (no login check) → session list rendered → each card shows session name, status dot, CLI badge, Open link. No "Copy Token Link" button on cards. No CA installation section below the list.
