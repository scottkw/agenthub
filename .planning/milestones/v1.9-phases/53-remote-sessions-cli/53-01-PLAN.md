Create `cmd_remote.go` in the root package with the following:

1. **CLIRemoteSession struct** — simplified version for CLI use:
```go
type CLIRemoteSession struct {
    ID       string
    Name     string
    CLIType  string
    Status   string
    Hostname string  // peer hostname (for display)
    FQDN     string  // peer FQDN stripped of trailing dot (for URL construction)
}
```

2. **parseRemoteID(id string) (hostname, sessionID string, isRemote bool)** — splits on first `:` character. If no colon, returns ("", id, false). If colon found, returns (parts[0], parts[1], true). Use `strings.SplitN(id, ":", 2)` to handle dots in hostname gracefully.

3. **resolveRemotePeer(peers []tailnet.Peer, hostname string) (fqdn string, found bool)** — iterates peers, finds one where `peer.Hostname` matches hostname (case-insensitive via `strings.EqualFold`). Returns `strings.TrimSuffix(peer.DNSName, ".")` and true. Returns ("", false) if not found.

4. **fetchPeerSessions(ctx context.Context, fqdn string, port int) ([]CLIRemoteSession, error)** — fetches `https://{fqdn}:{port}/api/sessions` with TLS 1.2 minimum, 5-second timeout. Decodes JSON array of `{"id","name","cli_type","status","hostname"}` objects (matching webserver's sessionListItem JSON shape). Returns `[]CLIRemoteSession` populated from response. Returns empty slice (not nil) on any error. Uses `crypto/tls` with `MinVersion: tls.VersionTLS12` — NO InsecureSkipVerify (Tailscale LE certs are publicly trusted per STATE.md decision).

- `TestFetchPeerSessions_Success` — use httptest.NewTLSServer returning 2 sessions; verify all fields mapped correctly
- `TestFetchPeerSessions_HTTPError` — server returns 500; verify empty slice returned
- `TestFetchPeerSessions_Timeout` — use httptest with handler that sleeps 10s; 1s context timeout; verify empty slice

var remoteGroups []CLIRemoteSession // from cmd_remote.go
if !*localOnly {
    peers, _ := client.ListTailnetPeers()
    // Use context with 10s overall timeout for remote discovery
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
    defer cancel()
    for _, p := range peers {
        fqdn := strings.TrimSuffix(p.DNSName, ".")
        peerSessions, _ := fetchPeerSessions(ctx, fqdn, tailnet.DefaultProbePort)
        remoteGroups = append(remoteGroups, peerSessions...)
