<objective>
Vendor the three already-shipping desktop xterm.js addons (`@xterm/addon-webgl`, `@xterm/addon-unicode11`, `@xterm/addon-clipboard`) into the Go binary so the web-served terminal page can load them same-origin under the v3.1 strict CSP (`script-src 'self'`).

Purpose: Today the web terminal page (`web/terminal.html`) loads only `xterm.js` and `addon-fit.js` — none of the three addons that ship on desktop. Phase 93 brings web to parity. This plan owns the file-copy + manifest + embed wiring; Plan 93-04 owns the runtime conditional addon loading inside `terminal.js` based on `/api/plugin-config`.

Output: Three new vendored `.js` files under `web/vendor/xterm/addons/`, three new lines in `web/vendor/xterm/VERSION`, extended `//go:embed` directive in `web/embed.go`, and three new `<script>` tags in `web/terminal.html` placed AFTER `addon-fit.js` and BEFORE `terminal.js` so the global namespace objects are available when `terminal.js` runs.

Per UI-SPEC §5: zero CDN references, all assets served from the embedded Go binary, CSP `script-src 'self'` honored.
</objective>
