## Integration Check

### Cross-Phase Issues

**INT-01: Windows CleanupStaleSocket uses wrong network dial** (medium — macOS/Linux unaffected)
- **File:** `internal/daemon/socket.go:51`
- **Issue:** `net.DialTimeout("unix", path, 500ms)` hardcodes "unix" network; on Windows, `DefaultSocketPath()` returns a named pipe (`\\.\pipe\agenthub-daemon`) which requires a different dial
- **Impact:** EnsureDaemon may attempt duplicate daemon spawn on Windows
- **Affects:** DAEMON-05

**INT-02: GUI startup panics on EnsureDaemon failure** (low — edge case)
- **File:** `app.go:48`
- **Issue:** `panic()` kills Wails process before frontend error banner can render
- **Impact:** If daemon binary can't spawn within 3s, GUI hard-crashes instead of showing retry UI
- **Affects:** DAEMON-05
