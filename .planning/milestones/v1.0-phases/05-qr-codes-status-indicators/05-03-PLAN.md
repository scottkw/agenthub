       - In the init useEffect, subscribe to Wails events:
         ```tsx
         const offStatus = EventsOn('session:status', (data: {sessionId: string; status: string}) => {
           setSessionStatuses(prev => ({ ...prev, [data.sessionId]: data.status }))
         })
         return () => { offStatus() }
         ```
       - Pass sessionStatuses to TabBar: <TabBar ... sessionStatuses={sessionStatuses} />
       - Add a "QR" button in the web-enabled session controls area (near the web toggle). Only show when webEnabled[sessionId] is true and webServerRunning is true. On click: setQrSessionId(sessionId).
       - Render QRModal when qrSessionId is non-null:
         ```tsx
         {qrSessionId && <QRModal sessionId={qrSessionId} onClose={() => setQrSessionId(null)} />}
         ```
       - On handleCloseTab, clean up sessionStatuses for the closed session.
       - On init, for each restored session, call GetSessionStatus to seed initial state:
         ```tsx
         sessions.forEach(s => {
           GetSessionStatus(s.id).then(st => {
             setSessionStatuses(prev => ({ ...prev, [s.id]: st }))
           })
         })
         ```
