    - TestGetSessionQRCode_NoServer: calling GetSessionQRCode when webServer is nil returns an error
    - TestQREndpoint: GET /api/sessions/{id}/qr with dashboard auth returns 200, Content-Type: image/png, body starts with PNG magic bytes

  <action>
    1. Run `go get github.com/skip2/go-qrcode` to add the dependency.

    2. In app.go, add `GetSessionQRCode(sessionID string) (string, error)`:
       - RLock a.mu, grab a.webServer, RUnlock
       - If ws is nil, return error "web server not running"
       - Build URL: fmt.Sprintf("%s/sessions/%s", ws.BaseURL(), sessionID)
       - Call qrcode.Encode(url, qrcode.Medium, 256) to get []byte PNG
       - Return base64.StdEncoding.EncodeToString(png), nil
       - Import: encoding/base64, github.com/skip2/go-qrcode

    3. In internal/webserver/server.go:
       - Add import for github.com/skip2/go-qrcode
       - Add handleSessionQR method: extracts sessionID from r.PathValue("id"), checks isSessionEnabled (404 if not), builds URL from BaseURL()+"/sessions/"+sessionID, calls qrcode.Encode(url, qrcode.Medium, 256), sets Content-Type to "image/png", writes PNG bytes
       - In setupRoutes(), add: mux.HandleFunc("GET /api/sessions/{id}/qr", ws.dashboardAuth(ws.handleSessionQR))

    4. Write tests FIRST (TDD red), then implement:
       - app_test.go: TestGetSessionQRCode using the existing testApp helper pattern — start a web server, enable a session, call GetSessionQRCode, decode base64, verify PNG magic bytes
       - app_test.go: TestGetSessionQRCode_NoServer — webServer is nil, expect error
       - internal/webserver/server_test.go: TestQREndpoint — use TestClient(), login, GET /api/sessions/{id}/qr, assert 200 + Content-Type + PNG body
       - internal/webserver/server_test.go: TestQREndpointNotEnabled — GET /api/sessions/{id}/qr for non-enabled ID, assert 404
  </action>
