<task type="auto" tdd="true">
  <name>Task 1: TLS certificate generation and persistence</name>
  <files>internal/webserver/tls.go, internal/webserver/tls_test.go</files>
  <behavior>
    - TestGenerateCA: generates a CA cert that is self-signed, has IsCA=true, BasicConstraintsValid=true, KeyUsage includes CertSign
    - TestGenerateLeafCert: leaf cert is signed by the CA, has SAN IPAddresses matching bind IP, ExtKeyUsage includes ServerAuth, x509.Verify against CA pool succeeds
    - TestLoadOrCreateCA: first call creates files on disk (ca.crt, ca.key in temp dir), second call loads them; both return identical CA cert bytes
    - TestBuildTLSConfig: returns a tls.Config with one certificate, MinVersion TLS 1.2
    - TestLeafCertSANRequired: leaf cert without IPAddresses would fail browser validation (verify IPAddresses is populated)
  </behavior>
  <action>
Create `internal/webserver/` package directory. Implement in `tls.go`:

1. `GenerateCA() (*ecdsa.PrivateKey, *x509.Certificate, []byte, error)` -- generates ECDSA P-256 CA key + self-signed CA cert with:
   - SerialNumber: big.NewInt(1)
   - Subject: pkix.Name{Organization: []string{"AgentHub Local CA"}}
   - NotBefore: time.Now().Add(-time.Minute) (clock skew buffer)
   - NotAfter: time.Now().AddDate(10, 0, 0)
   - IsCA: true, BasicConstraintsValid: true
   - KeyUsage: x509.KeyUsageCertSign | x509.KeyUsageCRLSign

2. `LoadOrCreateCA(dir string) (*ecdsa.PrivateKey, *x509.Certificate, []byte, error)` -- if `ca.crt` and `ca.key` exist in dir, PEM-decode and return them. Otherwise call GenerateCA and persist both as PEM to dir. Use `os.MkdirAll(dir, 0700)` for the config directory.

3. `GenerateLeafCert(caKey *ecdsa.PrivateKey, caCert *x509.Certificate, bindIP net.IP) (tls.Certificate, error)` -- generates ECDSA P-256 leaf key, signs with CA:
   - SerialNumber: big.NewInt(time.Now().UnixNano())
   - Subject: pkix.Name{CommonName: bindIP.String()}
   - IPAddresses: []net.IP{bindIP} (CRITICAL: SAN required per Pitfall 1 in research)
   - NotBefore: time.Now().Add(-time.Minute)
   - NotAfter: time.Now().AddDate(1, 0, 0)
   - KeyUsage: x509.KeyUsageDigitalSignature
   - ExtKeyUsage: []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth}
   - Returns `tls.X509KeyPair(certPEM, keyPEM)` -- leaf key NEVER written to disk.

4. `BuildTLSConfig(leafCert tls.Certificate) *tls.Config` -- returns `&tls.Config{Certificates: []tls.Certificate{leafCert}, MinVersion: tls.VersionTLS12}`.

5. `ExportCACertPath(dir string) string` -- returns the path to ca.crt file for user installation guidance.

Do NOT write leaf key to disk (anti-pattern from research). Use `encoding/pem` for all PEM encoding/decoding. Use `x509.MarshalECPrivateKey` for EC key serialization.
  </action>
  <verify>
    <automated>cd /Users/ken/dev/agenthub && go test ./internal/webserver/... -run TestTLS -v -timeout 30s</automated>
  </verify>
  <done>All 5 TLS test cases pass. CA cert is self-signed with IsCA=true. Leaf cert is CA-signed with SAN IPAddresses. LoadOrCreateCA persists to disk and reloads identically. BuildTLSConfig returns valid tls.Config with MinVersion TLS 1.2.</done>
</task>

    - TestListInterfaces: returns non-empty list on any dev machine (at least one non-loopback interface), each entry has non-empty Name and IP, no loopback or link-local addresses appear
    - TestNetworkInterfaceStruct: NetworkInterface has Name, IP (string), IsTailscale (bool) fields

  <action>
Implement in `network.go`:

1. `type NetworkInterface struct` with fields: `Name string`, `IP string`, `IsTailscale bool`.

2. Package-level `var tailscaleCIDR *net.IPNet` initialized in `init()` via `net.ParseCIDR("100.64.0.0/10")`.

3. `IsTailscaleIP(ip net.IP) bool` -- returns `tailscaleCIDR.Contains(ip)`.

4. `ListInterfaces() ([]NetworkInterface, error)` -- calls `net.Interfaces()`, iterates:
   - Skip interfaces where `Flags&net.FlagUp == 0` or `Flags&net.FlagLoopback != 0`
   - For each address: extract IP via type switch on `*net.IPNet` / `*net.IPAddr`
   - Skip `nil`, `IsLoopback()`, `IsLinkLocalUnicast()` IPs
   - Append `NetworkInterface{Name: iface.Name, IP: ip.String(), IsTailscale: IsTailscaleIP(ip)}`
   - Return the collected list (use `make([]NetworkInterface, 0)` for empty default per project convention)

Follow the exact pattern from 04-RESEARCH.md Pattern 5. Return IPv4 addresses only by default (skip `ip.To4() == nil` entries) to keep the dropdown clean -- VPN interfaces are always IPv4.
