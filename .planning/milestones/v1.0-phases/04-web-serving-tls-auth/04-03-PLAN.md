  <action>
Create `web/` directory at project root (same level as `internal/`, `frontend/`).

1. `web/embed.go` -- package `web` with:
   ```go
   package web

   import "embed"

   //go:embed dashboard.html terminal.html
   var WebFS embed.FS
   ```

2. `web/dashboard.html` -- single-page dashboard:
   - Title: "AgentHub Dashboard"
   - Login form: password input + submit button, POST to `/login` (fetch API, not form submit -- stays on page)
   - After login: fetch GET `/api/sessions` to get list of web-served sessions
   - Display sessions as a list with clickable links to `/sessions/{id}` (terminal page)
   - Each session shows: session name, CLI type, "Open" link, "Copy Token Link" button
   - Minimal inline CSS (no framework needed -- this is a utility page)
   - Show CA cert installation guidance section at the bottom (WEB-03): platform-specific instructions for macOS (Keychain Access), Linux (update-ca-certificates), Windows (certutil). Include a "Download CA Certificate" link to `/ca.crt`.

3. `web/terminal.html` -- xterm.js terminal page:
   - Load xterm.js 6 from jsDelivr CDN: `https://cdn.jsdelivr.net/npm/@xterm/xterm@6/css/xterm.css` and `https://cdn.jsdelivr.net/npm/@xterm/xterm@6/lib/xterm.js`
   - Load fit addon: `https://cdn.jsdelivr.net/npm/@xterm/addon-fit@0.11/lib/addon-fit.js`
   - Extract session ID from URL path (`/sessions/{id}`)
   - Extract optional token from URL query param (`?token=xxx`)
   - Open WSS connection to same host: `wss://${location.host}/sessions/${sessionID}/ws${token ? '?token=' + token : ''}`
   - Use EXACT same binary framing protocol as Phase 2:
     - MsgOutput (0x01): write payload to terminal
     - MsgInput (0x10): send terminal keystrokes
     - MsgResize2 (0x11): send cols/rows as big-endian uint16
   - Handle terminal.onData -> send MsgInput frame
   - Handle terminal.onResize -> send MsgResize2 frame
   - Handle ws.onmessage -> parse frame, write MsgOutput payload to terminal
   - fitAddon.fit() on load and window resize
   - Minimal styling: dark background (#1e1e1e), terminal fills viewport

Verify `go build ./web/...` compiles the embed package. The `//go:embed` directive must reference files in the same directory (not `..` paths -- per Pitfall 7 in research).

  <files>internal/webserver/server.go, internal/webserver/server_test.go</files>
  <behavior>
    - TestWebServerDashboardRequiresAuth: GET /dashboard without cookie returns 401
    - TestWebServerLoginSetsCoookie: POST /login with correct password returns 200 + Set-Cookie header
    - TestWebServerLoginBadPassword: POST /login with wrong password returns 401
    - TestWebServerDashboardAfterLogin: GET /dashboard with valid session cookie returns 200 + HTML
    - TestWebServerSessionListAPI: GET /api/sessions with valid cookie returns JSON array of web-enabled session IDs
    - TestWebServerTokenAccess: GET /sessions/{id} with ?token=valid bypasses dashboard auth, returns 200
    - TestWebServerTokenAccessInvalid: GET /sessions/{id} with ?token=invalid returns 401
    - TestWebServerCACertDownload: GET /ca.crt returns PEM-encoded certificate with Content-Type application/x-pem-file
    - TestWebServerWSS: WSS /sessions/{id}/ws with valid auth upgrades and receives MsgOutput frames from hub
    - TestWebServerToggle: EnableSession/DisableSession controls which sessions are web-served; disabled session returns 404
  </behavior>
  <action>
Implement in `server.go`:

1. `type Config struct` with fields:
   - `BindIP string`
   - `Port int` (default 7443, fallback to random if taken)
   - `ConfigDir string` (for CA cert persistence, e.g. ~/.config/agenthub)

2. `type WebServer struct` with fields:
   - `config Config`
   - `auth *AuthManager`
   - `tokens *TokenStore`
   - `manager *relay.HubManager` (from existing relay package)
   - `mu sync.RWMutex`
   - `webEnabled map[string]bool` (sessionID -> enabled; controls WEB-01 toggle)
   - `listener net.Listener`
   - `mux *http.ServeMux`
   - `caKey *ecdsa.PrivateKey`
   - `caCert *x509.Certificate`
   - `caDER []byte`

3. `func NewWebServer(cfg Config, manager *relay.HubManager) (*WebServer, error)` -- creates WebServer, initializes AuthManager, TokenStore, webEnabled map. Calls `LoadOrCreateCA(cfg.ConfigDir)` to load/create CA cert. Does NOT start the listener yet.

4. Route registration in a `setupRoutes()` method:
   - `GET /` -- redirect to /dashboard
   - `GET /dashboard` -- requires dashboardAuth; serves dashboard.html from web.WebFS
   - `POST /login` -- accepts JSON `{"password": "..."}`, calls auth.Login, sets cookie, returns 200 or 401
   - `GET /api/sessions` -- requires dashboardAuth; returns JSON of web-enabled sessions (filter by webEnabled map)
   - `GET /sessions/{id}` -- requires sessionAuth (cookie OR token); serves terminal.html
   - `GET /sessions/{id}/ws` -- requires sessionAuth; upgrades to WebSocket; relay logic identical to existing relay/server.go handleSession but with proper OriginPatterns (not InsecureSkipVerify)
   - `POST /api/sessions/{id}/token` -- requires dashboardAuth; calls tokens.Create(sessionID), returns JSON `{"token": "...", "url": "https://bindIP:port/sessions/{id}?token=xxx"}`
   - `GET /ca.crt` -- serves CA cert PEM with Content-Type `application/x-pem-file` (no auth required -- cert is public)

5. Auth middleware helpers:
   - `dashboardAuth(next http.HandlerFunc) http.HandlerFunc` -- checks `agenthub_session` cookie via auth.IsAuthenticated; 401 if invalid
   - `sessionAuth(next http.HandlerFunc) http.HandlerFunc` -- checks token query param OR session cookie; 401 if neither valid

6. `(ws *WebServer) EnableSession(sessionID string)` / `DisableSession(sessionID string)` -- toggle webEnabled map (WEB-01).

7. `(ws *WebServer) Start() error` -- generates leaf cert for config.BindIP, builds TLS config, calls `tls.Listen("tcp", bindIP+":"+port, tlsCfg)`. Try config.Port first; if EADDRINUSE, try port 0 (random). Store listener. Start `go http.Serve(listener, mux)`.

8. `(ws *WebServer) Stop() error` -- closes listener.

9. `(ws *WebServer) Addr() string` -- returns listener address for URL display.

10. `(ws *WebServer) BaseURL() string` -- returns `https://bindIP:port`.

For the WebSocket handler: use `websocket.Accept(w, r, &websocket.AcceptOptions{OriginPatterns: []string{"*"}})` -- the auth middleware already validates access; the web server's own origin will match. Do NOT use InsecureSkipVerify (anti-pattern from research -- that's only for the Wails-internal relay).

The WebSocket read/write pump logic is identical to existing `relay/server.go handleSession` -- subscribe-before-snapshot pattern, MsgInput/MsgResize2/MsgPing handling. Copy the pattern but apply auth first.

For tests: use `httptest.NewTLSServer` or create WebServer with test config and in-memory CA. Tests should NOT require real network interfaces.
