  <name>Task 1: Add darwin build tag to tray.go and create Linux/Windows stubs</name>
  <files>tray.go, tray_linux.go, tray_windows.go</files>
  <action>
1. Add `//go:build darwin` as the FIRST line of `tray.go` (before `package main`). This constrains the Cocoa CGO code to macOS only. Do NOT change any other content in tray.go.

2. Create `tray_linux.go` with:
   - `//go:build linux` tag
   - `package main`
   - No-op `func (a *App) initTray() {}` and `func (a *App) cleanupTray() {}`

3. Create `tray_windows.go` with:
   - `//go:build windows` tag
   - `package main`
   - No-op `func (a *App) initTray() {}` and `func (a *App) cleanupTray() {}`

These stubs match the exact signatures called from the App lifecycle. Without them, `wails build -platform linux/amd64` fails with `fatal error: 'Cocoa/Cocoa.h' file not found`.
  </action>
  <verify>
    <automated>cd /Users/ken/dev/agenthub && go vet ./... && grep -q "//go:build darwin" tray.go && grep -q "//go:build linux" tray_linux.go && grep -q "//go:build windows" tray_windows.go</automated>
  </verify>

<task type="auto">
  <name>Task 2: Add wails.json Info section and production build config files</name>
  <files>wails.json, build/darwin/Info.plist, build/entitlements.plist</files>
  <action>
1. Update `wails.json` to add the `Info` section (required by NSIS installer template). Add after the existing fields:
```json
"info": {
  "companyName": "AgentHub",
  "productName": "AgentHub",
  "productVersion": "1.0.0",
  "copyright": "Copyright 2026 AgentHub",
  "comments": "AI coding session manager"
}
```
Note: Wails v2 uses lowercase `info` key in wails.json (the Go struct tag is `json:"info"`). Do NOT add a capital-I `Info` key.

2. Create `build/darwin/Info.plist` — copy from `build/darwin/Info.dev.plist` but change `CFBundleIdentifier` from `com.wails.{{.Name}}` to `com.agenthub.app`. Keep all other template variables ({{.Info.ProductName}}, {{.OutputFilename}}, etc.) intact — Wails substitutes these at build time.

3. Create `build/entitlements.plist` with hardened runtime entitlements for notarization:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>com.apple.security.network.client</key>
    <true/>
    <key>com.apple.security.network.server</key>
    <true/>
</dict>
</plist>
```
These two entitlements are required because AgentHub runs a TLS web server (network.server) and makes WebSocket connections (network.client). Do NOT include `com.apple.security.get-task-allow` — Apple rejects notarization with that entitlement.
  </action>
  <verify>
    <automated>cd /Users/ken/dev/agenthub && python3 -c "import json; d=json.load(open('wails.json')); assert 'info' in d and d['info']['productName']=='AgentHub', 'missing info'" && grep -q "com.agenthub.app" build/darwin/Info.plist && grep -q "com.apple.security.network.server" build/entitlements.plist && ! grep -q "get-task-allow" build/entitlements.plist</automated>
  </verify>
  <done>wails.json has info section with product metadata, build/darwin/Info.plist has com.agenthub.app bundle identifier, build/entitlements.plist has network entitlements without get-task-allow</done>
</task>
