Create `internal/relay/manager.go`:
- `HubManager` struct: `mu sync.Mutex`, `hubs map[string]*Hub`
- `NewHubManager() *HubManager`
- `Create(sessionID string, reader io.Reader, writer io.Writer) *Hub` — creates Hub with DefaultScrollbackBytes, stores in map, starts `go hub.Run()`, returns hub
- `Get(sessionID string) (*Hub, bool)` — lookup under lock
- `Remove(sessionID string)` — calls hub.Shutdown() if exists, deletes from map
- `Shutdown()` — shuts down all hubs, clears map

Create `internal/relay/server.go`:
- `Server` struct: `manager *HubManager`, `mux *http.ServeMux`
- `NewServer(manager *HubManager) *Server` — creates ServeMux, registers routes
- Routes:
  - `GET /sessions/{id}/ws` — handleSession (WebSocket upgrade)
  - `GET /sessions` — handleListSessions (JSON list of session IDs)
- `ServeHTTP(w, r)` — delegates to mux (Server implements http.Handler)

`handleSession` implementation (critical ordering from research):
1. Extract session ID via `r.PathValue("id")`
2. Look up hub via `manager.Get(sessionID)` — 404 if not found
3. `websocket.Accept(w, r, &websocket.AcceptOptions{InsecureSkipVerify: true})` — Phase 4 tightens this
4. Create subscriber with buffered channel (256) and closeSlow that calls `conn.Close(websocket.StatusPolicyViolation, "too slow")`
5. **Subscribe FIRST** (before snapshot — this is the anti-race pattern from research)
6. Replay scrollback: `hub.ScrollbackSnapshot()` — write as single binary message
7. Start read pump goroutine: reads from conn, parses frame type byte, dispatches:
   - MsgInput: `hub.WriteInput(payload)`
   - MsgResize2: parse cols/rows, could store for later use (Phase 3 will call backend.Resize)
   - MsgPing: no-op (keepalive)
8. Write pump: select on `sub.Msgs`, `ctx.Done()`, `hub.Done()`
9. defer: `hub.Unsubscribe(sub)`, `conn.CloseNow()`

`handleListSessions`: returns JSON array of hub session IDs from manager.

**Anti-patterns to avoid:**
- Do NOT read from session.Read directly in the handler — only the Hub's drain goroutine reads the PTY
- Do NOT snapshot before subscribe — frames between snapshot and subscribe would be lost
- Do NOT use gorilla/websocket — use coder/websocket exclusively
