filesURL builds the query URL (client.go:366-374): it takes (op, sessionID, relPath), defaults empty relPath to ".", sets session and path query params, returns c.base + "/api/files/" + op + "?" + encoded. Extend it (or add a sibling) for the write ops "write"/"upload"/"delete"/"rename"/"mkdir".

ListFiles is the context-aware request + status-as-error template (client.go:381-399):

  // http.NewRequestWithContext(ctx, GET, c.filesURL("list", ...), nil) then c.http.Do
  // non-200: body,_ := io.ReadAll(resp.Body); return fmt.Errorf("files list: %d %s", status, body)
  // 200: json.NewDecoder(resp.Body).Decode(&files.FileListResponse)

doJSON is the shared JSON request/response helper (client.go:488): marshals body if non-nil, sends method to c.base+path, maps status>=400 to a typed error, decodes result if non-nil. RenameFile/MkdirFile should route through doJSON with a small request struct.

Wire types from Plan 123-01: files.FileWriteResponse{Path, Size}, files.FileOpResponse{Path, OK}.

Daemon routes from Plan 123-03: PUT /api/files/write, POST /api/files/upload, DELETE /api/files/delete, POST /api/files/rename, POST /api/files/mkdir.
