1. **`func cmdWeb(client *daemon.DaemonClient, args []string, out io.Writer) error`** (or whatever signature pattern Plan 01 established):
   - If `len(args) < 1`: return error `"usage: agenthub web <start|stop|status>"`
   - Switch on `args[0]`:
     - `"start"`: call `cmdWebStart(client, args[1:], out)`
     - `"stop"`: call `cmdWebStop(client)`
     - `"status"`: call `cmdWebStatus(client, out)`
     - default: return error `"usage: agenthub web <start|stop|status>"`

2. **`func cmdWebStart(client *daemon.DaemonClient, args []string, out io.Writer) error`**:
   - `port := 443` (default)
   - Create context with 5-second timeout: `ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)` then `defer cancel()`
   - Call `h := webserver.CheckHealth(ctx)`
   - If `!h.Connected`: return error `"Tailscale is not connected"`
   - If `h.IP == ""`: return error `"Tailscale IP not available"`
   - If `!h.HasCerts`: return error `"Tailscale HTTPS certificates not enabled"`
   - Call `url, err := client.StartWebServer(h.IP, port, h.Domain)`
   - On error: return `fmt.Errorf("agenthub web start: %w", err)`
   - On success: `fmt.Fprintln(out, url)` and return nil

3. **`func cmdWebStop(client *daemon.DaemonClient) error`**:
   - Call `client.StopWebServer()`
   - On error: return `fmt.Errorf("agenthub web stop: %w", err)`
   - On success: return nil (silent)

4. **`func cmdWebStatus(client *daemon.DaemonClient, out io.Writer) error`**:
   - Call `resp, err := client.GetWebServerStatus()`
   - On error: return `fmt.Errorf("agenthub web status: %w", err)`
   - If `resp.Running`: print 3-line key-value block to `out`:
     ```
     running:    true
     url:        <resp.URL>
     addr:       <resp.Addr>
     ```
   - If `!resp.Running`: print `running:    false\n` to `out`
   - Use `fmt.Fprintf(out, "%-12s%v\n", "running:", resp.Running)` pattern for 12-char padded labels
   - Return nil

5. **`func cmdServe(client *daemon.DaemonClient, args []string) error`**:
   - If `len(args) < 1`: return error `"usage: agenthub serve <session-id>"`
   - Call `client.ToggleWebServing(args[0], true)`
   - On error: return `fmt.Errorf("agenthub serve: %w", err)`
   - On success: return nil (silent)

6. **`func cmdUnserve(client *daemon.DaemonClient, args []string) error`**:
   - If `len(args) < 1`: return error `"usage: agenthub unserve <session-id>"`
   - Call `client.ToggleWebServing(args[0], false)`
   - On error: return `fmt.Errorf("agenthub unserve: %w", err)`
   - On success: return nil (silent)

7. **`func cmdHealth(out io.Writer) error`**:
   - Create context with 5-second timeout
   - Call `h := webserver.CheckHealth(ctx)`
   - Print 5-line key-value block to `out` with 12-char padded labels:
     ```
     installed:  <h.Installed>
     connected:  <h.Connected>
     has-certs:  <h.HasCerts>
     ip:         <h.IP>
     domain:     <h.Domain>
     ```
   - Use `fmt.Fprintf(out, "%-12s%v\n", "installed:", h.Installed)` etc.
   - Return nil (health always succeeds — CheckHealth returns a struct, no error)

8. **`func cmdQR(client *daemon.DaemonClient, args []string, out io.Writer) error`**:
   - If `len(args) < 1`: return error `"usage: agenthub qr <session-id>"`
   - Call `resp, err := client.GetWebServerStatus()`
   - If err or `!resp.Running`: return error `"web server not running — use 'agenthub web start' first"`
   - Build URL: `url := fmt.Sprintf("%s/sessions/%s", resp.URL, args[0])`
   - Call `q, err := qrcode.New(url, qrcode.Medium)`
   - On error: return `fmt.Errorf("agenthub qr: %w", err)`
   - `fmt.Fprint(out, q.ToString(false))` (QR block with Unicode half-blocks)
   - `fmt.Fprintln(out, url)` (URL below QR code)
   - Return nil

Update the switch statement in `main()` to call these real functions instead of the stubs, following whatever error-handling pattern Plan 01 established (likely: functions return error, main prints to stderr + os.Exit(1)).
