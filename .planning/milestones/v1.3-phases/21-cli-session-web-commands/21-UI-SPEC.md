# Phase 21 — UI Design Contract: CLI Session + Web Commands

> Visual and interaction contract for Phase 21. This phase introduces no GUI changes.
> All "UI" is CLI stdout/stderr output format, interaction patterns, and terminal rendering.
> Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — no shadcn, no Tailwind |
| Preset | not applicable |
| Component library | none — stdlib `text/tabwriter` for table output |
| Icon library | none — Unicode status symbols only (see Color section) |
| Font | terminal default (inherits user's terminal font) |

**Source:** Detected from codebase scan — no `components.json`, no `tailwind.config.*`.
The GUI uses handcrafted CSS with Tokyo Night palette. The CLI binary (`cmd/agenthub-cli/`) outputs plain text to stdout/stderr with no styling framework.

**shadcn Gate Result:** Not applicable. Phase 21 is a Go CLI binary — React/Next.js/Vite gate does not apply.

## Spacing Scale

Declared values for CLI output (column padding, not CSS):

| Token | Value | Usage |
|-------|-------|-------|
| col-gap | 2 spaces | Column separator in `text/tabwriter` (minwidth=0, tabwidth=0, padding=2) |
| indent | 2 spaces | Sub-item indentation under grouped output |
| section-gap | 1 blank line | Between logical groups in multi-section output (e.g., `health`) |

Exceptions: none — CLI output uses `text/tabwriter` stdlib defaults, not an 8-point pixel grid.

**Source:** RESEARCH.md Pattern 4 (`tabwriter.NewWriter(os.Stdout, 0, 0, 2, ' ', 0)`).

## Typography

CLI output is monospaced terminal text. No font size control. Contract covers text structure only.

| Role | Format | Usage |
|------|--------|-------|
| Header row | ALL CAPS, tab-separated | Column headers in `agenthub list` output |
| Body row | mixed case, tab-separated | Data rows in `agenthub list` output |
| Key-value label | lowercase, padded to 12 chars with spaces | Field labels in `health` and `web status` output |
| Error message | `agenthub <cmd>: <description>` | All errors to stderr |
| Success value | plain string, no prefix | IDs, URLs printed to stdout on success |

**Header row example:**
```
ID    NAME    AGENT    STATUS
```

**Key-value label example (12-char padding):**
```
installed:  true
connected:  true
has-certs:  true
ip:         100.x.x.x
domain:     hostname.ts.net
```

**Source:** RESEARCH.md Pattern 4 (tabwriter), Pattern 7 (health output), Pattern 3 (new output).

## Color

CLI output uses no ANSI color codes. All status is communicated through text values and symbols.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | terminal default background | All output — no override |
| Secondary (30%) | terminal default foreground | Body text |
| Accent (10%) | none | Not used in CLI output |
| Destructive | none — status text only | `kill` confirms with exit code 0 or non-zero stderr |

Accent reserved for: nothing — CLI output is uncolored plain text.

**Status values in list output (text, not color):**

| State | Text Value |
|-------|-----------|
| Running | `running` |
| Stopped | `stopped` |

**Web server state in `agenthub web status` output:**

| State | Text |
|-------|------|
| Running | `running  <URL>  <addr>` (tab-separated) |
| Stopped | `stopped` |

**Source:** RESEARCH.md — explicit decision to use stdlib; no ANSI color dependency added.

## Copywriting Contract

All messages follow the pattern `agenthub <cmd>: <problem description>` for errors.
Success output is minimal: only the essential value is printed (ID, URL, or table).

### Command Output Contracts

#### `agenthub new <agent> <path>`

| State | Output | Stream |
|-------|--------|--------|
| Success | `<session-id>\n` (UUID) | stdout |
| Missing args | `usage: agenthub new <agent> <path>\n` | stderr |
| Daemon unreachable | `agenthub: <daemon error>\n` | stderr |
| Create failed | `agenthub new: <error>\n` | stderr |

#### `agenthub list`

| State | Output | Stream |
|-------|--------|--------|
| Sessions exist | tab-formatted table with header | stdout |
| No sessions | `ID    NAME    AGENT    STATUS\n` (header only, no rows) | stdout |
| Daemon error | `agenthub list: <error>\n` | stderr |

Empty state: header row is always printed even when there are no sessions. No special "no sessions" message — the empty table is self-evident.

#### `agenthub kill <id>`

| State | Output | Stream |
|-------|--------|--------|
| Success | (no output — silent success) | — |
| Missing id | `usage: agenthub kill <session-id>\n` | stderr |
| Not found / error | `agenthub kill: <error>\n` | stderr |

Destructive action: `kill` terminates a session. No confirmation prompt — CLI tools do not prompt by default. Exit code 0 = success, non-zero = failure. This matches unix tool conventions (cf. `kill(1)`).

#### `agenthub rename <id> <name>`

| State | Output | Stream |
|-------|--------|--------|
| Success | (no output — silent success) | — |
| Missing args | `usage: agenthub rename <session-id> <name>\n` | stderr |
| Error | `agenthub rename: <error>\n` | stderr |

#### `agenthub web start`

| State | Output | Stream |
|-------|--------|--------|
| Success | `<url>\n` (e.g. `https://hostname.ts.net`) | stdout |
| Tailscale not connected | `agenthub: Tailscale is not connected\n` | stderr |
| No IP | `agenthub: Tailscale IP not available\n` | stderr |
| No certs | `agenthub: Tailscale HTTPS certificates not enabled\n` | stderr |
| Start error | `agenthub web start: <error>\n` | stderr |

#### `agenthub web stop`

| State | Output | Stream |
|-------|--------|--------|
| Success | (no output — silent success) | — |
| Error | `agenthub web stop: <error>\n` | stderr |

#### `agenthub web status`

| State | Output (key-value, 12-char padded labels) | Stream |
|-------|-------------------------------------------|--------|
| Running | `running:    true\nurl:        <url>\naddr:       <addr>\n` | stdout |
| Stopped | `running:    false\n` | stdout |
| Error | `agenthub web status: <error>\n` | stderr |

#### `agenthub serve <id>`

| State | Output | Stream |
|-------|--------|--------|
| Success | (no output — silent success) | — |
| Missing id | `usage: agenthub serve <session-id>\n` | stderr |
| Error | `agenthub serve: <error>\n` | stderr |

#### `agenthub unserve <id>`

| State | Output | Stream |
|-------|--------|--------|
| Success | (no output — silent success) | — |
| Missing id | `usage: agenthub unserve <session-id>\n` | stderr |
| Error | `agenthub unserve: <error>\n` | stderr |

#### `agenthub health`

| State | Output (key-value, 12-char padded labels) | Stream |
|-------|-------------------------------------------|--------|
| Any result | 5-line key-value block (always prints all fields) | stdout |
| Timeout/error | `agenthub health: <error>\n` | stderr |

Health output format (fixed):
```
installed:  <true|false>
connected:  <true|false>
has-certs:  <true|false>
ip:         <address or empty>
domain:     <domain or empty>
```

#### `agenthub qr <id>`

| State | Output | Stream |
|-------|--------|--------|
| Success | QR block (Unicode half-blocks via `q.ToString(false)`) + blank line + `<url>\n` | stdout |
| Web server not running | `agenthub qr: web server not running — use 'agenthub web start' first\n` | stderr |
| Missing id | `usage: agenthub qr <session-id>\n` | stderr |
| QR encode error | `agenthub qr: <error>\n` | stderr |

#### `agenthub` (no subcommand or unknown subcommand)

| State | Output | Stream |
|-------|--------|--------|
| No args | usage block (see below) | stderr |
| Unknown command | `agenthub: unknown command "<cmd>"\n` + usage block | stderr |

Usage block format:
```
Usage: agenthub <command> [args]

Commands:
  new <agent> <path>     Create a new session
  list                   List all sessions
  kill <id>              Terminate a session
  rename <id> <name>     Rename a session
  serve <id>             Enable web serving for a session
  unserve <id>           Disable web serving for a session
  web start              Start the Tailscale web server
  web stop               Stop the Tailscale web server
  web status             Show web server status
  health                 Check Tailscale health
  qr <id>                Display session QR code in terminal
```

### Primary CTA

| Element | Copy |
|---------|------|
| Primary CTA | `agenthub new <agent> <path>` — "Create session" |
| Empty state (list) | header row only; no empty state body needed |
| Error state | `agenthub <cmd>: <problem description>` — always names the command |
| Destructive confirmation | `kill`: no prompt — unix convention; exit code signals success/failure |

### Session Name Default

**Source:** RESEARCH.md Pitfall 4 — `CreateSession` requires a name; `agenthub new <agent> <path>` omits a name argument.

Default name: `filepath.Base(workDir)` — the directory basename. This matches tmux/screen conventions and requires no user input.

Optional flag: `--name <name>` may be added but is not required for Phase 21 success criteria.

## Interaction Contracts

### Daemon Auto-Start

Every command calls `daemon.EnsureDaemon(socketPath)` before creating `DaemonClient`. If the daemon is not running, it starts automatically (polls up to 3 seconds). The user sees no output during this wait unless the daemon fails to start, in which case:

```
agenthub: failed to start daemon: <reason>
```

**Source:** RESEARCH.md Pattern 2 (EnsureDaemon), REQUIREMENTS.md DAEMON-05.

### Exit Codes

| Code | Meaning |
|------|---------|
| 0 | Command succeeded |
| 1 | Command failed (error printed to stderr) |

No other exit codes. All error paths call `os.Exit(1)` after printing to stderr.

### Session ID Format

Session IDs are UUIDs (from daemon). `agenthub new` prints the raw UUID to stdout. All other commands accept UUIDs as positional arguments. No short-ID aliasing in Phase 21.

### `agenthub web start` Port

Default port: 443. Tailscale web server binds on the Tailscale IP (100.x.x.x), which is a virtual network interface where port 443 is accessible without root privileges. No `--port` flag required for Phase 21 success criteria; may be added in Phase 24 (CLI Polish).

**Source:** RESEARCH.md Pitfall 2.

### `agenthub list` Column Order

Fixed column order: `ID  NAME  AGENT  STATUS`

Column widths: controlled by `text/tabwriter` with 2-space minimum gap. No fixed widths — tabwriter aligns dynamically to content.

## GUI Impact

**None.** Phase 21 adds a standalone CLI binary at `cmd/agenthub-cli/`. The Wails GUI (`main.go`, `frontend/`) is not modified. The GUI already polls `ListSessions` periodically, so CLI-side changes (kill, rename, new) are reflected in the GUI tab bar within the next poll cycle (1-2 seconds).

**Source:** RESEARCH.md Pitfall 5 (rename polling delay is expected, not a bug).
