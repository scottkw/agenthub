**Create `cmd/agenthub-cli/cmd_attach.go`** with these functions:

1. `func cmdAttach(client *daemon.DaemonClient, args []string) error`
   - Validate args: `len(args) < 1` returns `fmt.Errorf("usage: agenthub attach <session-id>")`
   - Extract `sessionID := args[0]`
   - Optional `--detach-key` flag: parse args for `--detach-key=X` where X is a single byte or name like `ctrl-\`. Default detach key: `byte(0x1C)` (Ctrl-backslash)
   - Call `client.GetRelayPort()` to get relay TCP port
   - Verify session exists: call `client.ListSessions()` and check sessionID is in the list. Return `fmt.Errorf("attach: session %q not found", sessionID)` if missing
   - Check `term.IsTerminal(int(os.Stdin.Fd()))` — return error if false
   - Build WebSocket URL: `fmt.Sprintf("ws://127.0.0.1:%d/sessions/%s/ws", port, sessionID)`
   - Create signal context: `ctx, stop := signal.NotifyContext(context.Background(), syscall.SIGTERM, syscall.SIGHUP)`; `defer stop()`
   - Dial WebSocket: `conn, _, err := websocket.Dial(ctx, wsURL, nil)`; `defer conn.CloseNow()`
   - Put terminal in raw mode: `oldState, err := term.MakeRaw(int(os.Stdin.Fd()))`; `defer term.Restore(int(os.Stdin.Fd()), oldState)`
   - Send initial resize frame: read `cols, rows, _ := term.GetSize(int(os.Stdin.Fd()))`, send `makeClientResizeFrame(uint16(cols), uint16(rows))` via `conn.Write(ctx, websocket.MessageBinary, frame)`
   - Start SIGWINCH watcher: call `watchResize(ctx, conn)` (platform-specific, defined in cmd_attach_unix.go / cmd_attach_windows.go)
   - Call `attachSession(ctx, conn, os.Stdin, os.Stdout, detachKey)` which runs the I/O pumps
   - Return nil on clean detach/exit

2. `func attachSession(ctx context.Context, conn *websocket.Conn, stdin io.Reader, stdout io.Writer, detachKey byte) error`
   - This is the testable core — takes io.Reader/Writer instead of os.Stdin/Stdout
   - Launch two goroutines with done channels:
     - `stdinPump(ctx, conn, stdin, detachKey)` — reads stdin, checks for detach key, sends MakeInputFrame
     - `wsOutputPump(ctx, conn, stdout)` — reads WebSocket messages, writes MsgOutput payloads to stdout
   - Select on readDone, writeDone, ctx.Done()
   - On any completion, close the WebSocket with `conn.Close(websocket.StatusNormalClosure, "detach")` and return

3. `func stdinPump(ctx context.Context, conn *websocket.Conn, r io.Reader, detachKey byte) error`
   - Read loop: `buf := make([]byte, 32*1024)`
   - For each byte in `buf[:n]`: if `b == detachKey`, return nil (clean detach)
   - Otherwise, send `relay.MakeInputFrame(buf[start:i])` for accumulated bytes before detach check
   - Optimization: scan for detach key in the buffer. If not found, send entire buffer as one MakeInputFrame. If found, send bytes before it and return.
   - On read error or ctx cancellation, return

4. `func wsOutputPump(ctx context.Context, conn *websocket.Conn, w io.Writer) error`
   - Read loop: `_, msg, err := conn.Read(ctx)`
   - For each message: call `relay.ParseFrame(msg)`. If `msgType == relay.MsgOutput`, write payload to w
   - This handles both the initial scrollback snapshot (first message, may contain concatenated MsgOutput frames with embedded 0x01 bytes — the terminal handles SOH bytes harmlessly) and live frames (individual MsgOutput frames)
   - On read error (session ended, WebSocket closed), return

5. `func makeClientResizeFrame(cols, rows uint16) []byte`
   - Returns `[]byte{relay.MsgResize2, byte(cols >> 8), byte(cols), byte(rows >> 8), byte(rows)}`
   - Uses `relay.MsgResize2` (0x11), NOT `relay.MsgResize` (0x02) — the server's read pump at relay/server.go:101 handles `case MsgResize2:` for client-to-server resize

**CRITICAL anti-patterns to avoid:**
- Do NOT call `os.Exit` anywhere in cmd_attach.go — return errors to main()
- Do NOT use `signal.Notify(os.Interrupt)` to catch Ctrl-C — in raw mode Ctrl-C is byte 0x03, not a signal. Only catch SIGTERM and SIGHUP.
- Do NOT use `relay.MakeResizeFrame()` for client-to-server resize — it uses MsgResize (0x02) which the server ignores. Use `makeClientResizeFrame()` with MsgResize2 (0x11).

**Create `cmd/agenthub-cli/cmd_attach_unix.go`** with build tag `//go:build !windows`:

```go
func watchResize(ctx context.Context, conn *websocket.Conn) {
    winchCh := make(chan os.Signal, 1)
    signal.Notify(winchCh, syscall.SIGWINCH)
    go func() {
        defer signal.Stop(winchCh)
        for {
            select {
            case <-winchCh:
                cols, rows, err := term.GetSize(int(os.Stdin.Fd()))
                if err != nil {
                    continue
                }
                frame := makeClientResizeFrame(uint16(cols), uint16(rows))
                _ = conn.Write(ctx, websocket.MessageBinary, frame)
            case <-ctx.Done():
                return
            }
        }
    }()
}
```
