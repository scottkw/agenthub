# Phase 19 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Nature

**This phase introduces zero user-facing UI changes.** Phase 19 is a pure backend refactoring: it extracts `SessionEngine` from `App` into `internal/daemon/` and establishes an in-process HTTP/JSON Unix socket IPC layer. The Wails-bound method signatures on `App` remain identical. The frontend React components are untouched.

**UI obligation:** Preserve — do not regress — the existing visual contract. Every component, color, spacing value, and typographic rule documented below is already live in the codebase. This spec functions as a regression baseline, not a design prescription.

Source for all values: `frontend/src/style.css` (read 2026-03-23).

### Wails Binding Contract
The following Wails-bound method signatures on `App` must remain identical after Phase 19. The frontend calls these; any signature change is a regression:

```
CreateSession(cli, name, workDir string) (string, error)
ListSessions() []SessionInfo
KillSession(id string) error
RenameSession(id, name string) error
DetectCLIs() []DetectedCLI
GetRelayPort() int
ToggleWebServing(id string, enabled bool) error
GetWebServerURL() string
IsWebServerRunning() bool
GetSessionStatus(id string) string
GetTailscaleStatus() TailscaleStatus
```

### Wails Events Contract
These runtime events must continue to fire with identical payload shapes:

```
session:status  → { sessionId: string, status: string }
tailscale:health → { installed: bool, connected: bool, hasCerts: bool, ip: string, domain: string }
```
