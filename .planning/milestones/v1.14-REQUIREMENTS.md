## v1.14 Requirements

Requirements for this milestone. Each maps to roadmap phases.

### UI Contrast (GitHub #23)

- [ ] **UI-01**: Main GUI text elements (sidebar labels, tab titles, settings labels, welcome content, status bar text) meet WCAG AA contrast ratio (4.5:1 for normal text) against the dark background theme

### Theme Audit (GitHub #21)

- [ ] **THM-04**: The theme picker only lists xterm themes that render readable foreground text, cursor, and ANSI colors across all 4 supported CLIs (Claude Code, Codex, Gemini CLI, OpenCode); unusable themes are removed from the picker

### Sidebar Layout (GitHub #20)

- [ ] **SBR-02**: Sidebar icons remain in the same horizontal position whether the sidebar is collapsed or expanded — no perceived shift when toggling the hamburger button

### OpenCode Theming (GitHub #17)

- [ ] **THM-05**: The theme selected in Settings > Appearance is applied to OpenCode terminal sessions, matching the behavior for Claude Code, Codex, and Gemini CLI sessions
