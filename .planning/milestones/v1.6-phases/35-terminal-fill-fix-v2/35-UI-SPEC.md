## Interaction Contract

This phase is a behavioral fix, not a visual one. The interaction contract covers the specific behavior change in `TerminalPanel.tsx`.

### Terminal Fill Behavior (Phase 35 Change)

| State | Current (Broken) Behavior | Required (Fixed) Behavior |
|-------|--------------------------|--------------------------|
| Tab activated, CLI has not yet output data | Terminal rendered at spawn dimensions (no fill); `fit()` silently fails because `css.cell.width === 0` | rAF retry loop polls `proposeDimensions()` up to 20 frames; fills as soon as cell dimensions are non-zero |
| Tab activated, CLI has output data (Codex) | Fills correctly on double-rAF (no regression risk) | Fills on first `proposeDimensions()` check — loop exits immediately |
| Tab switch to previously hidden terminal | Same broken behavior as initial activation | Same fix applies; `isActive` effect re-runs on each tab switch |
| Window resize after initial fill | Works correctly via ResizeObserver (unchanged) | ResizeObserver path unchanged |
| `wails dev` vs production binary | Fix must behave identically — rAF is timing-agnostic | Verified identical behavior — polling does not rely on fixed frame count |

### No New Visual States

This phase introduces no new:
- Loading states visible to the user
- Error states visible to the user
- Empty states
- Modal dialogs or overlays
- Status indicators or badges

The fill succeeds silently. The user's observable outcome is that the terminal viewport is correctly sized on first render.

## Implementation Notes for Executor

These notes are derived from RESEARCH.md and are prescriptive for the executor.

**File to change:** `frontend/src/components/TerminalPanel.tsx` — the `isActive` useEffect only. No other files change.

**Replace:** The double-rAF one-shot (lines 103–134 in current TerminalPanel.tsx) with the rAF retry loop pattern.

**Key constants:**
- `MAX_ATTEMPTS = 20` — do not lower; covers 333ms at 60fps or 667ms at 30fps
- Readiness check: `fitAddonRef.current?.proposeDimensions() !== undefined`
- Cleanup: `cancelled = true` flag + `cancelAnimationFrame(rafId)` on the most recent rAF ID
- ResizeObserver: retained unchanged for post-initial-fill resize handling

**Do not change:**
- The `[isActive]` dependency array
- The `[sessionId]` effect (terminal creation)
- The `[fontSize]` effect (font size application)
- Any Go backend files
- Any other frontend files
