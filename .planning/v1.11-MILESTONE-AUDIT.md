### Integration Gap

**SERVE-02 Init-Time Race (Low Severity)**

- **Location:** `App.tsx` lines 113-131 (polling interval)
- **Issue:** When frontend initializes during local-mode startup, `IsWebServerRunning()` may return `false`. The polling interval later detects the server and sets `webServerRunning=true`, but does NOT re-run the `webEnabled` seeding loop for existing sessions.
- **Impact:** Restored sessions may show `WEB OFF` in StatusBar until user creates a new session or refreshes. New sessions created after the poller fires work correctly. Daemon state is correct throughout.
- **Affected:** SERVE-02 (display only, not functional)
- **Workaround:** User refresh or new session creation
