### Integration Findings

**1. APP-03 edge case — quit modal undercounts during auto-close countdown**
- **Severity:** Low
- **Location:** `frontend/src/App.tsx:404`
- **Impact:** During the 5-second window after an agent exits but before the tab closes, the session is already `state="stopped"` in the daemon. If the user triggers quit during this window, the quit modal excludes the session from its count despite the tab still being visually open.
- **Fix:** Supplement `ListSessions()` result with frontend `sessionExits` state to re-include sessions with active countdowns.

**2. QuitGUIOnly notification field mismatch**
- **Severity:** Low
- **Location:** `app.go:194`
- **Impact:** macOS notification after "Quit GUI Only" checks `s.Status != "stopped"` but the `Status` field (running/idle/waiting/errored) never equals "stopped". Should check `s.State != "stopped"`.
- **Fix:** Change `s.Status` to `s.State` on line 194.
