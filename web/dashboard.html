    CA Certificate Installation

    To avoid browser TLS warnings, install the AgentHub CA certificate into your OS trust store. Download CA Certificate

    macOS
    Linux
    Windows

    Open Keychain Access and drag the downloaded ca.crt file into the System keychain. Then double-click it, expand Trust, and set When using this certificate to Always Trust.

    Alternatively, run in Terminal:

    sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ca.crt

    Copy the certificate to the system CA bundle and update:

    # Debian / Ubuntu
sudo cp ca.crt /usr/local/share/ca-certificates/agenthub.crt
sudo update-ca-certificates

# RHEL / Fedora / CentOS
sudo cp ca.crt /etc/pki/ca-trust/source/anchors/agenthub.crt
sudo update-ca-trust

    For Firefox on Linux, import via Settings → Privacy & Security → Certificates → Import.

    Run in an Administrator Command Prompt:

    certutil -addstore -f "ROOT" ca.crt

    Or open Manage User Certificates (certmgr.msc) and import into Trusted Root Certification Authorities.
